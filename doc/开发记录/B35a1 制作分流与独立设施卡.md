## B35a1.3 开发假设

只涉及代码结构、命名、排版与交互承载：

1. 内核只读规则集中在新文件 `GameEngine.CraftScope.cs`。施工阶段判断只在 `BuildStageHere` 一处，B57 持续工地替换时只改它。
2. 工作区身份 `CraftWorkspace.Key` 的写法：
   - 自建工坊：`ws|{世界种子}|{地点}|{区}|{设施类别}`。
   - 公共设施：`pub|{世界种子}|{公共站 Id}`。
   - 分类记忆和返回重验都用这个键，不用列表序号或显示名。
3. 分类记忆以 JSON 存浏览器本地的 `craftTabs`（与 `fold`、`collapsed` 同一机制），不进存档。顶栏用键 `top`。
4. 工作区左列顶上放设施块（图标、名称、状态行），下面是分类按钮。状态行与设施栏卡面取同一个 `FacilityCardsHere`。
5. “处理说明”折叠区用 `<details>`，默认收起，放在火堆加工位下方、对象层上方，只在主层出现。条目逐条列配置里全部处理（原“自动加工”列表同一来源）。
6. 候选里的设施配方行用 `RecipeCandidate.Workspace` 标所去设施。行小字的写法是 `{设施名} · {原门槛或时长小字}`。
7. 开发入口“B35a1 设施试用组”：在当前区记工作台、锻炉、缝纫台已建成，并放废金属 3、铁矿石 3、木炭 2、木材 4。

## B35a1.4 实施记录与偏差

**Q600**

- 判定 `RecipeVisible` 只按现有事实现算，不写任何旗标，也不授知识。显现条件任一满足即可：
  - 已有知识；
  - 主角技能全满足；
  - 接取或完成指定任务（任务事实沿用 `QuestAccepted`／`QuestDone`）；
  - 完成指定任务。
- 共用这一判定的地方：顶栏与工作区目录、拖拽候选、物品来源（`ItemSources`）、直接请求（开工校验，回“尚未发现这项配方。”）、候选返回重验、右栏悬停有效性。
- 知识奖励预览目前没有列配方名的界面，未另改。

**分流**

- 顶栏首次默认“徒手制造”，工作区默认“全部配方”，出处 S14 2482、Q908。
- 主行动正在做本上下文的配方时，新开面板就选它。
- 指定的配方需要设施、却从顶栏打开时：不选，出提示“需要在{设施名}内查看和操作此配方。”。
- 工作区绑定的设施不在了（换区、拆除），刷新时关面板并提示“该设施已不可用，请重新选择。”。逐层返回恢复路径同一处理。

**独立卡**

- 遮蔽棚、床垫只在已建成或施工中出卡，安全屋卡同理。
- 工坊施工中暂不出卡，与原先一致。偏差：Q935 持续工地留 B57。
- 晾制架仍是自己的卡，不进 `FacilityCardsHere`。

**拖拽候选**

- 两条路径都只列已掌握且可显示的配方，不列锅食谱、晾制与安全屋三项。
  - 材料拖到材料：原顶栏三类配方，加上当地设施配方。
  - 材料拖到营地地点卡：原设施建造（不含野外火堆），加上当地设施配方。
- 偏差：过滤后一条都不剩时，不再打开空候选，落回原合并或“不支持”判定。原先会打开含未掌握配方的列表。
- 点设施候选，进该设施工作区；候选上下文（列表、所选配方、所指锅）保留。

**返回与 ESC**

- 下面没有别的窗口时，返回／ESC 先回候选，按以下条件重验：配方已掌握、可显示、设施仍在。
- 失效的条目去掉，并提示“内容已变化，请重新选择。”；一条不剩就关面板。

**Q932**

- 原处理说明九条全部迁入火堆加工菜单（烧水、烤制×2、水煮×2、复煮、煅烧、烘制、炖煮），标题、说明与步骤原样。
- 水量仍按现行配置，100 毫升属 B56，未改。

**Q930**

- 撤 `OpensCraft`。办完服务只留结果日志，不开制作页。

**Q931**

- 以下各处都用 `SafehousePanelBlocked`（当前地点已建安全屋）把关：`SwitchPanel` 打开、`PanelRestoreBlock` 逐层恢复、每次刷新时离开当地收面板、安全屋卡“面板”按钮。

**测试与构建**

- 全量测试从 3162 增至 3192，全部通过；`dotnet build web/Survival.sln` 0 错误。
- 3162 是开工前的数目。M1052 合并 B45 的三项选择层测试为一项后为 3160，M1053 新增 32 项。

**代码合成一个提交（M1052）的原因**

- 撤“选择设施”和 `OpensCraft` 同时影响内核、网页壳与旧测试。拆开提交会让中间提交编译不过。
- `GameEngine.CraftScope.cs` 一个文件同时承载 Q600、分流、设施卡、候选和安全屋校验。

## B35a1.9 本地试玩结论

（留空，待推送前本地 Release 包试玩。）

建议路线：

1. 开局营地：打开顶栏“手工制作”，应停在“徒手制造”，共四类，没有“自动加工”。切到“设施建造”后关闭、再打开，应恢复“设施建造”。
2. 点开发入口“B35a1 设施试用组”：设施栏应出工作台、锻炉、缝纫台三张卡，各写“{名} · 空闲”。
   - 点工作台：标题“工作台”，左列有设施块和“全部配方／装备／材料”。
   - 选“材料”后关闭，再点锻炉：锻炉仍是“全部配方”。回工作台：恢复“材料”。
3. 在工作台做“紧固件”（废金属1）：工作台卡变“制作中”，锻炉、缝纫台仍“空闲”。做完回“空闲”。
4. 把废金属拖到另一张材料卡或营地地点卡：候选里工作台配方的小字前写“工作台 · ”。
   - 点它进工作台工作区，按钮写“返回”；按 ESC 回候选，再按一次关闭。
   - 点表头“显示全部”：进顶栏“全部配方”。
5. 开发入口“制造熟练设为7级”：工作台“装备”里应多出猎手弓、战术电台、聚焦镜片、镇定勋章、维护手册等蓝图配方，仍写未掌握；直接开工被拒。
6. 点火堆卡：主层有收起的“处理说明”，展开后有九条，没有“查看火堆”。
7. 营区（开发入口登记后到营区工坊）：
   - 三张公共卡：工作台写“空闲”、角标“公共”、悬停“公共设施。”；锻炉、军械台写未开放原因。
   - 事项盘“使用营区工坊”首句“从设施卡进入。”，按钮“使用营区工坊（0分钟）”，办完不开制作页。
8. 建安全屋后：屋外、屋内都能开面板。到别处后：地图没有“安全屋返程”，安全屋卡不出，无法远程开面板，外地柜子记录不显示。
9. 系统说明“手工制作”：首段为入口段原句，第二段为秘密配方说明。“营地设施”条目里没有“营地建造”。
