## B45b.3 开发假设（只涉代码结构、内部命名、排版与动画）

1. 卡面与菜单的快捷入口做成同一个 Razor 组件，组件不带外层容器；菜单里放在原「投入木材」所在的 `fm-quick` 行，按钮沿用卡面样式类，按内容定宽、一行放不下换行。原菜单「投入木材」旁的不可用原因小字保留。
2. 菜单里的「点燃」按钮 id 为 `fm-ignite`；点火盘仍是原居中盘，只是来源失效判定看发起它的那个按钮。
3. Q583 的「锅卡」取加工位卡里的锅卡标题（`.pc-head`），「加工位卡」取 `fm-slot-{k}`；「标题」取菜单标题 `h2`。
4. Q584 的锅层「多个可能动作」按「对象操作区与底部提交条同时显示」判定；只有其中一个时照原规则标键帽。
5. Q585 首段的焦点恢复只在对白结束、加工菜单仍开着时做：对白前焦点仍在菜单里且可用就回它，否则回菜单标题。
6. 「原因」按钮在鼠标悬停、键盘聚焦、点按（触屏）时显示，鼠标离开或失焦时恢复；显示内容每次按该行当前真实原因重读，行已恢复可用或消失就不再显示。

### 实现中按正文取舍的地方

- **Q582 保留草稿时的显示**：正文写「下一次真实提交才重验并提示」。所以目标位被别处占用（`Taken`）后，来源区不按占位逐行标灰，已选来源和数量文本原样保留，提交按钮可按；按下时同源重验，底部显示「加工位{序号}已被占用，请重新选择。」，不扣物、不改投另一空位。此时不显示「最多N份」，＋／−不可用（没有可放入上限），数量框仍可编辑。
- **Q582 无草稿时别处占用**：只选了空位、没选来源时，新内容直接显示在加工位卡上，停在加工位层（不进入新内容层）。
- **Q582 煅烧确认**：从菜单进入的煅烧确认投料也按菜单自己的放入处理（不算「被别处占用」），但不清菜单的来源选择（煅烧确认有自己的木材明细，不用菜单来源）。
- **Q588 判定口径**：预演没有原因但可放入量为 0 时，行也算不可放入，原因用原句「当前没有可放入数量。」。

### 本地自测

用无头浏览器（`tools/playtest/cdp.mjs`）在 1280×720、1920×1080 下试过以下项目，控制台无错误。

- **Q585 首段**：新局读完开场对白后点火堆卡，菜单先开，引导「火要有燃料」盖在上面；读完回到同一菜单，焦点在菜单标题。菜单开着时触发的另一段引导（「一份安全的水」）读完同样回到菜单。
- **Q587**：主层只有标题，没有路径；进加工位1后路径为「火堆 › 加工位1」，再进锅为「火堆 › 加工位1 › 金属锅」，进锅里净水为「… › 金属锅 › 净水」。
- **Q581**：菜单主层有「投入木材」「点燃」，有内容后多出「等待加工」，点燃后换成「熄灭」。
  - 菜单里投入木材：燃料 0 → 60 分钟，菜单不关。
  - 点燃：点火盘打开（锚 `fm-ignite`），停 1 秒以上不被收起；Esc 只关盘。选打火器后菜单仍在；点「点火（5分钟）」开工，菜单收起、中央进度条出现。
  - 等待加工：点击开工，菜单收起。
- **Q588**：加工位1空位层，木材行显示「木材×1 不可放入 原因」，没有 `data-drag`，不可聚焦，点击不选中；悬停「原因」时底部显示 Q556 原句加煅烧引导，移开恢复「请选择原料来源。」。
- **Q584**：点选金属锅行后焦点在数量框，按 Enter 放入。锅层可见键帽只有「ESC」「0–9」，没有 Enter；锅里净水层只有一个对象操作，照常显示 Enter。点净水行后焦点进数量框，输入 2、Enter，装满 1000 毫升。
- **Q582-A01**：放锅成功后停在「火堆 › 加工位1」，锅只显示在加工位卡上，来源区收起，来源已清空。装水成功后停在锅层，来源清空。
- **Q583**：加工位层 Esc 回主层，焦点在 `fm-slot-0`；锅层 Esc 回加工位层，焦点在 `fm-slot-0`；净水层 Esc 回锅层，焦点在加工位1的锅卡标题；煅烧确认投料成功后焦点在新内容所在的 `fm-slot-1`，停在主层。

## B45b.5 遗留

1. **Q585 下方对白布局**：去大框、贴头像不在本批（BM4b）。
2. **Q586、Q589、Q590** 不在本批。
3. **内容被自己取走或时间推进移走后的焦点**：Q583 只写了「返回」与「煅烧投料成功」两种情况，以及返回目标失效时回安全处。以下两种情况焦点不移动，以免抢走玩家正在操作的位置：
   - 在内容层用「取出」把内容拿走，菜单自动回到加工位层（原按钮消失，焦点落在页面上）；
   - 时间推进使内容消失，菜单回父层并提示「内容已变化，请重新选择。」。

   要不要也把焦点移到加工位卡，可在下轮试玩后再定。
4. **引导是否重复**：读完对白本身不会再开引导。再次打开菜单是否再给同一引导，仍按内核原有的引导去重规则，本批未改。

## B45b.6 线上试玩重点

**开发入口**：网址加 `?dev=1`，按 Esc 打开游戏菜单，在「开发入口」栏里取用。常用的有：

- 「煅烧木炭：木材×10（放当前地面）」
- 「新物品（食品）」

1. **首次火堆引导（Q585 首段）**：新开一局，读完开场对白后点火堆卡。
   - 看菜单先开、引导「火要有燃料」盖在菜单上；
   - 读完回到同一菜单，焦点在菜单标题，Tab 能接着走；
   - 不会再弹一次同一引导。
2. **主层快捷（Q581）**：
   - 菜单主层的「投入木材」「点燃」「熄灭」「等待加工」与卡面对比，原句、禁用条件、原因是否一致；
   - 点燃打开点火盘，选打火器期间菜单不关；
   - 点火、等待加工开工成功后菜单收起，交给中央进度条；
   - 开工失败（如燃料不够）时菜单留着。
3. **放入后停层（Q582-A01）**：
   - 加工位1选锅放入，停在「火堆 › 加工位1」，来源已清空；再按 Enter 不会做任何放入；
   - 锅层装水、放入食材后停在锅层，来源已清空。
4. **占位草稿（Q582-A02）**：需要两份可放进加工位的材料，例如两份生块根，或锅加生块根。
   - 先在加工位2选一份并选好来源；
   - 再把另一份从地面或随身拖到加工位2；
   - 看菜单不跟随新内容、来源仍选中；
   - 按「放入加工位2」或 Enter，提示「加工位2已被占用，请重新选择。」，材料不少，加工位1不被代投。
5. **返回焦点（Q583）**：
   - 净水／食材层、锅层、加工位层逐级 Esc 或点路径，看焦点依次落在锅卡、加工位卡；
   - 煅烧确认投料后，焦点落在新的煅烧位；
   - 聚焦本身不执行任何操作。
6. **锅层 Enter（Q584）**：
   - 锅层两个按钮都没有 Enter 键帽，焦点不在框里时按 Enter 不做事；
   - 点来源行后焦点在数量框（已全选），输入数字后 Enter 提交一次；
   - Tab 到「拾取…」按钮后按 Enter，执行拾取。
7. **主层路径（Q587）**：主层没有路径行，子层路径完整，可点。
8. **不可放入来源（Q588）**：
   - 选空加工位后，木材行标灰，带「不可放入」「原因」；点行、拖行、键盘都选不了；
   - 悬停、聚焦、点按「原因」时，底部显示完整原句，离开后恢复；
   - 在主层先选木材（未选目标时可选），再点加工位，木材被清掉，底部显示木材原因，提交禁用；
   - 主层「投入木材」、拖木材到火堆卡加燃料、「煅烧木炭」照旧可用。
9. **三档分辨率**：1280×720、1600×900、1920×1080 下，主层快捷按钮行与来源行（「不可放入」「原因」）不溢出、不截断。
