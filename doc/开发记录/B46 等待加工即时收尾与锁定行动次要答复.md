## B46.3 开发假设（只涉代码结构、内部命名、排版与动画时长）

1. **展示时长**（策划【交开发方定】）：标准 1200 现实毫秒，按 Q321 快／标准／慢 ×0.5／1／1.5 为 600／1200／1800。从中央条渲染后让出一帧再计时（入场 180ms×倍率包在里面，不耗尽展示）。
2. **展示期间的进度条不做插值**：中央条按内核真值静态显示「已推进0分钟 / 5分钟」「剩余5分钟」与 0% 进度，唯一真实段提交后才变。因此「减少动态效果」与普通情形是同一静态展示、同一间隔，不需要另写分支。
3. **单段的判定**放在内核只读方法 `SingleSegmentShowPending`：当前要推进的行动（子行动优先）在运行、尚未提交任何段（`ElapsedMinutes == 0`），并且开工锁定／原单段事务／潜行接近或躲避（`ExitLocked`），或同源预计（`EstimateEndMinute`，最多模拟 2 段）恰为一段——后者只对读档后不锁的旧在办行动有用，展示时退出控件照其真实状态。终局、对白、战斗、敌踪待选时不展示。
4. 等待期间 `Running` 保持为真，沿用「行动进行中」对整理、开工的原拦截；不新增输入绑定，跳过按钮与空格沿用 BM2 的同一个按钮。
5. Q536 的非锁定收尾放在 `ResumeCore` 的原 `ResumeBlockReason` 之后：开关关时该方法只验通用状态，另加「原火堆仍在」才收尾，火堆没了沿原路径（置回运行后由段前判定停止）。
6. Q533 窄条改为逐行，只删两条 CSS；完整弹窗原本就逐行。

## B46.4 实施记录与偏差

1. **Q536 等待加工全部完成（R199）**：
   - 非锁定、锁定、Q524 旧档在办的等待加工，暂停期间原目标都已完成（例如暂停层「休息30分钟」期间烤好）时，点「继续行动」立即写「等待加工结束：{地点}火堆{目标数}项加工全部完成，成品留在原位（{已耗时}）。」，游戏时间不变，不进推进循环也不走单段展示。
   - 已耗时只是等待自己的段，暂停中休息的时间不并入；目标数取原绑定，后放进火堆的新加工不算；成品被取走，回执仍算完成。
   - 部分完成、目标消失而无回执、空绑定都不当作全部完成，沿原规则（非锁定照常继续运行或按原句拒绝；锁定按 Q514 分类）。
   - 只读复核、估算、剩余显示 0 不清行动、不写日志；重复请求与读档不重复完成。
   - 新版敌踪开关开时，原来非锁定会拒绝「原等待目标已全部完成，请退出等待。」，现在改为直接完成；这句只剩空绑定一种情形会出现（实际开工校验不允许空绑定）。
2. **Q531**：柴炉部署、收起锁定后原物丢失，继续时写例如「部署折叠柴炉已中止。原因：原行动目标已失效，无法继续。已耗时间保留。」。不补原物、没有成果；10 分钟铺开野营布不锁定。B41c2 已是此行为，本批只补验收用例。
3. **Q532**：锁定采集暂停、原工具在当前地面只缺拾取时，中央条与「继续行动」拒绝都写「需要先拾取原工具：撬棍。」这样的公开名。工具在别处、损坏、耐久不足、卡位或重量不允许仍用各自原句；非锁定采集仍「先拾取工具」。
4. **Q533**：暂停条保持现位置。完整弹窗和窄条都是「暂停原因：…」下一行复核原因（警示色），永久失效再下一行「本次行动无法继续，点击「继续行动」后将自动中止。」；文字直接在页面里，不靠悬停。
5. **Q534**：旧版（开关关）接近敌人与固定战、可选强敌，锁定主行动暂停且补给子行动未结束时，按钮悬停与真实拒绝都是「当前行动还没结束。」；子行动结束后是「行动暂停中，请先继续行动。」。非锁定暂停仍是「行动暂停中，先结束或取消行动」。新版敌踪卡的入口不在本条范围，未改。
   - （说明）可选强敌和固定战共用同一个接战拦截 `EngageBlocked`，B41c2 起两者句子就一致，本批保持一致。
6. **Q535 单段展示**：救助配给、柴炉部署／收起、点火、食用、吞噬融合、开工 5 分钟锁定的工作等，开工（扣物、扣额度等即时提交照旧一次）后中央条先出现约 1.2 秒（快 0.6、慢 1.8），写行动名、「已推进0分钟 / 5分钟」「剩余5分钟」（工作型「预计剩余5分钟」）、「本次行动不可中途退出。」与「跳过动画 空格」，然后提交那唯一一段并出结果。点跳过或按空格立即结束展示，结果不变。补给子行动同样处理，结束后回到父行动暂停。10 分钟铺布、长行动最后 5 分钟不展示。
7. **测试**：
   - `dotnet build web/Survival.sln`：0 错误。
   - `dotnet test web/Survival.sln`：2367 项全部通过（批前 2344 项，本批新增 23 项）。
8. 本批没有启动浏览器预览，单段展示的观感、三档分辨率下窄条逐行排版留给试玩。
