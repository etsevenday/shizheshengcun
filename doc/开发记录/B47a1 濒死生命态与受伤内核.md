## B47a1.3 开发假设

以下为代码结构、命名、排版等开发方自定，不涉及规则、数值或新玩家文字：

1. 生命态不另存枚举，由“确死标记（角色 `Dead`／名册死亡／主角终局）＋当前健康”派生；新增 `ActorState.Dead` 只在确实死亡时置位，主角终局与队友死亡两条原收束各自同时置位。
2. 所有健康伤害经一个入口 `DamageActor`，返回“未受伤／受伤／进入濒死／抵抗／死亡”，死亡后果（终局、离队、遗物、战斗收束）仍由各调用方在原时序处理。
3. 状态句由调用方收集，在自己的伤害／治疗日志之后写出；战斗中写战报，战外写普通日志。
4. 测试用 `GameEngine.TestDeathRolls` 队列注入致死判定的 u（不动存档随机游标），正式流程恒为空。
5. 测试类命名 `B47a1DyingTests`，继承 `BattleTestBase`。

## B47a1.4 实施记录与偏差

- 致死判定只在“事件前已濒死且 D>0”时抽一次随机；正常者归 0 不抽、不穿透。没有濒死者的存档在本批前后随机序列完全一致。
- 世界段顺序：先结非健康五项 → 健康负项合计 × 5/60 作为一次身体损伤 → 事件后仍正常存活才加自然恢复（不与负项相抵）→ 推进 5 分钟 → 战外出血独立一次事件 → 段末确死收束（主角终局、同伴离队）先于尸变与自然治愈。已确死者本段不再结算免疫、病毒、出血。
- 同伴在世界段确死，死亡原因沿原 `DamageCause`（饥饿、缺水等）或「伤势过重」；主角沿原最近伤害原因，出血致死为「出血」。
- 战斗：敌方命中先走入口，入濒死／抵抗时原感染、控制、出血、磨损、恐慌照常结算；确死才写原死亡战报并收束，不再执行后续反应。受击特写的“倒下”标记只在确死时给（姿态／特写本身属 B47b）。主角在死亡喷溅中确死，仍由 PlayerDownAfterSplash 在本次结算写完后终局。全员健康 0 不判败北。敌人不变：H 归 0 直接死亡、退出在场名单，掉落不变。
- 状态句位置（R09 §8「只追加对应状态句」）：战报与普通日志里都是紧跟在原伤害／治疗那一条之后的独立一条，不并进原句。
- 医疗：绷带（战外用药、战斗包扎、城内换药）与战斗医疗技能直接回血都走 HealActor；只止血、解除虚弱失衡等无正回血不脱离；脱离清提醒锁，再次归 0 重新先入濒死。食物等非医疗正健康在濒死期间不生效（现有数据只有绷带带健康，属防御性门）。已确死者不受理回血。
- 预估（过渡口径，B47a3 前）：只读预演不抽致死随机，已濒死者再受正伤一律按未能抵抗处理；因此「按当前状态，行动途中可能死亡」现在只在预演里归 0 后又受正伤时出现，不再在首次归 0 时出现。撤出旧风险句未改。
- 原非致死事件包（远征中止惩罚“健康扣到不低于 1”）不变，不接入致死判定。
- 旧测试：14 条以“健康归零当 tick／当击即死”为前提的用例（AT09、RC15、DR07、DR13、EC14、CB08、PTY_Q90e、B518、R612、P416、R07_A01、B9a 同伴战死、CB09、COMP20 守卫战死亡）改为“已濒死＋本次正伤＋致死判定失败”，保留原意图；S11 搜集划伤改为验证入濒死后成果照交；17 门、存档 52 相关计数同步改。
- 开发菜单「求生熟练度全部 N 级」不含意志（与潜行同样单列）。

测试：2628 项全绿（基线 2606，新增 22 项：M1 配置／新局／迁移×2／濒死同伴入战；M2 A01、A02、意志等级、搜集划伤；M3 A04×2、A05、濒死同伴、出血死因；M4 A03、A06、大回合出血、敌人 0H；M5 A05 绷带脱离、只止血与食物门、战斗包扎、城内换药）。

开发菜单（?dev=1）复现路线：

- 进入濒死：「濒死与意志（B47a1）」→「主角健康→0.3」，再被敌人打或开始赶路／等待并点「主角饱食水分→0」，日志出现进入濒死句。
- 致死抵抗：「主角健康→0（濒死）」＋「主角饱食水分→0」或「主角开始出血」后等待；每段一次判定，成功写抵抗句，失败按原死亡收束。「意志设为1级／10级」对照 65%／83%。
- 医疗脱离：「药品各1」给绷带，濒死时使用，日志在用药结果后出现脱离句。
- 同伴：队友行「健康→0（濒死）」，入战后被打、或战外受伤观察同一流程；真死才离队、留遗物、其他人恐慌 +8。

## B47a1.6 线上复验结论

完整档（构建 fb0a28b，线上无头浏览器，2026-11-15），结论：通过，无违反策划案的 bug，控制台无错误。

- 开发菜单「濒死与意志（B47a1）」组齐全；成长页 17 门熟练度，意志排在潜行之后。
- 战斗：健康 0.3 被游荡尸击中进入濒死不死；之后每次挨打一次抵抗句，濒死期间感染暴露照常；确死只写原死亡句，结算写完才进终局，终局记录含最后一击。
- 世界段：濒死＋出血、濒死＋饱食水分归 0 均每段一次判定，出血独立成事件；意志 10 级 83%、1 级 65%；濒死期间休息、睡眠健康保持 0。
- 医疗脱离：战外绷带回血后写脱离句；脱离后再归 0 重新先进入濒死；战斗中队友包扎回血写脱离句。
- 队友：濒死仍在队、可入战、无恐慌；流血确死后离队、遗物可取、他人恐慌+8，名册与遗物记录正确。
- 敌人 0H 直接死、胜利结算正常；搜集、制作、吃喝、睡眠、存读档、返回标题再读档正常；濒死存档读回后不重复写进入濒死。
- 旧档 51 读入正常，补意志 1 级。三档分辨率主界面与战斗画面无错位。
- 体验观察：濒死在界面上无标识、成长页意志用通用说明（属 B47b，Q690、Q695）；已濒死时仍弹健康高危暂停句（Q698，次要）；世界段抵抗句与确死句时间戳不一致（Q699，次要）；队友战死后编队留空位（旧行为）。
