## B47a3.3 开发假设

以下为代码结构、命名、排版等开发方自定，不涉及规则、数值或新玩家文字：

1. 两支预估共用一次副本推进：副本里“需要致死判定”一律按仍可存活继续（完成计划），身体区只取首个危险段末的快照。危险段 = 首次由正常归零的那一段，或已濒死者受确定／可能正伤的那一段；身体快照取该 5 分钟段结束时。
2. “健康取决于抵抗结果”判为：该人在截止段内有需要致死判定的正伤（确定或可能）。只有首次归零、同段没有后续正伤的，健康后值可确定为 0。饱食、水分、体力、清醒、精神在伤害事件之前结算，截止段内照常显示。
3. 普通行动相关人物 = 预估开始时同行（`Party`）里未确死的人，含濒死、含主角；候补、驻屋、不在同行的名册人物不纳入（副本里候补照常推进世界，只是不记风险）。右栏原本只显示主角身体前→后，本批不新增同伴身体行，同伴只出风险句；食饮同伴的 `Feed.TargetAfter` 同样取共同截止处。
4. 各人风险只列每人第一个危险；晚于共同截止的，用同一套 Q675 句子列在「各人风险」组，不标发生时刻（策划只给了组标题与说明，没给时刻写法）。
5. 概率伤只有两处真实来源：搜集划伤与遗迹勘整风险（都在完成时结算、只伤主角）。副本里按未触发推进；已濒死者在完成段记“仅有概率正伤”的危险；尚未濒死者若这一下扣量不小于当时健康，只附 Q687 限定（只在它不晚于共同截止时附）。
6. 求不出可信完成 = 副本推进结束时行动仍在（暂停无法继续、算满 4000 段）或以中止收场（原料腐败、等待加工燃料不足）。原因取暂停无法继续的原拒绝原因或中止日志原文，接在“按当前条件无法预估完成。”后。此时耗时与完成时刻写“未预估”，不列设施／燃料变化与“需求工作量…完成后余量”说明；产物、完成后经验等原本就是静态配方／规则说明的行照常保留。`EstimateEndMinute`（中央条剩余、开工 5 分钟认定）同样把中止视为求不出，返回 null。
7. 计划区用 Q683 正式标题“完成计划（假设能够存活并完成）”与限定句；Q674 的“计划信息不代表一定能够存活并完成。”被 Q682—Q687 节取代，不再另显示。
8. 右栏版式：有截断时先“预估至危险段”块（标题、范围句、截止句、主角身体行、截止内阈值提醒、本段风险、各人风险组、抵抗含义、概率限定），再“完成计划”标题与限定，下接原耗时／完成／产物／负重／经验／可能物资／原折叠；计划区的风险行只留倍率变化等计划提示、无法估完与尸变句。无危险时与原版式相同。
9. 就近浮窗、制作／休息面板摘要等紧凑位置仍读摊平的 `Warnings`（常只显示第一条），截断时顺序改为：无法估完 → 截止句 → 本段风险 → 各人风险说明与风险 → 抵抗含义 → 计划提示 → 阈值提醒 → 尸变 → 概率限定；无危险时与原顺序相同。
10. 撤出确认窗：原即时损失表不变；“返程中仍可能发生”里原风险行之后逐人一行「{姓名} 健康{扣包后}→{本人截止处或撤出结束}」（取决于致死判定写“未预估”），有截断的接本人截止句与撤出风险句，再附一次抵抗含义与撤出尸变句。撤出途中只有健康变化（五项已含在扣包里），所以只列健康。
11. 测试类命名 `B47a3Tests`，继承 `BattleTestBase`。

## B47a3.4 实施记录与偏差

- 副本与真实状态完全分开：`SimCopy` 才走新分支，真实 `DamageActor` 仍按事件前意志抽一次 u；副本不推进真实随机、不写真实日志、不发经验、不置提醒锁。存档结构不变，仍为 52（`SimProbe` 不进存档）。
- B47a1 的过渡口径“只读预演已濒死再受正伤按未能抵抗”撤下：以前副本里主角“死了”就停算，预计耗时、退出锁与中央条剩余都会变成截断后的值或算不出；现在完成计划照常算到结束，因此已濒死且确定受伤、恰好 5 分钟的新工作会按原规则锁定（Q682-A02），长工作身体先截止也不误锁。
- 副本里病毒到上限不尸变：以前主角尸变会让预估写“行动途中可能死亡”并停算，现在照常算完并给本人尸变句；病毒检查含完成段（世界段在完成之前结算）。到上限按引擎内部 `Zombified` 判定（内部值、原 100 与误差），不看显示取整。
- 同伴病毒速率：本批不改真实病毒规则，副本沿当前引擎。Q652（同伴无自然正增长）属 B49 尚未接入，所以现在同伴已感染且自然速率为正时也会被报尸变风险；B49 接入后预估自动跟随（Q684-A02 的“同伴自然 V 不涨”这半要等 B49）。
- 撤出预估：副本上直接调用原 `AbortExpedition`（同一扣包、惊魂、路线／倍率／T 锁定），再推原撤出行动到完成，所以“先一次即时代价、再按撤出专用身体规则逐段”与真实撤出同源。已在撤出中时不再扣包，只推剩余（确认窗此时本就打不开，只有内核数据，界面不显示，见遗留）。
- 阈值提醒“途中{属性}将越过提醒阈值，行动会暂停”只列共同截止段及以前的；`AlertsExpected` 同口径。工作倍率变化（入夜、火堆燃尽、体力跌破阈值）属完成计划，截止后也照列。
- 抵抗率取真实状态里本人当前意志等级（副本里不会因预估升级）。
- 旧测试：`BM4bRailTests.Fix_EnemyStatus_ResourceStock_RouteSource` 的源码定位从 `@foreach (var id in Stats.All)` 改为 `@if (!p.BodyCut) { @BodyRows(p) }`（身体行抽成 `BodyRows`，无危险时仍在原位置）。其余旧测试未改、全部通过。
- 本地未起网页实机看版式（启动本地服务被拒），界面只经编译与源码测试验证，版式留给试玩。
