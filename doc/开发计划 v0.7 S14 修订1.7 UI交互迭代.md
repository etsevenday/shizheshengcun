## 3 开发假设（规则解释，不含数值）

计划阶段 A1–A13：

- **A1 存档 schema 7**：From6To7 新增对话记录与等待烹饪状态；旧档 SeenDialogues 中能确认已展示的台词按配置顺序导入为一组“旧存档记录”（日期时间/地点显示“未知”），确认不了的不导入。
- **A2 一次对话**按触发事件分组（开场唤醒、首战到达、首战胜利、融合完成），对话对象取 speaker。
- **A3** 现有台词全是饱饱：主角位常驻但弱化；note 字段按“叙述”中性样式显示。
- **A4 临时形象**：主角/饱饱占位 SVG 放 `wwwroot/img/portraits/` 可直接替换；状态图标、带图指令、方位徽标缺图用统一占位。
- **A5** config 里对白 note 文案（如首战提示提到“右栏预估”）不改，列待确认。
- **A6 系统说明**8 个主题正文由开发按各主案整理，数值从配置动态取；列待确认请策划复核文案。
- **A7 左栏状态图标**一级容量按可用空间适配，危险类（出血、归零类）优先留在一级，其余进“全部状态”。
- **A8 等待烹饪“下一段燃料有效”**= 下一个 5 分钟段能完整受热，否则禁用并给原因。
- **A9 剩余时间估算**在克隆状态上只读模拟，按 5 分钟段累加，不影响真实随机/状态。
- **A10 重量**四舍五入远离零、InvariantCulture；0 克显示 0.00公斤。
- **A11** 新顶栏按钮不加快捷键。
- **A12** 区域地图节点暂不画方位徽标（策划写“如显示”），只做地块卡。
- **A13** 方向正好落在 22.5° 扇区边界时，按屏幕顺时针归下一扇区（现有数据无边界情况）。

各代理开发中补充的规则解释与偏差：

14. **（M59–M60 内核）** 点火/自用/融合开始即提交效果，“退出”只能等本段完成（返回 Deferred 如实提示）；旧档未读对白读档时展示首句、时间地点记读档时；完成前会腐败的食材不纳入等待烹饪；负重阈值文案（20/30 公斤）保持整数。
15. **（M62）** 对话等待时中央推进条并进对话层底栏（“行动名 · 对话中，时间未推进”），不在中部另叠一层；对话记录左右分栏，Esc 直接关闭整层。
16. **（M61）** 状态图标多收四类：属性归零、体力偏低、精神低落、战斗恐慌惩罚档，并按属性挂载；屏宽 <1440 顶栏不显示快捷键提示；左栏点属性在右栏开二级页。
17. **（M63）** 投木按钮小字“+60分 · 余N”；等待烹饪按钮火堆有内容即出现、无目标时禁用写原因；运行中中央条悬浮在中部，会挡住设施行中间一段；中央条保留“跳过动画”；暂停层“取消”改叫“退出”。
18. **（M64）锚定浮窗位置**：默认按“右→左→下→上”找第一个放得下的方向（换武器按“上→右→下→左”），都放不下取空间最大的一侧再限制在屏内；锚点可见不足 1/4 即视为滚出并收起。浮窗渲染在卡片之外（fixed 定位），控件阻止冒泡。
19. **（M64）就近执行覆盖范围**：除策划点名的移动/制作/建造/敌踪/战斗外，区域地图节点移动、休息/睡眠/等待、拖工具到资源卡的采集也改为卡旁/面板内开始；采集卡原本就是卡内按钮直接开始，右栏的第二个确认按钮一并移除。右栏所有详细预测保留，只读。
20. **（M64）敌踪卡**：点卡面只选中（右栏看详情），点卡上“接近 ▸”才打开卡旁预览；浮窗的“接近并开战”才接敌。
21. **（M64）方位徽标**放在相邻地图卡图片左上角 24px 圆章内（旋转箭头），点到它等同点卡面（选中路线并打开移动确认浮窗，不移动）。
22. **（M64）拖工具采集**：资源卡旁浮窗关闭（×/取消/Esc/锚点消失）时，这次拖拽打开的预览一并作废，右栏不留无法开始的预览。
23. **（M65）就近执行条**：选指令后的预览与“执行·动作·AP”固定在指令区下方（我方区内），不是浮窗；换武器才用锚定浮窗（选一把后在浮窗内执行）。
24. **（M65）执行请求号**由按钮渲染时所见的战斗状态（战斗 ID、轮次、游标、剩余 AP、日志条数）与所选指令/目标/物品决定：同一画面上的连点/双击只被内核受理一次，状态一变即是新请求。
25. **（M65）招式图**：没有专门的招式插画，用当前武器图 + 招式字角标（劈/割/刺/推/散），勉强拳击用拳图；装填用实际弹药图；医疗用真实物品图与随身数量。
26. **（M65）布局比例**：屏宽 <1440 时我方区:敌方区 1.3:1，≥1440 为 1.55:1；敌卡健康用“♥”代替“健康”二字；矮屏隐藏敌卡“甲/闪/速”行（悬停仍可见），战斗日志只留两行。
27. **（M65）目标倒下后**沿用 D2 单敌自动选中：只剩一只时自动改选它，执行条随之显示新目标（预览可见更新，不暗换后直接执行）。
28. **（M66）系统说明**：首战教学词条只在玩家已获得词条后才在“吞噬融合”条目里提及；“指令一览”列出全部战斗指令（含当前武器用不了的招式）。
