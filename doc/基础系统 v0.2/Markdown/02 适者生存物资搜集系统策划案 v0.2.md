# 适者生存物资搜集系统策划案

基础系统 v0.2   |   2026年10月21日   |   三人团队单机原型

本版采用地点卡、资源点卡和物品卡呈现末日单人生存。三份系统案共同定义“发现地点 → 移动探索 → 定向搜集 → 搬运加工 → 补给休息 → 再次出发”的基础循环，供策划与开发直接拆分任务。

本次优先级高于旧版范围案中的对应规则：暂停侵蚀、轮回、超能力、善恶值、招募和联机；同时暂不接入战斗。取消10日硬终局，改用7日生存检查目标，达成后可以继续游玩。

统一使用游戏内分钟推进时间，替换每日12行动点。配置值为本项目原型建议值，可调但不能由开发各自补定。时间与状态由基础求生案负责，地图和搜集系统通过同一行动流程调用。

## 系统目标

让玩家能预测“去哪找、能拿多少、怎样加工、是否值得搬回去”。首版采用可读的固定产出，随机性只出现在少量有明示风险的搜集动作中，不让基础水源、食物和工具依赖低概率掉落。

## 04 搜集流程与风险结算

### 自然采集与遗迹搜集

自然资源库存按实际产物件数扣减，工具加产也须多扣；库存不足时可采尽余量。一次性容器则扣1次库存，给出整组物品，不按物品件数扣库存。

选中当前地点已发现资源点 → 展示耗时、产出、工具及风险 → 校验库存和行动状态 → 预留本次库存与工具 → 按共享时钟推进 → 完成时提交库存扣减与工具磨损 → 产物先进入当前地点地面 → 结算风险并记录日志。健康归0则进入死亡，不允许继续操作。

自然资源点剩余不足额时允许采尽余量，耗时不减少，开始前必须显示实际产出。产物默认落地，玩家自行选择携带；背包不足不会取消一次已经成功完成的搜集，也不会让产物消失。

### 首版环境风险

| **动作** | **一次完成时的风险** | **是否扣产物** |
| --- | --- | --- |
| 树林采木 | 5%概率划伤，健康减3。 | 不扣产物。 |
| 村庄杂物箱 | 5%概率划伤，健康减2。 | 不扣产物。 |
| 废料场任一搜集 | 10%概率擦伤，健康减6。 | 不扣产物。 |
| 其余资源点 | 无随机伤害。 | 按正常产出。 |

不接入战斗或复杂伤口系统，只结算一次直接健康损失。风险概率只掷一次，随机结果或种子在行动开始时保存；读取存档不得重掷。资源点卡明确标出概率与伤害，风险不是隐藏惩罚。

### 取消与午夜补充

取消在下一5分钟边界生效，不给产物，不磨损工具，释放预留库存；已消耗时间和身体状态保留。补充上限按“可用库存加已预留库存”计算，防止预留动作跨午夜后释放造成超额。离开地点不停止补充。

## 05 搬运堆叠与保质规则

### 携带与地面

携带总重等于所有随身物品数量乘以单重之和；工具也计重。不额外限制槽位总数，堆叠只影响显示。总重不超过20公斤为轻装，超过20至30公斤会降低相关行动效率；超过30公斤的拾取禁止。重量先用整数克求和，界面显示公斤，避免浮点边界误差。

单次拾取可输入数量。整堆超重时不自动取一部分，提示最大可取数量供玩家确认。本地丢弃和拾取不耗时间；非当前地点物品不能远程取用。地面不设重量限制，也不自动销毁物品。

### 堆叠与消耗顺序

相同物品且保质截止时间相同的实例才自动合堆，达到堆叠上限后分为新堆。工具各占一张实例卡。界面可按同类归组，但需要展开查看各批次的新鲜度；默认食用与制造先消耗最早到期的有效批次，平手按实例ID排序。

### 保质期

易腐品在生成时记录expiresAt，按绝对游戏时间计算，携带、地面和离线地点速度一致。达到截止时标记腐败，不能食用或作配方材料，仍保留重量和卡牌，可手动丢弃。原型不实现冰箱、腐败转化物或混合保鲜。

加工必须使用新鲜原料；加工中原料预留，不冻结其保质期。若在完成前原料腐败则动作中止，原料以腐败状态返回当前地面，不生成产物。熟食保质期从成功出锅的时刻重新计算。

### 补充算例

某资源上限6，现可用1、已预留2；午夜补3后，可用量为min(6−2,1+3)=4，合计6。若随后取消，则可用量回到6；若完成则产出2，可用仍为4，不发生再次扣减。

## 06 加工执行与共享状态

### 材料与工具的查找

材料来源仅限随身与当前地点地面；同一保质批次优先随身，不跨地点取物。配方开始时预留投入物品，不能被另一操作使用。配方完成时消耗预留材料并生成产物至当前地面，设施则修改当前地点设施状态。催化工具不投入材料，也不因加工磨损。

### 持续条件

烧水和烹饪只允许在营地火堆操作，随身金属锅为催化工具。每个时间段开始前确认火堆仍在燃烧；燃料耗尽则动作暂停，已经流逝时间保留。可以在暂停界面添加燃料并点火，再继续剩余工作量；或取消并返还预留材料。熄火期间不能推进加工工作量。

火堆只在点燃后按全局流逝分钟消耗燃料；玩家移动、休息、睡眠或在别处行动时仍会燃烧。主动熄火不耗时，剩余燃料分钟保留，下次点火仍花5分钟且需打火器，不再强制投入新木材。燃料为0时才需要新木材。

### 动作打断

普通加工和设施建造支持在5分钟边界取消，已耗时间保留、预留材料返还当前地面，不生成半成品。死亡同样返还预留物至死亡地点并终止本局。成功完成后先核销材料、提交产物，再完成日志与存档；行动ID用于防重复提交。

### 物品使用

食用、饮用、使用绷带可从随身或当前地面发起，均为5分钟即时类动作：确认时扣物并立即应用效果，随后推进5分钟生存消耗，不可中途取消。绷带有60分钟角色级冷却，不能靠多张绷带叠加瞬间恢复；冷却中不允许扣物。

放入火堆的木材在投料确认时被消耗，不属于可返还的配方预留。暂停中的加工允许点火作为维护子动作，世界时间照常推进；原加工状态与预留不被覆盖，完成维护后仍由玩家选择继续或取消。
