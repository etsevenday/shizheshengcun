# 适者生存：地图清理系统策划案

版本：v0.3。配套：[开发接入与规则变更](<00 开发接入与规则变更 v0.3.md>)、[探索随机收获规则](<03 探索随机收获与完成规则策划案 v0.3.md>)。

## 1. 功能定位

在当前地点栏增加“清理”按钮。清理代表翻找、整理地块表层的零散基础物资；每地有独立次数，次数随游戏世界时间恢复。清理不增加探索度，不发现新地图、资源点或遗迹箱，也不提高安全、舒适或建筑容量。

保留三种资源获取：探索负责有限的地图推进并附带随机收获；清理负责受次数限制的随机基础收获；定向搜集负责已发现资源点的稳定产出。清理不是将地面已有物品自动捡走或删除，不对玩家摆放物资进行抽签。

参照《奇幻森林》按地块清理产生不同材料的方向，具体参考及未验证范围见00第7节。下列次数、时间和权重是本项目的首轮平衡参数。

## 3. 次数恢复算法

### 3.1 串行恢复

每个地点仅有一个恢复进度，不给每次消耗各开一个同时倒计时。次数不满时每经过intervalMinutes恢复1次；累计剩余时间继续用于恢复下一次。达到上限后清空剩余进度，不预存额外次数。

开始清理前先更新至当前世界时间，再扣1次数。该扣除立即生效，即使中途取消、死亡或随机为空，也不返还。这样不需要“预留清理次数”，也避免取消返还与恢复产生超上限问题。

使用charges、refillProgressMinutes、lastUpdatedWorldMinute计算。令elapsed=当前世界分钟−上次更新分钟：

```text
if elapsed < 0: 拒绝异常时间并报告，不产生恢复
if charges == cap:
    refillProgressMinutes = 0
else:
    total = refillProgressMinutes + elapsed
    charges = min(cap, charges + floor(total / intervalMinutes))
    refillProgressMinutes = 0 if charges == cap else total % intervalMinutes
lastUpdatedWorldMinute = 当前世界分钟
```

更新所有地点时，elapsed必须来自各自上次世界时间，不能用“本次打开界面后的时间”。允许按5分钟段实时更新，或离开地点时保存并在重新访问时补算，二者结果必须相同。清理执行的20分钟、睡眠、移动、维护都计入恢复；浏览和现实离线不计。

### 3.2 数值例子

树林08:00从4/4开始清理，立即变3/4，恢复进度0；08:20完成后进度20/240，下一次还需3小时40分。若期间不再清理，12:00回到4/4且进度清0。

若08:00扣成3/4，08:20再扣成2/4，原20分钟恢复进度不重置；12:00恢复到3/4，16:00才恢复到4/4。不是12:00两次一起恢复。

从满次数开始扣1后，5分钟取消：次数仍减少1，恢复累计5分钟，没有掉落、没有探索进度。不因取消或重新进入地点重开倒计时。

## 4. 单次行动成本

清理是clear主行动，基础工作量20分钟；无最低体力硬锁。按5分钟段使用gather身体消耗：

| 属性 | 每游戏小时变化 | 轻装、白昼、无腹泻、无阈值变化的20分钟 |
| --- | --- | --- |
| 饱食 | −1.875 | −0.625 |
| 水分 | −4.5 | −1.5 |
| 体力 | −12 | −4 |
| 清醒度 | −5 | −1.666667 |
| 精神 | −0.5 | −0.166667 |

健康无新增清理专属伤害；初版清理额外受伤概率0。饥渴归零、0体力工作伤害、腹泻等仍按基础案计算。内部保留小数，显示向下取整。

时间倍率沿用min(2.0,夜间系数×超重系数×低体力系数)。无照明夜间1.5，超过20公斤1.25，体力低于20为1.25；火堆提供当前地点照明，离开营地不能携带该照明。每段重算倍率，最后不足一段也消耗完整5分钟。

例：倍率一直1.5时，20基础分钟需30世界分钟，体力实际−6、水分−2.25；不能仍按20分钟扣身体消耗。例：倍率一直1.25时需25世界分钟。工具不改变清理时间、概率和件数，也不磨损斧头或石刀。

## 5. 八地点共享随机表

### 5.1 抽取契约

**清理与探索都引用下表，绝不各复制一份数值。** 每次成功完成行动只抽1个互斥结果，或未获得物资，或获得表内某一种物品1份。不是每行独立判定，不额外抽数量，不连抽多次，不带保底，不按探索度加权。

每表权重合计100。按表内顺序构建累积区间，从[0,100)均匀抽一个整数；命中唯一结果。比如树林顺序为未获得、木材、纤维、石块、野果，对应[0,20)、[20,50)、[50,75)、[75,90)、[90,100)。程序使用保存的PRNG，不使用系统时间或UI动画生成随机数。

| 地点 | 未获得物资 | 物品与互斥概率（每次命中均1份） | 合计 |
| --- | --- | --- | --- |
| 临时营地 | 25% | 木材25%；植物纤维30%；石块20% | 100% |
| 农野荒地 | 20% | 生块根35%；植物纤维35%；石块10% | 100% |
| 溪流浅滩 | 20% | 石块35%；植物纤维25%；草药20% | 100% |
| 树林边缘 | 20% | 木材30%；植物纤维25%；石块15%；野果10% | 100% |
| 废弃村庄 | 30% | 木材20%；布料30%；废金属20% | 100% |
| 五金店 | 30% | 废金属35%；零件15%；石块10%；布料10% | 100% |
| 诊所 | 30% | 布料45%；草药25% | 100% |
| 废料场 | 30% | 废金属40%；零件10%；石块15%；木材5% | 100% |

配置表使用物品ID：wood、fiber、stone、raw_root、herb、berry、cloth、scrap、parts；空结果用null，而不是生成“空物品卡”。

### 5.2 资源边界

上述是地表散落材料，可与原资源点的物资种类重叠，但不扣原资源池库存，不搜空遗迹箱，不直接给出原箱内整组奖励。随机拿到石块时，不改变树林石块资源点剩余4/8等数据。部分材料也会在原先无同类定向资源点的地块出现，例如营地散落石块、五金店散落布料；这是本版明确新增的零散来源，不新增资源点卡。

不随机发金属锅、简易斧、石刀、打火器、草药绷带、罐头、净水或熟块根，保留工具制作、遗迹搜集与烧水价值。溪流水仍走既有稳定取水入口，不把脏水放进随机表。药草可以在发现药草资源点前零星拾获，但不会自动发现该点。

只使用现有18种物品，不新增垃圾、昆虫、树枝或食材种类。食物/草药命中后，以**行动完成时间**生成新批次完整保质期：野果24小时、生块根72小时、草药72小时。物品默认落在当前地面，不自动入背包，超重不会吞掉产物。

## 6. 结算、暂停与取消

开始时确认次数>0且空闲，扣1次数并保存隐藏抽签。执行中显示主行动进度，按旧案低值与死亡规则处理。次数可能在执行中恢复，UI直接刷新，不回溯抵消已扣次数。

完成且存活时：有产物则创建1份当前地面物品；空结果只记“本次未找到可用物资”。两种都按完整清理消耗结算，次数不会因空结果退回。再记录本次耗时、身体变化、剩余次数和下一次恢复。

暂停保留进度与隐藏结果；补给/休息后仍由玩家明确继续。取消不产物、不退次数、不恢复已花时间。死亡前未完成的清理不产物；若行动正常完成后因其后事件死亡，则保留已提交地面产物。边界优先级以00第4节为准。

## 7. UI与文案

当前地点卡增加独立清理行，位置在探索按钮附近，不藏在背包整理按钮里。

```text
树林边缘  探索75%
[探索周边 · 30分钟]  有机会发现路线并取得零散物资
[清理 · 20分钟]      次数3/4 · 距恢复1次3小时40分
```

0次时显示“清理0/4”，禁用开始，仍可点详情查看原因与恢复说明；满次数显示“4/4·已满”，不显示会继续积攒的倒计时。100%探索时探索按钮禁用，清理继续显示。

清理预览包含：本次扣1次数、基础与预计时间、预计完成时刻、五项身体变化、空结果概率、可能物品和各自概率、产物留地面。落地结果卡可继续通过拖拽拾取或使用。身体危险、单主行动占用与所在地不符均显示具体原因。

清理中不显示已经锁定的具体掉落，只显示“正在整理地块”。完成提示分别为“清理完成：木材+1，已放在树林边缘地面”或“清理完成：本次未找到可用物资；已消耗1次清理机会”。日志不能把空结果叫程序失败。

## 8. 平衡基线与观察项

下列是理论期望，不是每次保证；按白昼轻装20分钟，不计赶路、休息及恢复限制。

| 地点组 | 每次期望件数 | 短时连续清理的理论每小时件数 |
| --- | --- | --- |
| 营地 | 0.75 | 2.25 |
| 荒地、溪流、树林 | 0.80 | 2.40 |
| 村庄、五金店、诊所、废料场 | 0.70 | 2.10 |

树林清理平均每小时0.9木材，低于无工具定向采木2木材/小时及有斧4木材/小时；荒地清理平均每小时1.05生块根，低于定向挖块根4份/小时。因此清理提供杂项补充，不应取代定向采集。

重复来源使石块、废金属、零件等从“仅靠有限定向库存”变为“额外少量可再生散落来源”，这是本版明确的经济变化。罐头、成品工具和药品仍不由随机清理再生。首轮试玩记录各地使用次数、空手次数、物品产量、停留时间及玩家是否忽略原资源点，再调整概率和恢复间隔，不在代码里另加隐藏保底。
