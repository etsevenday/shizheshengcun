# 适者生存：卡片拖拽交互与容器策划案

版本：v0.3。配套：[开发接入与规则变更](<00 开发接入与规则变更 v0.3.md>)。

## 1. 目标与范围

卡片是玩家操作对象的基础单位。物品、资源点、设施和地点都使用卡片表达；卡片外观相似不代表它们都可拾取。例如地点、固定火堆和资源点不能被装入背包，金属锅与简易斧可以。

玩家能够拖动卡片整理位置，跨地面与随身区域转移，把木材投进火堆，把水倒进锅中，把工具或原料拖到适当卡片上发起交互。点击详情与拖拽必须调用同一条玩法指令，成本、校验和结果一致。只实现明确列出的组合，不推断任意两张卡都能合成。

参考原作的卡片组合交互方向；容量、配方触发方式和本文参数是项目自身设计，参见00的参考依据。

## 2. 卡片与存放区域

| 类型 | 本项目对象 | 可以拖动到哪里 |
| --- | --- | --- |
| 普通物品 | 木材、石块、纤维、布料、草药、食物、废金属、零件、绷带 | 地面、随身、同类堆或适配交互目标 |
| 工具 | 石刀、简易斧、打火器 | 地面、随身、适配资源点或火堆 |
| 液体单位 | 净水、脏水；每份500毫升/500克 | 地面、随身、金属锅的装水区 |
| 容器 | 每个独立实例的金属锅 | 地面、随身、营地火堆的锅位 |
| 固定对象 | 地点、资源点、火堆、遮蔽棚、床垫 | 只允许在所属展示区内调整顺序；不能改变世界归属 |
| 配方卡 | 石刀、斧、绷带、棚、床垫及加工预览 | 是交互入口与材料引用，不能成为背包物品 |

随身区是角色实际携带；地面区始终属于当前地点。卡片排列顺序不影响体力、时间或重量。地图切换后保留各地点自己的地面排列；其他地点地面不得成为当前拖拽来源或目标。

沿用按区域有序排列、自动吸附的卡片桌面，不引入无限自由坐标画布或物理碰撞。将卡拖到同区空白插入线可放到指定顺序；新产物默认追加在地面区尾部并高亮，不打乱手工排序。筛选状态下按可见卡间的插入线更新其在完整列表中的顺序，未显示卡的相对顺序保持；自动排序是显式按钮，不持续覆盖手动排列。

## 3. 拖拽操作规范

### 3.1 起拖、数量与落点

- 左键按住移动超过6px起拖；不足6px松手视为普通点击。触发起拖后本次松手不再触发点击。
- 拖动时只生成影像与预览，源卡尚不扣物；显示名称、可能转移数量与来源。工具和锅始终按一个实例处理。
- 同区空白排序移动整张堆卡，不拆分。跨区转移、同类合堆、投料与装水默认1份；按住Shift松手打开数量框，范围由源可用量、容量、堆叠与负重共同决定。
- 数量框先显示可行上限，不静默截断玩家已确认的数量。取消数量框等于取消本次拖拽。
- 数量框、危险弹窗或菜单打开时，背后卡片不能接收拖拽。拖至窗口外、按Esc或失焦回到原处，不扣物不耗时。
- 嵌套目标优先取光标所在的明确热区：锅的装水区、火堆燃料区、配方材料槽、容器取出区；随后才是普通卡面；最后是区域空白插入线。被覆盖的底层卡不接收落下事件。

### 3.2 高亮与反馈

合法即时目标显示绿色描边加动词，如“投放1木材，燃料+60分钟”；合法行动入口显示琥珀描边加“查看采集/制作”；非法目标显示禁止符号与具体原因。仅变色不足以说明语义。

放下后按三类处理：同区排序立即生效；合法转移、装水、投料立即原子提交；耗时交互打开行动预览，玩家按“开始”后才开始计时。一次拖拽不会静默启动耗时制造或自动串行多次行动。当前主行动暂停时，允许的补给和点火维护也先显示其预览。

## 4. 交互白名单

| 来源 → 目标 | 松手结果 | 消耗与约束 |
| --- | --- | --- |
| 同区卡 → 空白插入线 | 调整卡片顺序 | 不耗时，不改变归属 |
| 地面物品 → 随身区；反向亦然 | 转移默认1份，Shift选数量 | 不耗时；超过30公斤拒绝整次操作 |
| 同类物品 → 同类卡 | 合堆；跨区先转移再合堆 | 仅同物品、同到期时间、同所有权目标；按stackMax分堆 |
| 木材 → 当前营地火堆燃料区 | 扣1木材，燃料+60分钟 | 不耗时，不自动点火；不可超过240分钟 |
| 打火器 → 当前营地火堆 | 打开点火预览 | 5分钟、craft身体消耗；需至少5分钟燃料；打火器不消耗 |
| 水卡 → 金属锅装水区 | 转移1份到锅，水量增加50% | 不耗时；满锅、异种液体、锅被锁定时拒绝 |
| 锅内水子卡 → 当前地面/随身区 | 倒出1份成为对应水卡 | 不耗时；随身目标校验总重；原锅内容减少 |
| 金属锅 → 当前营地火堆锅位 | 放置/关联锅；显示烧水或烹饪入口 | 放置不耗时，不自动加工；每火堆一个锅位 |
| 简易斧 → 已发现的可采木材资源卡 | 打开采木预览，绑定该斧 | 成功产量2、30基础分钟、耐久−1；资源不足可只产1 |
| 石刀 → 已发现的纤维资源卡 | 打开采纤维预览，绑定该刀 | 产量2、10基础分钟、耐久−1 |
| 合法原料 → 另一原料/配方材料槽 | 打开候选配方与缺料说明 | 未确认开始不扣物、不耗时、不正式预留 |
| 可用食物/水/绷带 → 角色状态卡 | 打开使用预览 | 依原即时使用规则，确认扣1并应用效果后耗5分钟 |

角色状态卡是HUD旁的小型“自身”投放目标，不将任意一条数值条当作可投放槽。锅内水也可通过子卡拖向自身饮用，按1份结算并锁定来源。脏水先显示腹泻12小时后果；腐败食物、生块根、草药不能以此入口直接服用。

未列入白名单的组合返回“暂不支持此组合”，原卡不动。废金属和零件本版只能整理/转移，不新增高级合成；食物放火堆不等于直接燃烧；净水或脏水放火堆不灭火；不新增净脏水混合、纤维燃料、磨损工具修理或容器嵌套。

## 5. 拖拽合成与七条配方

两张材料卡相叠只是查找候选配方；多配方同时匹配时按配置顺序列出，不能自行挑一个立即消耗。例如石块拖到纤维上会展示石刀和简易斧候选，缺少材料的仍列出但开始禁用。之后可把其他原料拖入配方槽，也可点击自动补齐。

材料槽保存实例与数量引用，不改变物品所有者。选择配方后自动从随身和当前地面补齐，先最早到期有效批次，再按实例ID；手工拖入优先使用指定批次。预览期间物品仍可移动；一旦引用失效即刷新，不继续沿用旧数量。确认开始时再次校验并正式预留。

| 配方 | 材料与基础工作分钟 | 拖拽入口与完成位置 |
| --- | --- | --- |
| 石刀 | 石块1、纤维1；30 | 原料组合/配方；工具在当前地面 |
| 简易斧 | 石块2、木材1、纤维2；60 | 原料组合/配方；工具在当前地面 |
| 草药绷带 | 布料1、草药1；15 | 原料组合/配方；绷带在当前地面 |
| 烧水 | 指定锅内脏水2；15 | 满脏水锅拖到火堆/点击烧水；净水留在原锅 |
| 烹饪块根 | 生块根2；30，空金属锅 | 生块根拖到空锅；材料用配方引用，不成为长期储物内容；熟块根在当前地面 |
| 遮蔽棚 | 木材4、纤维4；120 | 原料拖至营地地点卡/配方；营地设施状态变更 |
| 床垫 | 纤维4、布料2；60，已有棚 | 原料拖到棚卡/配方；营地设施状态变更 |

烧水和烹饪仅营地燃烧火堆可执行。锅可以在当前地面或随身；同一锅只能被一个行动占用。按钮入口对空锅烧水，可在确认时原子转移当前可用的2份脏水入指定空锅并启动；若锅已有1份脏水，只补1份；缺水则不转移也不启动。锅有净水时禁止覆盖或替换。此入口与手工装水最终调用同一流程，不生成“虚拟锅水”。

打火器拖到火堆可来自当前地面或随身，执行期间锁定其工具实例。普通资源按钮继续自动用随身最高耐久工具；显式拖入的刀斧必须已在随身，若在地面则提示“先拾取工具”。显式工具失效不暗中换另一把，要求重新确认预览。

## 6. 金属锅内容与水量

### 6.1 容量与状态

首版每锅容量1000毫升，只接受500毫升整数份；最多2份。空锅0%，1份50%，2份100%。存储为整数毫升或等价整数份数；显示同时提供“脏水50%·500/1000毫升”，避免玩家把50理解为饮水效果。

同一锅只允许一种水：空、脏水或净水。不能混装两种水；提示先倒出/饮用已有水。不做部分毫升、污染浓度、蒸发、温度、自动降温或过量倾倒。锅内没有物理固体库存；烹饪原料由行动预留表达，烹饪时装水禁用。

容器总重=锅1000克+内容物每份500克。随身空锅1公斤，半锅1.5公斤，满锅2公斤；地面水倒进随身锅会增加携带重量，随身水倒进随身锅总重不变。移动满锅按2公斤校验，不能只算锅壳。

### 6.2 放到火堆与烧水

将随身锅拖至营地火堆锅位时，原子转移锅及内容到营地地面并关联火堆；地面锅只新增关联。卡片采用附着视图，不复制第二张实体锅。火堆一个锅位，已有其他锅时拒绝且提示先取下。取下或拾取未被锁定的锅会解除关联，锅内水一同移动。

必须脏水100%才允许现行烧水配方；50%时显示“再加入1份脏水，凑满1升”。不新增半锅烧水时长。点击开始后锁定锅与2份脏水，工作15基础分钟；水量一直100%，另显示加工进度0%→100%。成功在原锅内将脏水2变净水2，总体积与重量不变，不额外生成地面净水。

锅位是直观入口，不额外增加制作时间；普通按钮可绑定同地未占用锅而不强制先拖入锅位，锅位已有锅时默认选它。直接绑定的随身锅在完成后仍随身，不能悄悄放到地面；附着火堆的锅保持地面归属。

火灭暂停：保留锅内脏水与工作进度，只开放木材投料、打火器维护和原规则允许的补给。不能移动锅、取水、加水或将同锅用来烹饪。取消或死亡：解除预留，脏水仍留原锅，不复制到地面；进度清零，重新烧水重新计15分钟。其他加工取消按v0.2返还材料至当前地面。

## 7. 木材投料的容量边界

每木材必须完整提供60分钟，不静默丢弃超出的燃料。最大可投数量=min(可用木材数, floor((240−当前燃料分钟)/60))。燃料190时连1份都放不下，提示“至少需要60分钟空余容量”；燃料180可加1份正好240。已有剩余燃料可直接点火，不强迫先加木材。

成功投料立即扣木材并保存，不属于可退配方预留。取消原加工不会返还已烧进火堆的木材。火堆水量/燃料条绝不使用同一标签。

## 8. 忙碌、预留与防重复

| 游戏状态 | 排序 | 实体转移/装水 | 耗时交互 |
| --- | --- | --- | --- |
| 无主行动 | 允许 | 校验后允许 | 开预览，明确开始 |
| 主行动执行中 | 允许纯UI排序 | 禁止；不在段中改变重量或材料 | 禁止另起行动 |
| 主行动暂停 | 允许 | 仅维护投料等白名单；其他实体转移禁止 | 仅允许补给、休息、点火维护 |
| 子行动中 | 允许纯UI排序 | 禁止 | 禁止再嵌套新行动 |
| 死亡/最高层弹窗 | 禁止拖拽 | 禁止 | 只接收最高层规定输入 |

正式预留的物品不可转移、合堆、投料或使用；允许在列表中排序但不能改变其所有者。由玩法层校验所有权、数量、容量、锁、所在地和负重，通过后一次提交。源扣减与目标增加必须同时成功；失败回原位。确认携带31公斤时拒绝整次转移，而不是自动只拿部分。

确认按钮自动补水同样校验最终携带总重：地面脏水补入随身锅可能超重，此时整次补水与开始都拒绝，提示可先把锅放到地面；不能以“制作预处理”绕过30公斤限制。已到背包中的水在锅内外转移只计净重量变化。

所有容器内容拥有唯一owner=containerId；火堆锅位只是关联，不再拥有锅的副本。数量、预留、到期和耐久继承原实例规则。转移和合堆不刷新食物寿命，不叠加工具耐久。

## 9. 数据与UI交付

程序最少需要：DropRequest(sourceId,targetId,verb,quantity,requestId)，校验结果及原因；容器实例、内容子物品、锅位关联、锁定行动；每区顺序列表。requestId用于幂等，重发同一请求不能重复加燃料或转移水。具体类名可由程序调整，但不能省略语义。

新增UI：插入线、拖动影像、合法/非法落点、数量框、配方候选层、锅内容展开层、燃料/水量/加工三种独立标签，以及“先拾取”“满锅”“混装禁止”“行动占用”反馈。点击按钮保留等价操作，避免拖拽成为唯一无提示入口。

示例流程：木材拖火堆（0→60分钟燃料）→打火器拖火堆并确认（5分钟后燃料55）→两份脏水分别拖空锅（0→50→100%）→锅拖火堆→确认烧水（15基础分钟）→完成后锅显示“净水100%”，展开可饮用或倒出。
