# 适者生存：探索随机收获与完成规则策划案

版本：v0.3。配套：[开发接入与规则变更](<00 开发接入与规则变更 v0.3.md>)、[清理及共享掉落表](<02 地图清理系统策划案 v0.3.md>)。

## 1. 修改目标

探索原有的地图发现与25%进度机制保留，但每次有效完成增加一次当前地块的随机物资抽取。探索可能只推进进度而没有物资；探索达到100%后永久停止该地探索，玩家后续依靠清理与定向搜集获取资源。

这是对旧案“探索不直接产物”的明确替换，不将旧UI“不获得物品”的提示继续保留。“探索完成”指探索度100%；单次行动完成且进度尚未满，仍能继续探索。

## 2. 行动规则

| 项目 | v0.3规则 |
| --- | --- |
| 起点条件 | 当前所在地、已访问、progress<100、无其他主行动 |
| 单次基础工作量 | 30分钟，5分钟结算段，工作时间倍率沿用原案 |
| 探索度 | 有效完成增加25，上限100；仅接受0/25/50/75/100合法进度 |
| 发现 | 保留原里程碑、路线和资源点解锁 |
| 随机收获 | 每次完成1次抽签，完全引用当前地块清理的同一lootTableId |
| 清理次数 | 不扣除、不要求大于0；探索有限次，清理可恢复 |
| 工具 | 不提升掉落率/件数，不降低耗时，不扣工具耐久 |
| 产物位置 | 当前地面，不自动入随身，不直接入锅 |
| 到100%后 | 探索按钮禁用，显示已充分探索；跨日、清理和离开不恢复 |

正常新局除营地外每个地点最多4次有效探索。营地初始100%，不能为了掉落新增营地探索机会，但可清理。已探索75%的旧档只剩一次；升级不把所有地点进度重置以补随机物品。

## 3. 概率与随机结果

随机表以02第5节和整合配置的lootTables为唯一来源。探索与清理只因自身工作量和进度/次数成本不同产生效率差异，概率与命中件数没有区别。

例如树林：未获得20%、木材1份30%、纤维1份25%、石块1份15%、野果1份10%。每次只产生其中一个结果；不是同时判五个独立概率，也没有“探索更稀有”的第二张表。r=90命中野果的规则与清理相同。

探索开始时锁定该次隐藏结果和配置版本并保存，完成时才显示。空结果也推进25探索度、触发里程碑并消耗完整时间。读取同一活动探索不重抽，打开详情或改变卡片顺序不重抽。低值暂停后的子行动不得覆盖原探索的随机计划。

有物资时以完成时刻生成新实例及相应保质期；重量、堆叠、到期与地面归属遵循物资案和拖拽案。一次探索只生成一份随机物品，不再额外发放同一里程碑的“物资礼包”。

## 4. 里程碑与掉落的关系

里程碑决定发现，随机表决定零散物品，两条通道相互独立。发现资源点不直接增加资源点库存：首次发现时读取该点已有世界状态，后续再发现不能重置它。拾到野果也不会自动解锁野果丛或其他地图。

| 地点 | 25% | 50% | 75% | 100% |
| --- | --- | --- | --- | --- |
| 临时营地 | — | — | — | 初始充分探索，不能探索 |
| 农野荒地 | 溪流路线 | 树林路线 | 无新发现 | 村庄路线 |
| 溪流浅滩 | 无新发现 | 草药资源点 | 无新发现 | 无新发现 |
| 树林边缘 | 木材资源点 | 石块资源点 | 野果与纤维资源点 | 废料场路线 |
| 废弃村庄 | 补给箱 | 五金店路线 | 杂物箱 | 诊所路线 |
| 五金店 | 无新发现 | 锅具箱 | 工具箱 | 废料场路线 |
| 诊所 | 药柜 | 布料包 | 无新发现 | 无新发现 |
| 废料场 | 金属堆 | 零件箱 | 无新发现 | 通往树林路线 |

上表不修改原路线耗时或双向连接；地点ID沿用camp、field、stream、woods、village、hardware、clinic、scrapyard。农野荒地初始块根与纤维、溪流初始水源仍按原案入场可见。

示例1：树林0→25，抽中野果1。完成后同时发现木材资源点、地面生成野果1；野果丛依旧要到75%才显示。允许零星物资早于对应集中资源点出现，这是本次新增玩法。

示例2：农野荒地50→75，抽空。探索度仍到75，日志写“未发现新线索；本次未找到可用物资”。“无新里程碑”和“抽空”是两个分别记录的结果，不等于行动失败。

示例3：树林75→100，解锁废料场，随机生成木材1；结果显示后探索按钮立即禁用。不能因为本次还有物品奖励再自动触发一轮探索。

## 5. 消耗、暂停与取消

沿用explore每小时饱食−1.875、水分−4.5、体力−10、清醒度−5、精神−0.5。白昼轻装且状态不跨阈值时，30分钟分别为−0.9375、−2.25、−5、−2.5、−0.25。夜间、超重和低体力按原公式影响实际世界耗时，身体消耗依据真实流逝时间，不按基础30分钟固定扣。

探索无新增专属划伤概率，不套用定向采木或废料搜集的受伤概率。饥渴归零、低值提醒、0体力工作伤害、腹泻与死亡仍有效。

低值暂停保存进度、隐藏随机结果和原探索起始进度；补给后明确继续。取消不增加进度、不解锁里程碑、不产出随机物品，已经流逝的世界时间和身体消耗保留。重启后的新探索重新按完整30基础分钟开始，不能保留被取消的工作量。

遵循00的统一事务：完成边界先判生存和持续条件，再原子提交进度、发现、随机物品、日志；恰好完成时出现普通低值提示的，行动已完成，不再保留可重复领取的暂停行动。死亡先于提交则都不给。

## 6. UI改动

主地点栏沿用探索进度条，探索与清理相邻、各自独立：

```text
树林边缘  露天 · 探索度75% · 白昼
[探索周边 · 30分钟]            [清理 · 20分钟]  详情
 完成后100% · 有机会取得零散物资   次数3/4 · 距恢复1次3小时40分
```

【实现同步】两个按钮并排在地点行右上并直接开始；探索副文案为“完成后N% · 有机会取得零散物资”，右栏说明“探索推进地块调查，并有机会取得零散物资；探索度达到100%后不再探索”。探索预览的“可能新线索”只在结果中以“发现…”出现，预览不列名称。

探索预览显示当前→目标进度、基础与预计世界时间、身体消耗、可能新线索、物资概率表、未获得概率和产物留地面说明。未知的路线/资源点只显示“可能发现新线索”，不提前泄露其名称。

旧文案“探索只负责发现，不获得物资”替换为“探索推进地块调查，并有机会取得零散物资”。完成结果分三行：探索度变化、实际发现、实际物品；不要把地面野果写成“发现野果丛”。

100%状态显示“已充分探索”，禁用探索并说明“该地点不再探索，可清理或搜集已发现资源”。即使清理次数0，也不能让探索作为无限替代入口。按快捷键、拖工具至地点卡或重复发送旧确认请求都必须再次检查progress<100。

工具拖至地点卡不触发探索附加收益；工具拖至具体已发现资源点才走定向搜集。拖动已获得物品继续使用01中的统一转移、投料和容器规则。

## 7. 数据与配置校验

地点使用同一个lootTableId供clear与explore读取；不要复制出exploreLoot概率。Action中保存type=explore、locationId、startProgress、targetProgress、workDone、lootPlan和lootTableVersion。结果提交用actionId幂等；进度、里程碑、物品不能分别重放。【实现同步】targetProgress 由 startProgress + 25 推导，不单独保存；lootPlan 存为 LootPlanned / LootRoll / LootItemId / LootCount；配置校验在 ConfigLoader，失败阻止启动而不是只阻止该行动。

配置加载时检查：全部地点有共享掉落表；权重非负整数且合计100；物品ID存在、数量均1；progress为合法阶段；空结果不带物品；探索目标不超过100。错误配置应阻止启动相关行动并报告，不静默改概率或丢产物。

存档迁移和旧活动探索兼容以00第5节为准。开发调参对已开始行动不追溯修改，仍执行其已保存计划；只有新行动读取新配置。
