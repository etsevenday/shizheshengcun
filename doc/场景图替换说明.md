# 场景图替换说明

2026年10月23日 ｜ 适用于 B 方案地点行（试玩留言 8f9a7c9b 第 3 点）

地点行改为 B 方案后，每个地点有一张场景图铺满整行，资源点卡叠在下方。现在用的是按 UI 预览稿画风生成的矢量占位图，美术图准备好后可以直接替换，不用改代码。

文件都在 `web/Survival.Web/wwwroot/scenes/`，由 `tools/gen_scenes.py` 生成。想微调占位图，改脚本后运行 `python tools/gen_scenes.py` 即可。

## 换成美术图

1. 把图片放进 `web/Survival.Web/wwwroot/scenes/`，例如 `woods.webp`。
2. 打开 `data/config.v0.3.json`，把对应地点的 `scene` 改成新文件，例如 `"scene": "scenes/woods.webp"`。
3. 推送后自动发布。

## 出图规格

| 项目 | 要求 |
| --- | --- |
| 比例与尺寸 | 1200×650 的比例，建议导出 2400×1300；webp 或 jpg，单张建议不超过 400KB |
| 显示方式 | 铺满并居中裁切。地点行是宽而矮的横幅，通常只露出中间一条，约为 y=150 到 y=500 |
| 安全区 | 主体放在 y=200 到 y=380 之间、左右各留 80 像素。下方约三分之一会被资源卡盖住，左上角放地点名与路线标签，右上角放“探索周边”按钮 |
| 光照 | 画白天的状态即可。清晨、黄昏、夜间由游戏统一压暗与调色，夜空星点也由游戏叠加 |
| 火堆 | 营地图不要画火焰，只画熄灭的火堆。燃烧时游戏会在配置里的 `sceneFireX`、`sceneFireY`（1200×650 坐标）叠加火焰与火光；换图后把这两个数改成新图里火堆中心的位置 |
| 文字 | 不要在图里写字，地点名与数值都由程序绘制 |
