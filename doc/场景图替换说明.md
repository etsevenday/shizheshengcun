# 场景图替换说明

2026年10月23日 ｜ 【实现同步 2026-10-26】适用于基础UI布局与操作修订案 v0.7 的两行地块栏

v0.7 起地块区整块的弱化背景与暗层已经取消，每个地点的一张场景图只用在第一行“地图与场景”的地图卡上：

1. 当前地图大图卡：固定在第一行最左，宽约占该行的六成，场景图铺满整张卡（1280×720 下约 410×158 像素，1600×900 下约 590×200 像素），
   昼夜调色、夜空星点与营地火光叠加都在这张卡里。地名、室内外与昼夜放在左上、右上两个小衬底上，探索度与探索/清理按钮放在底部一条渐变衬底上。
2. 相邻地图卡：第一行右侧可横滚的普通地图卡，上方图片区约 146×70～100 像素。

两种卡都按“铺满、横向居中、纵向约 60% 处”裁切。

现在用的是按 UI 预览稿画风生成的矢量占位图，美术图准备好后可以直接替换，不用改代码。

## 换成美术图

1. 把图片放进 `web/Survival.Web/wwwroot/scenes/`，例如 `woods.webp`。
2. 打开 `data/config.v0.6.json`（配置已随人物与战斗 v0.6 改名，见开发计划 v0.5），把对应地点的 `scene` 改成新文件，例如 `"scene": "scenes/woods.webp"`。
3. 推送后自动发布。

## 出图规格

| 项目 | 要求 |
| --- | --- |
| 比例与尺寸 | 1200×650 的比例，建议导出 2400×1300；webp 或 jpg，单张建议不超过 400KB |
| 显示方式 | 当前地图大图卡：整幅宽度都可见，纵向露出约 y=110 到 y=570（1280×720）或 y=150 到 y=550（1600×900）；左上角、右上角各有一个约 30 像素高的小衬底，底部约三分之一是由透明渐变到半透明的按钮衬底。相邻地图卡：横向露出中间约 x=110 到 x=1090，纵向约 y=60 到 y=600 |
| 安全区 | 地点的辨识主体（窝棚、溪流、货架等）放在 x=300 到 x=900、y=200 到 y=430 之间：这块在当前地图大图卡里不被任何衬底挡住，在相邻地图卡里也完整可见。画面底部 y=450 以下会被按钮衬底半遮，左上、右上角会被地名与昼夜衬底遮住，这些位置只放地面、天空等氛围元素。地点名、探索度、按钮都由卡片绘制，不需要在图里留位置 |
| 光照 | 画白天的状态即可。清晨、黄昏、夜间由游戏统一压暗与调色，夜空星点也由游戏叠加 |
| 火堆 | 营地图不要画火焰，只画熄灭的火堆。燃烧时游戏会在配置里的 `sceneFireX`、`sceneFireY`（1200×650 坐标）叠加火光；火堆本身另有独立的火堆卡（燃烧/熄灭两态图在 Services/Icons.cs 的 fire_lit、fire_out），不靠场景图表现 |
| 文字 | 不要在图里写字，地点名与数值都由程序绘制 |

## 昼夜变化

| 时段 | 游戏时刻 | 画面 |
| --- | --- | --- |
| 夜间 | 19:30–04:30 | 亮度约四成、偏蓝、出现星空；营地火堆燃烧时火光明显 |
| 清晨 | 04:30–07:30 | 由暗转亮，带暖色 |
| 白昼 | 07:30–16:30 | 原图 |
| 黄昏 | 16:30–19:30 | 偏橙，逐渐变暗 |

室内地点（五金店、诊所）变化更柔和，不显示星空。时段只影响画面，规则上的昼夜仍以 06:00–18:00 为准。
