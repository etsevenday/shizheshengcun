# 场景图替换说明

2026年10月23日 ｜ 【实现同步 2026-10-24】适用于 v0.4 地块卡片桌面

每个地点的一张场景图现在有两个用途（卡片统一与设施烹饪 v0.4 · 01 案）：

1. 地块区的弱化背景：铺满整个地块区，透明度约四成，上面铺满当前地图卡、相邻地图卡、火堆卡、设施卡与资源卡，昼夜调色与营地火光照旧。
2. 地图卡的主图：当前地图卡左侧约 120×190 像素、相邻地图卡上方约 146×70 像素，按“铺满、横向居中、纵向约 60% 处”裁切。

现在用的是按 UI 预览稿画风生成的矢量占位图，美术图准备好后可以直接替换，不用改代码。

## 换成美术图

1. 把图片放进 `web/Survival.Web/wwwroot/scenes/`，例如 `woods.webp`。
2. 打开 `data/config.v0.4.json`（配置已随交互与地图扩展 v0.3 改名），把对应地点的 `scene` 改成新文件，例如 `"scene": "scenes/woods.webp"`。
3. 推送后自动发布。

## 出图规格

| 项目 | 要求 |
| --- | --- |
| 比例与尺寸 | 1200×650 的比例，建议导出 2400×1300；webp 或 jpg，单张建议不超过 400KB |
| 显示方式 | 背景：铺满并居中裁切，几乎全部被卡片盖住，只透出色调与轮廓。地图卡：铺满小框，横向居中、纵向取 60% 处，相邻地图卡只露出约 y=250 到 y=520 的一条，当前地图卡露出中间约 40% 宽的竖条 |
| 安全区 | 地点的辨识主体（窝棚、溪流、货架等）放在画面正中 x=480 到 x=720、y=280 到 y=480 之间，这块在两种地图卡里都能看到；四周只放氛围元素。地点名、探索度、按钮都由卡片绘制，不需要在图里留位置 |
| 光照 | 画白天的状态即可。清晨、黄昏、夜间由游戏统一压暗与调色，夜空星点也由游戏叠加 |
| 火堆 | 营地图不要画火焰，只画熄灭的火堆。燃烧时游戏会在配置里的 `sceneFireX`、`sceneFireY`（1200×650 坐标）叠加火光；火堆本身另有独立的火堆卡（燃烧/熄灭两态图在 Services/Icons.cs 的 fire_lit、fire_out），不靠场景图表现 |
| 文字 | 不要在图里写字，地点名与数值都由程序绘制 |

## 昼夜变化

| 时段 | 游戏时刻 | 画面 |
| --- | --- | --- |
| 夜间 | 19:30–04:30 | 亮度约四成、偏蓝、出现星空；营地火堆燃烧时火光明显 |
| 清晨 | 04:30–07:30 | 由暗转亮，带暖色 |
| 白昼 | 07:30–16:30 | 原图 |
| 黄昏 | 16:30–19:30 | 偏橙，逐渐变暗 |

室内地点（五金店、诊所）变化更柔和，不显示星空。时段只影响画面，规则上的昼夜仍以 06:00–18:00 为准。
