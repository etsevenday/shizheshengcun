## 实现范围

主界面整体换为废土墨线、旧纸卡牌、冷暗面板与赭金行动按钮。8 个场景、5 张透明图集（80 图位）覆盖 46 个配置物品及资源/设施/敌人；HUD 使用 8 个矢量图标。场景、物品、预览共享映射。导航、菜单、浮窗、对白与战斗沿用原布局和交互，继承公共配色。

720p 下采用紧凑横向物品卡与两列锅内容，1080p 保留竖向插画卡。转移箭头实际尺寸为 40×40；名称正文至少 16px，辅助信息至少 14px。锅的长预留说明保留在 title 与对象详情；空槽短文案改为“食材 N/2 · 拖入食材”，完整可放入物品说明保留在 title。水量的种类/百分比与毫升分行，数值仍由原状态计算。

没有改动内核、配置、存档结构、行动结算、Q14–Q22 问题与回答、AGENTS.md 或任何“Codex 供策划使用”的说明。仅有上述卡片文案排版调整。

## 修复与复验记录

1. 初版图集在非正方形卡内露出相邻图位：改为内层 SVG viewport 并显式 overflow:hidden；重跑全部截图与拖拽。
2. 原全局 SVG 最小高度挤掉资源按钮：插画改为在图片区内绝对定位；资源卡限定行内高度，长辅助说明在原 title/详情保留。
3. 720p 的锅原排版挤掉食材区：标题/水量并排，液体/食材分列，长预留说明单行加 title；提高设施行占比并保持四区同屏。
4. CSS 背景中的相对场景路径被按 css 目录解析：页面根部 custom property 使用 NavigationManager.ToAbsoluteUri；移动浮窗也使用统一新场景映射。
5. 第一次自动化报告保留在 runtime-results-first.json：3组失败来自脚本未先关结果提示、未等首战AP就绪、request.get传入URL对象。改为真实关闭提示、等状态就绪和字符串URL后，9组全部复验通过；没有用强制点击跳过遮挡。
