## 七项精修的实现

| 项目 | 实现与目视检查 |
| --- | --- |
| 1. 做旧边框 | 暗框、纸框、主操作框使用 SVG 九宫格；不规则外轮廓、断线、露底与磨损角。大面板和小按钮分别使用 5–12px 角部尺度；携重/设施/随身及交替纸卡使用固定变体。原边框不再作为完整亮色矩形叠在材质下。 |
| 2. 旧纸底材 | 增加边缘发黄、局部污渍与克制纤维，中心留出清楚文字区；没有对文字本身叠加污损。 |
| 3. 按钮、标签和选中 | 主行动保留赭黄纸面，次级行动为暗框，数量/访问状态为浅纸签；选中资源标题用墨刷底，局部金边。默认、悬停、键盘焦点、按下、禁用、搜空均有截图。 |
| 4. 插画比例 | 资源和物品按类别放大外层 SVG 12% 左右，锅具箱 20%、工具箱 16%；只改变视口显示，不改变图集源坐标和嵌套裁切。三档截图检查无串格、拉伸、按钮被挤掉。 |
| 5. 携重和属性图标 | 携重改用可缩放的既有背包图集视口，增大且提亮；属性图标略增大、加重轮廓，并给心形/水滴/盾牌少量填色。低属性状态颜色保留。 |
| 6. 字体和层级 | 标题、卡名统一沿用现有宋体/衬线回退链；数字保留等宽数字特性。普通暗框压低亮度，亮金留给选中和主操作。没有新增字体下载。 |
| 7. 进度条和场景融合 | 给轨道、填充加轻微材质和阴影，保留真实宽度和阈值位置；地图、设施、地面、随身和右栏用不同背景位置/蒙版，减弱同一亮窗或墙角的机械重复。 |

没有修改场景原图、图集原图、玩法配置、存档协议、交互代码、Q14–Q22 的答复、AGENTS.md 或原有角色分工描述。已有 v0.8 验收资料保留。
