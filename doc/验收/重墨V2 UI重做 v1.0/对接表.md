## 渲染

- 精灵用内嵌 SVG：外层 `viewBox` 等于清单裁窗，内层 `<image>` 按图集原尺寸放置。浏览器只下载实际显示的图集。
- 全部位图最近邻（Q840 B）：`wwwroot/css/app.css` 根上 `:root { image-rendering: pixelated; }`，继承到 `<img>`、SVG `<image>` 和 CSS 背景图。全站没有别处把它改回平滑（测试 `M4_NearestNeighborRule` 锁定）。
