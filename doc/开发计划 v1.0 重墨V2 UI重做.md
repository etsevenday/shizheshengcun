### B31a.3 开发假设（只涉代码结构、命名、像素与动画）

1. 字体与素材从 a9b93f0 原样导出，不改名、不子集化（Q275 修改或子集化须遵照授权，本批不做）。字体文件放 `wwwroot/fonts/`（sha256 e71248ed…dea4，1,397,704 字节），授权文本 `chill-bitmap-license.txt` 同目录随发。框体与纹理放 `wwwroot/art/ink2/`，旧 `art/v09/` 不删（其他页面样式仍可能引用）。
2. 令牌命名 `--ink2-*`；色值逐个取自 `生成界面.cjs`（p、button、badge、meter、frame、svg defs）。旧语义变量（--bg、--text、--accent、--good、--warn、--danger 等）改为引用令牌，--warn 与 --accent 同取暖金（新稿无单独警示色），--good 取灰绿。公共外壳与卡框层的写死颜色用 Lab 最近色映射到令牌，带透明度的用 `color-mix(in srgb, var(--ink2-*) N%, transparent)`。灰绿徽标底不参与最近色映射，避免冷色暗底被映成绿底。
3. 字号归档按用途：辅助（≤14）→14；正文（15—17，以及 18 的按钮、输入框、数值、卡名）→16；对白（.dlg-bubble、.dlg-narr）→20；标题（h1—h3、各 *-head h2、*-title，18—30）→24，其余 19—22 就近 20、23 以上就近 24；品牌字、大时钟、标题页大字 →32；只留两个图标字符（地牢入口图标、瞄准符号）不归档。字号不随窗口缩放，旧的矮屏缩字规则统一落到同一档。
4. 字体回落：`--font-pixel` 为 Ink16 后接系统黑体，系统字体只在缺字时由浏览器逐字回落（目前只有两个表情符号，见 B31a.5）。`--title-font` 改指阅读字体，文书类对白去掉宋体。
5. 框体粗细照 `frame()` 的高度分档，按组件类型静态指定：主面板、标题页框、对白层、战斗站位卡 8px；卡片、地图卡、行列面板、时钟、负重、中央条、状态浮窗 6px；按钮、徽标行、小件 4px。新框体九宫格切 12 单位（源图 96 单位）。
6. 九状态叠加用每张卡自己的阴影变量（--st-hover/sel/danger/busy/base）组合成一个 box-shadow；焦点用卡外 5px 双线 outline；不可用用斜线底纹；危险、加工中提供样式类 `.st-danger`、`.st-busy`，接线留给页面批次。
7. 偏好键 `survival.pref.readFont`（pixel/clear）、`survival.pref.animSpeed`（fast/standard/slow），沿用现有 `prefGet/prefSet` 前缀；app.js 在页面载入即按同一解析规则套用（`html[data-read-font]`、`--motion-k`），进游戏后切换由 GameSession 调 `survival.applyPresentation`。倍率后的毫秒四舍五入。
8. 战斗菜单在战斗中与敌踪选择中都显示两项偏好（Q322 已定敌踪菜单可调浏览器偏好）；其余菜单项、标题与 Esc 行为不动（B31b）。
9. 「其他动效取各自基准时长」：CSS 里全部 animation/transition 时长乘 `--motion-k`（载入动画除外），中央行动条淡出 150ms 与 app.js 定位闪烁 2200ms 同乘；留言组件、拖拽提示与 8 秒结果提示是阅读停留时长，不乘。

### B31c.3 开发假设（只涉代码结构、命名、像素与动画）

1. 局部盘一律用 `AnchorPop` 的居中模式（`Centered` 默认 true）：选卡操作（CardPop）、移动、接近、锁定路线、投炭、采集拖入工具（ActionPops）、点火工具（IgniteMenu）、食饮（FeedPop）。位置由 `survivalPop` 按 `data-center` 算到视口正中，放不下时距屏边 8；原「锚点滚出或消失即收起」判定保留在居中计算之前。旧的锚卡旁定位代码不删（`Centered=false`，目前无调用方）。
2. 居中框尺寸直接用 B31b 的居中弹窗令牌 `--pop-w/--pop-h`（608×438／760×547／912×656），宽高都固定（新稿每个操作盘都是同一框），`min(…, 100vw/vh − 16px)` 限制在视口内。框内：头部（对象小图、真实名、来源与已选参数）与底部动作固定，正文独立滚动；底部按新稿「取消」在左（190 宽）、主动作在右（238 宽），只改排列，不改按钮文字。原本就是居中窗的超额（PXg）、封存（PXi）、重置（PXj）、撤出（PXd）、同类武器（P03d）、转移数量框（PXh）改用同一尺寸，底栏推到框底。
3. 居中局部盘不加遮罩，背后四轨照原规则可点、可拖（点别的卡照原规则换选中、盘随之换内容），这是沿原交互；整备页内的交接盘、制作页内工作区、悬停提示、战斗内各盘不走 AnchorPop，位置不动。
4. 居中盘与中央行动位都在视口正中：居中盘开着时（`GameSession.LocalDiskOpen`），中央行动位与一级面板开着时一样收成中部底部窄条，保证「退出行动」可达（B31b.3 第 5 条的同一排版处理，不改规则）。
5. 动效时长（全部乘 `--motion-k`，系统减少动态效果时由 B31a 的全局规则直接落到结果）：弹层入场 200ms（位移 10px 加淡入）、遮罩分轨淡入 200ms、退场 140ms（位移 8px 加淡出）、一级面板从顶栏一侧与右栏属性子页从右侧短滑入 190ms（位移 12px）、悬停／焦点／选中边线与底色过渡 140ms（按钮与卡片）、结果提示原位淡入 180ms（上浮 6px）、一般提示到时淡出 140ms 后再移除。取值都在动效说明给的区间中段。用 CSS 独立 `translate` 属性做位移，不与现有 `transform` 定位冲突。
6. 弹层退场用 `app.js` 的影子层：MutationObserver 发现居中弹层（局部盘、菜单、确认窗、数量框）被移除时，把它复制到 body 下不接收输入的 `.pop-ghosts` 容器里淡出，160ms×倍率后删掉；同一帧有新弹层接上时直接删影子。真实弹层已关闭，输入立即回到背后，不经 Blazor 节点。
