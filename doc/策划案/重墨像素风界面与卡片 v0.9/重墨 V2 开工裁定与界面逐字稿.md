#### Q319、Q323–Q324 · 面板与对象操作

- **Q319** 一级面板只覆盖中间指定轨道，左右栏和各轨原位不动。地图、休息、日志、目标、提示、说明、对话记录、编队、远行准备、岗位事项及常态对白覆盖①②，岗位较高子盘保留现行扩展。制作、安全屋、晾制及三城鸟瞰覆盖①②③。整备、成长覆盖四轨。战斗仍用独立全屏。新稿的内部布局按各页可用区域缩排。手工制作保留④随身与其现有拖料入口，③覆盖期间通过盘内实际地面来源、数量和批次选择使用本区地面物品。原材料槽与现有手选／拖料能力可用时仍可用，已被面板盖住的卡不能隔层操作。保留原取料优先级、批次重验、其他轨的可见与可操作边界。
- **Q323** 右栏显示对象详情、原因和只读预估。新稿画在右栏的资源、接敌／绕行、数量转移、交谈和事项按钮放在对象卡或原操作入口。地牢现有「确认开始远征并前往」与底栏存档「重试」按原例外入口执行。
- **Q324** 卡片操作、点火、投炭、食饮、转移数量、超额、封存、重置、撤出、同类武器整理等局部盘在屏幕中央打开，使用对应新稿的居中框。在 1600×900，以 P02e／PXh 等同类操作盘的 760×547 CSS px 为基准，随 Q325 比例推导。空间不足时限制于可用视口，沿原屏边最小 8 CSS px，正文独立滚动，动作和取消固定可达。显示真实对象、归属和已选参数。开盘仅查看或编辑草稿，确认仍走原事务。取消、Esc 和来源失效沿原重验及焦点规则。悬停提示和制作、整备页内工作区仍使用自身原位置。

【实现同步 2026-11-10】Q321 已做：世界推进每段 60／120／180 毫秒、当前敌方逐条展示 240／480／720 毫秒，旧 40／120／250 与 max(160, 4×档位) 去掉；中央行动条淡出 150 毫秒与 CSS 动效同乘倍率；撤出最短可见 2 秒、跳过动画与退出响应沿原逻辑；速度只在网页壳呈现层，内核结算不读它（src/Core/State/UiPresentationPrefs.cs、web Services/GameSession.cs；自动测试 B31aPresentationTests；开发计划 v1.0 B31a，提交 e8e2f47）。

- **Esc** 先按原层级收起当前最上方可关闭的子层。没有可关闭的子层时打开当前情境的游戏菜单，战斗／敌踪、强制对白、行动推进和暂停均可用。强制对白本身不可由 Esc 结束。对白与战斗同时存在时，菜单按战斗情境展示，保留对白锁。
- **菜单内** 可以关闭菜单、调节阅读／动画偏好及打开反馈。其余菜单项按当前已有的条件与输入锁控制。强制对白锁期间仅开放上述入口，世界操作及原锁挡住的存档退出、重开等仍禁用。战斗内沿原战斗菜单的查看和保存权限。打开菜单与打开反馈不提交、确认、取消或恢复世界行动。
- **返回** 反馈关闭后回到游戏菜单。再次 Esc 或点继续关闭菜单，恢复原场景、原对白行或当前战斗画面与焦点。读取当前真实进度，沿原阅读暂停与行动规则。菜单不会消费对白继续键或下达战斗指令。
