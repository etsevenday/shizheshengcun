### Q501 ESC 与界面层级

原条目标题改为「ESC 与界面层级」，在原入口和位置替换正文，六段依次为：

> 按 ESC 时，先返回或关闭当前最上层可关闭的界面；没有可关闭层时，打开当前场景的菜单。一次只处理一层。

> 游戏菜单的手动存档页按 ESC 返回菜单首页；在菜单首页再按 ESC，回到原画面。覆盖确认打开时，先取消覆盖确认，不会保存或覆盖存档。

> ESC 不会退出正在进行或暂停的行动，也不会替你继续行动。允许退出的行动，请使用中央行动栏的“退出行动”；开工为5分钟的行动不可中途退出。强制整理等必须完成的步骤不能用 ESC 跳过。

> 战斗中，ESC 先收起当前可关闭的说明、物资页、医疗盘或取消尚未提交的指令；没有这些界面时打开战斗菜单。选择“返回战斗”或再次按 ESC 只返回战场，不能脱战。菜单内的存档、系统说明和反馈按各自可用条件开放。

> 对白期间，ESC 可以打开菜单，但不会结束对白或确认选项；关闭菜单后回到原对白。结算页按 ESC 打开或关闭结算菜单，查看记录等子页先按自身层级返回。

> 反馈与留言窗口打开时，ESC 由窗口处理；关闭后回到菜单。

其他玩家可见提示内按键词「Esc」统一成「ESC」，例如「右键/ESC 取消」「ESC 取消」；只改按键写法，原业务条件不变，不改内部Escape命名或玩家自由输入。

### Q502 空格的受理边界

仅当前可见、启用、非淡出的中央跳过按钮且中央行动层可接收输入时受理一次空格；按住不重复，不同键盘／鼠标路径不同时执行两次。输入法、编辑输入、菜单、对白、反馈、模态／前景面板、阅读抽屉与其他聚焦控件优先，空格不能穿透。焦点在中央跳过按钮时按其原生激活只执行一次；允许的背景焦点触发后阻止页面滚动。暂停、结束／终局、换场景、新行动或读档不接受旧请求／按住状态；保留原逐段结算与暂停、对白、遇敌边界，不把「跳过」当继续／退出。未来战斗播放层Enter／Space按Q297优先接收，不与中央共触发。验收Q495-A01—Q502-A02（具体行见S14同批表）。

### Q452 总控重拟：效果合计与旧物去向

**值的含义。** 单件说明中一侧没有对应品质／词条／固定效果，或项目确实不适用、不能比较时，用「—」。全身合计中可以计算的真实数值必须取领域结果：没有附加值时可为0，没有倍率修正时可为×1，不能因原合计为了简洁省略了该行就写「—」，也不能一律补0。沿既有符号、单位、百分比和精度，不通过拆解旧合计拼接文字推算。工具维护的装备替代值缺失与配方仍有基础恢复量是两回事。

**变化排版。** 保留两件装备的完整原说明与状态，下面的合计变化只列值或生效说明发生变化的项目，固定格式「{项名} {当前值} → {更换后值}」。按既有顺序分别归到「战斗」「求生」两组，每个有内容的组只写一次组名，空组不显示；不要把长的「战斗（…）」「求生（…）」前缀重复到每一行。封顶、下限、作用条件及战斗生效说明沿现有合计真实文字，各出现一次；随某一值变化的封顶注记紧跟该侧数值。攻击类仍按所选武器槽，七槽下原总合计不删。

| 特殊项目 | 正式行及取值 |
| --- | --- |
| 耐久0导致的效果暂停名单变化 | 效果暂停 {当前名单} → {更换后名单} |
| 名单内每件的写法 | {装备名}（{槽名}），多件用「、」连接，沿真实槽顺序；空名单写「无」，不写0。 |
| 徒手页可攻击位置变化 | 徒手拳击可打位置 {当前位置} → {更换后位置} |
| 上行位置值 | 沿原公开位置列表及原生效范围；确实不适用时写「—」，不新授予其他角色的攻击范围。 |
| 工具维护装备替代值变化 | 工具维护恢复 {当前替代值} → {更换后替代值}（替代，不相加） |
| 上行替代值 | 有装备替代值时按原百分比格式，缺失时写「—」；不把配方基础恢复量填成装备值，不把多个替代值相加。 |

无合计变化时不新增「无变化」空提示，仍显示单件说明。名单、位置和维护说明也只在真实变化时列出，不把条件文字误算为可相加属性。原合计中位移抵抗的多人限定、求生倍率下限等事实继续可读，不借比较重做计算规则。

**旧物去向。** 两处合法默认「本人随身」；本人随身卡位不够且「当前地面」确实合法时，只列地面，但不自动选中。「确认更换」禁用，原因正式写「随身卡位不足，无法收下换下的{装备名}（更换后{已占}/{上限}）。请选择「当前地面」，或先腾出随身卡位。」。{已占}/{上限} 取选择本人随身回收旧件时的最终卡位预演，可显示超限；上限沿实际规则，不硬造不同容量。

点选地面后重算最终卡位和负重，成功合法才可确认，不保留已经解除的卡位提示。地面也不合法，或实际受阻是超重、占用等其他条件时，沿真实阻断原因，不给出不可执行的地面建议。旧槽为空仍省略旧物去向；未点选时不移动旧件。
