# 重墨 V2 重新出图与易读字体 v0.9

2026-11-09。替换 14 中上一版的简化 SVG 造型。物品、技能、图标、资源、设施、势力、代班和招募样例依各自正式名称重新绘制。重墨 V2 参考仅用于墨线、木刻阴影、材质、像素块和低饱和色板。原参考图不作为新图的图形模板。版式、共享底框和程序绘制的状态层仍按 06 与 13 的合同接入。

本轮 581 项重绘均已核对，包括 180 件物品、102 个技能/熟练度/动作、81 个 UI 与状态图标、188 个资源点与设施、16 个代班、10 个招募样例、3 枚势力徽记及饱饱的专属符号。交付包另外导出 26 张人物肖像裁窗，共 607 张独立透明 PNG。随机人物的完整运行时外观组合仍按原数据绑定并另行验收。

- [字体实景对照](<assets/重墨V2重制/字体对照.html>) 把同一套菜单、复杂汉字、数字和对白放在相同画布。默认选「细像素」，可以在素材库切换「清晰阅读」。
- [替换清单](<assets/重墨V2重制/替换清单.json>) 只包含通过人工题意核对及透明裁窗检查的图。开发可按稳定键替换相应美术。全量引用与当前状态见 [新版全量视觉清单](<assets/重墨V2重制/新版全量视觉清单.json>)。
- [重绘图册](<assets/重墨V2重制/重绘图册.html>) 只展示通过复核的素材。可调至 24–96 px，检查小图辨识度和不同装备的轮廓。
- [出图计划与提示词](<assets/重墨V2重制/出图计划.json>) 记录对应的名称、原图风格参考、图位和提示词。[图集复核](<assets/重墨V2重制/图集复核.json>) 记录不通过的格位。已筛掉有底色、图位串入和题意错配的条目。

## 字体调整

默认字库采用 [寒蝉点阵体 16px v2.502](https://github.com/Warren2060/ChillBitmap/releases/tag/v2.502)，具体文件、授权和哈希见 [字体来源](<assets/重墨V2重制/字体来源.json>)。按钮、卡名和常规正文使用 16 CSS px，辅助标签最低 14，长对白 20 CSS px，标题 24 CSS px。长对白行高 1.7，去掉人工加粗与文字阴影。正文采用骨白与暗底对比，动态文本可以选中、滚动和换行。预览提供平滑的系统黑体阅读模式，正常进入保持细像素。已按当前配置抽取 1,380 个不同汉字，在 Chrome 中核对均由寒蝉本体渲染。

对照了 [方舟像素 16px 的末版](https://github.com/TakWolf/ark-pixel-font/releases/tag/2026.09.01)，在同一批实际汉字中有明显缺字回退。也参考了 [Cubic 11](https://github.com/ACh-K/Cubic-11) 的 11×11 格线，本轮长对白优先使用 16 格字型。旧 8/10 格字体只作为对照样张。此处替代 Q275 中的默认字库及字号建议，游戏对实际文本和复杂字形的验收继续沿 Q275。清晰阅读模式目前为样板中的辅助选项，实机设置由开发接入验收。

## 接入与核对

1. 图集是带真实透明通道的 PNG，单体按 `crop=[x,y,width,height]` 取样，原点在左上。岗位代班的 `portraitCrop` 和全身主体来自同一新绘图。图形按文件、像素裁窗和 ID 绑定。也可运行 `导出重绘单图.ps1 -Destination <空目录>`，导出按类别和稳定 ID 命名的独立透明 PNG。
2. 图标和文字均独立显示。物品画实际外形与材质，技能画动作或效果，界面符号优先辨识，设施资源画实际对象。角色模板只描述职业样例，随机角色仍绑定已保存的真实外观字段与身份。角色卡和历史按实际代班身份读取独立图像。
3. 低分辨率实际显示时核对物品图、技能轮廓与状态符号，留意同名状态、相近物品和小图对比。长文按 1280×720、1366×768、1600×900、1920×1080 的 100% 缩放检查。入口、规则、位置、费用、字串和旧档状态由现有实现提供。
4. 已建立的 [40 个页面样板](<assets/UI场景全览/index.html>) 用于对照版式。最新重绘图和文字样式在素材库样板及新绑定表中检查。正式游戏接入后以 UX2、INK2 与 Q275–Q277 验收。
   Q281 的实际地点切换规则和 Q282 的存档失败中文原句沿最新策划；字体对照含 Q282 实际文案及重试按钮。
5. 开发维护素材时修改重绘表的对应键，再运行 `node 更新绑定.mjs` 刷新可检索页和全量绑定。原始数据仍由全量素材库的配置扫描生成。替换表路径相对重制目录，新版全量绑定的资源路径相对 `assets/全量素材库/`。
