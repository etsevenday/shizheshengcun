## Q275 游戏界面全部采用像素字体

标题、导航、区块名、卡名、按钮、正文、数字、时间、表格、动态提示、战斗日志、对白和历史回看均使用像素字。文字保持独立可选择、换行、缩放和读屏。系统原生文件选择或浏览器界面由宿主呈现。

- 默认采用寒蝉点阵体 16px v2.502。正文 16 CSS px、辅助最低 14、长文及对白 20、展示标题 24。正文行高最低 1.5，长对白 1.7，禁用合成粗体。过窄时换行或纵滚，按钮、四轨道和五根随身卡仍可达。字体对照、原始文件和可选清晰阅读样板见 [15 重制说明](<15 重墨V2重新出图与易读字体 v0.9.md>)。
- 字体自托管并记录固定版本、来源、授权和哈希。按游戏现有字串、姓名池、标点、数字、单位、技术符号和动态插值核对实际字形。缺字优先补充合法像素字库；长文仍按 N02 换行、滚动和固定操作条。分发保留上游附带授权和版权声明。修改或子集化须遵照所用版本授权。[上游发行](https://github.com/Warren2060/ChillBitmap/releases/tag/v2.502)
- 测试 1280×720、1600×900、1920×1080 的 100% 浏览器缩放。包含新局长对白、岗位与角色姓名、长卡名、动态数量、耐久、百分比、`<0.01`、`→`、`×`、中英文混排和临时提示。已支持内容不得依赖非像素字体才显示，缺字修补后复验。过长文本走原 N02 滚动与独立控制区。

## Q276 最后一批完成全部人物与敌人的独立形象

UX2-B1–B4 可先接稳定 ID 与图层，缺生产图时使用原可辨识图和新框。UX2-B5 才集中交付全部人物与全部敌人正式形象，并以实际可显示覆盖作为完成条件。

- 主角、六名固定同行、营地来客、各城命名 NPC、当前会显示为独立身份的岗位接续者，均有对应身份的专属图。饱饱沿原有体内声音与形象设定做专属表现。原人离岗后，代班按实际岗位与代班身份绑定，回看按保存身份呈现，避免代班借用原人物头像。头像可从同一专属主体裁切，整备立绘、战斗形象及在场对话按该身份实际入口使用。没有战斗入口的角色只交付其实际所需表现。
- 随机招募与保底补员按角色实际拥有的现行外观字段出独立形象。生产可用已验收的像素部件离线组合成独立图，或按身份稳定组合并缓存最终成图。每名角色用原稳定身份绑定自己的成图。同一人跨名册、整备、战斗与读档保持一致，肤色、发型、发色与面部细节按保存值表现。性别未说明和旧档缺外观字段走明确的中性、无推断外观构成，原显示值仍保留。同一外观组合可以共享合成素材，各实际身份仍有可单独验证的成图绑定，不能用两张性别剪影顶替全量交付。无需预先穷举无限候选流水号。Q276 取代 Q180 仅提供文字外观的素材范围，生成字段、概率、数值与旧档仍沿 Q180。
- 每种敌人按敌人配置 ID 交付独立战斗图，当前 42 个均在机器合同。同种变体需在剪影、可见构件或纹理中有至少一处稳定可辨差异。真实同类敌人实例可以共享该种图，战斗选择继续用实例身份。人物与敌人图的展示只改变渲染，已存档身份、外观、实际装备、敌人能力与站位不变。

## Q277 生产与像素观感验收

开发方分批采用 AI 生图加降采样、限色、边缘整理与必要的人工补像素。单体独立、透明安全边、最近邻显示和动态文字分层按 01 §2 与 §7。卡片可随窗口正常连续调整，合适时使用整数倍率，视口中间尺寸按可读性与清晰度验收。

生产清单按稳定 ID 记录类别、版本、用途、来源或生成记录、授权、目标显示尺寸及完成／暂用状态。按当前运行配置盘点物品、资源、设施、地图与场景、技能、九状态卡框、人物、敌人、图标和徽标。中途可用现有可辨识素材配新框，保留真名与状态。结案以每项实际素材为准。

INK2-14 以三档游戏窗口的 100% 正常显示为准。人物和物件的方形像素簇与轮廓可辨，边缘无明显模糊，底纹没有整屏密集噪点，纹理不吞字。再抽查 1366×768 和任一连续调整后的非整倍尺寸，确认卡片不因像素对齐跳档，操作位不漂移。可放大定位缺陷，最终在正常窗口截图判定。缺图可在阶段验收登记，最终全量交付时占位清单须清零。
