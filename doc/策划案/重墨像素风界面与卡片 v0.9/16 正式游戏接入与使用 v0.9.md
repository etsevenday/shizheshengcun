# 重墨 V2 正式游戏接入与使用

## 玩家操作

打开[适者生存](https://etsevenday.github.io/shizheshengcun/)后，标题页、游戏菜单和战斗菜单都可切换「阅读字体」。默认是寒蝉点阵体 16px 的「细像素」，也可以选择「清晰阅读 · 系统黑体」。设置保存在当前浏览器，下次进入会恢复。对白为 20px、行高 1.7，正文可选中和滚动回看。

- 点物品卡，卡面和详情共用该物品 ID。制作材料、整备和战斗物资沿用同一套物品图。
- 顶栏打开「成长」，可以查看 15 门熟练度及其 75 个技能图。战斗操作台按同一节点 ID 显示已解锁、锁定和被动技能。
- 在城市岗位交谈时，人物卡和事项面板随在岗状态显示对应人物；对白与历史记录按发生当时的发言人显示肖像。
- 收容所名册的图是职业示意，候选者的性别及外观字段仍以本局资料为准。

## 开发维护

`assets/重墨V2重制/替换清单.json` 是经美术复核的原始裁窗表。`tools/build-ink-v2.py` 从该表导出 WebP 图集、肖像、字体和运行时 `manifest.json`。同时导入先前已核定的角色、敌人、场景和分层 UI 框。浏览器按需载入实际显示的图集。字库保留完整字形，字体与授权文件随网站发布。

| 类别 | 运行时键 |
| --- | --- |
| 物品与装备 | `item:<itemId>` |
| 技能与门类 | `skill:<nodeId>`、`skillFamily:<familyId>` |
| 通用动作、状态与界面图标 | `action:<actionId>`、`status:<statusId>`、`glyph:<glyphId>` |
| 地块资源与设施 | `resource:<locationId>:<nodeId>`、`facility:<facilityId>` |
| 角色、代班与职业样例 | `actor:<actorId>`、`duty:<npcId>`、`recruitTemplate:<templateId>` |
| 敌人与势力 | `enemy:<enemyId>`、`faction:<factionId>` |

出图换版后从仓库根目录运行以下命令。提交更新后的 `web/Survival.Web/wwwroot/art/ink-v2/`，让本地构建和 Pages 使用同一批素材。

```sh
python -m pip install Pillow 'fonttools[woff]'
python tools/build-ink-v2.py
dotnet publish web/Survival.Web -c Release -o publish
```

视觉设置只写浏览器阅读偏好。现有存档、玩法、入口和规则继续按原实现运行。测试用的传送和离岗切换只在 `?dev=1` 开发菜单中提供。

已核定的旧版独立地景继续用于农野荒地、溪流、林地、村庄、五金店、诊所和废料场。地图道路、库存账徽标和状态框由程序按实际数据绘制。没有专属肖像的角色使用新版中性标记，招募职业样例只在名册中展示。

## 实机复查

`tools/verify-ink-v2.cjs` 可在 Chromium 和 Playwright 环境下对正式构建运行。将 `?dev=1` 游戏地址及输出目录作为两个参数。脚本使用独立浏览器会话，记录素材绑定、对白排版与实际页面截图。

```sh
node tools/verify-ink-v2.cjs 'http://localhost:5180/?dev=1' screenshots
```

截图取自发布构建的实际游戏页面。测试存档用来放置全目录物品，开发入口用于定位和切换岗位状态。
