# UI 与美术应用场景全览 v0.9

2026-11-09。将既有美术和公共 UI 放进 40 张可切换的界面样板，覆盖 [08 合同](<08 UI结构与流程合同 v0.9.json>) 的 P01–P09，并补齐启动、暂停、结算和撤出入口。

拉取仓库后，在 Chrome 或 Edge 打开本地 [场景全览](<assets/UI场景全览/index.html>)。左侧选组，或从下拉框跳转。地址后的 `#P05a` 一类编号可以直接定位场景。每页底部列出对应组件、本页实际取景和构图参考，点击缩略图打开原尺寸。

## 图层和源文件

| 图层 | 预览内容 | 开发接入 |
| --- | --- | --- |
| 场景 | 营地外围、战场、三城鸟瞰 | 背景独立加载。正式地图节点和移动反馈继续取实际坐标与道路。 |
| 主体美术 | 物件、设施、装备、人物、敌人 | 独立 PNG 直接绑定展示位。原图的图册取景是带底样板，正式成图按稳定 ID 补齐透明主体。 |
| 底纹与装饰 | 铁灰纹、旧纸纹、冷钢和锈铁装饰条 | 公共底纹仍用原 SVG。参考底图只取无字装饰局部，页头和布局使用独立组件。 |
| UI 边框 | 面板、卡框、主操作按钮、选中边 | 沿用 [分层样件](<12 UI分层样件使用说明 v0.9.md>) 的九宫格 SVG 与 CSS。 |
| 状态 | 进度、选中、拖放、危险、锁定与地图节点 | 挂在实际状态或预演上，保留独立文字和控件。 |
| 文字 | 标题、卡名、导航、状态说明和对白 | 正式文字按现行合同和 Q275 像素字库。样板使用系统字与展示数据。 |

「合成」查看完成画面，「仅 UI」检查去掉场景和主体后的界面，「仅美术」检查各背景与主体在版式中的位置。可用七个开关单独调节。图层隐藏会保留原占位，以便开发比较同一构图。

- [场景清单](<assets/UI场景全览/场景清单.js>) 记录场景编号、组件、参考来源与取景。取景坐标为 `[x, y, 宽, 高]`，相对于原图的百分比。
- [屏幕样板](<assets/UI场景全览/屏幕样板.js>) 组装卡片、轨道、战斗站位和各层。用 [场景样式](<assets/UI场景全览/场景皮肤.css>) 管版式和图层，用 [公共样式](<assets/UI分层样件/css/ink-layers.css>) 管可复用边框。
- 六张新增 PNG 包含营地外围和检查站战场两张背景、单体透明感染者，以及我方、感染者和野外动物三套透明图集。各主体在样板中独立取景和定位。文件在 `assets/UI场景全览/art/`，生成提示词、原图来源、尺寸和哈希在 [美术来源](<assets/UI场景全览/美术来源.json>)。净水、火堆和透明幸存者沿用前次样件。

## 试接和验收

1. 先按现有 UX2-B1 接主界面、火堆与公共卡，再依 B2–B5 扩展。场景样板供视觉对照，页面交互用 [交互原型](交互原型.html) 与 [实施验收](<07 UI重做验收与实施 v0.9.md>)。
2. 检查画面、可读性和独立图层时，在 1280×720、1366×768、1600×900、1920×1080 打开相同场景。分别切换合成、仅 UI、仅美术，卡位和控件保留，资源无丢失。
3. 按正式数据核验四轨、五根卡、七槽、两个火堆工位、八战斗站位与每页五技能卡。Q279 战斗物资只读且无同行食饮按钮，Q280 整备锅仅显示根卡，锅内食饮走队伍子行或锅浮窗。真实动作、旧档与权限按原验收执行。
4. 全量正式插画、游戏字体及实机接入分别进入对应批次验收。样板中的资源数、回合与进度用于展示版式，页面节点位置供说明层次使用。
