# UI 分层样件使用说明 v0.9

2026-11-09。供 UX2-B1 试接公共组件。界面结构、交互规则和批次顺序继续按 [04–08 主案](README.md) 与 [Q274–Q278 定稿](<11 Q274-Q278 素材、字体与实施定稿 v0.9.md>)。

## 1. 本地查看

拉取项目后，用 Chrome 或 Edge 打开本地的 [图层预览.html](<assets/UI分层样件/图层预览.html>)。预览不需要启动游戏或联网。若从 GitHub 下载，解压仓库后再打开，保留原目录结构，预览会从相邻的参考原图目录读取三张城市鸟瞰。

依次关闭场景、底纹、物件插画、边框、状态和文字，检查每层如何单独替换。下方可对照九种卡片状态，点击插画可查看原尺寸。预览的文字使用系统字体，数字和进度是演示数据。完整页面和操作流程查看 [交互原型.html](交互原型.html)。

## 2. 先试接净水卡和火堆卡

1. 打开 [素材清单](<assets/UI分层样件/素材清单.json>) 和 [组件接入对照](<assets/UI分层样件/开发交接.md>)。样式在 `css/ink-layers.css`，边框、底纹和状态标记在 `ui/`，三张透明 PNG 在 `art/`。引用示例 CSS 时保留 `css/` 和 `ui/` 的相对位置。
2. 在 UX2-B1 的试接范围加 `.ink-skin`，给现有容器、卡片和按钮分别挂 `.ink-panel`、`.ink-card`、`.ink-button`。给标题条挂 `.ink-card-title`，插画挂 `.ink-art`。边框沿用现有 `materials.css` 的九宫格做法，SVG 源切值为 16，面板、卡片、按钮的角部显示值示例为 10、8、6 CSS px。样式加载顺序按实际级联调整，卡片尺寸、拖放热区和操作事件沿正式组件。
3. 从 `ItemShelf.razor` 的净水卡和 `FireCard.razor` 的火堆卡起步。插画按 `clean_water`、`fire_lit` 绑定。熄灭或未点燃状态使用对应的现有图。火堆、锅、加工位分别使用真实对象和状态，样图只占火堆插画位。
4. 选中时挂 `data-ink-selected="true"`，用 `:focus-visible` 显示真实键盘焦点。拖放命中后按真实预演挂 `data-ink-drop="allow"` 或 `"deny"`，移出落点时清除标记。禁用取现有控件语义和原因。风险图标、进度和禁用原因取真实数据，焦点、选中、风险和进度各占自己的位置。挂样式类后仍以 [06 九状态合同](<06 卡片信息与状态合同 v0.9.md>) 判定显示和操作。
5. 验收通过后再推广到整备、战斗、制作、地图和城市等页面。角色立绘是姿态样件，城市鸟瞰是无字构图参考。正式游戏资源按稳定 ID 补齐，场景节点依真实地图。按 Q275 接入本地像素字库，按 Q276–Q277 在 B5 清理暂用图。

## 3. 验收

在 100% 浏览器缩放下检查 1280×720、1600×900、1920×1080 和 1366×768，并按 Q277 再抽查连续调整后的非整倍窗口。随身五根卡、四轨道和火堆加工位都可达。确认长卡名可读、换状态不移动卡位、键盘焦点可辨，合法落点执行原事务，非法落点显示真实原因且原数据不变。切换火堆、锅和加工位时，应能区分各对象，并读取真实进度。

记录提交号、窗口尺寸、截图、操作结果和临时图缺项。公共层验收对应 [INK2-01–14](<03 开发交接与验收 v0.9.md>)，火堆与键盘回归看 [UX2-A03、A04、A17](<07 UI重做验收与实施 v0.9.md>)。浏览器预览记录覆盖图层显示，实机接入后需另行记录结果。
