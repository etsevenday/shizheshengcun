### Q267 耗材真实缺项与烧水

沿Q234：D合法未锁未预留随身脏水毫升；P可用净水片整份；C可用滤芯整份；F有可用滤水器=1否则0；V=2000*min(floor(D/2000),P+F*C)。不重复用水，不改公式/来源权限。

| 键 | 正式逐字稿 |
| --- | --- |
| main | 处理后才可饮用：随身脏水{D}毫升；按现有净水片/滤芯，最多可处理{V}毫升（每批2000毫升，需完整4份脏水）。 |
| noMaterials | 随身没有可用的净水片或滤芯，暂不能按耗材处理脏水。 |
| smallBatch | 随身可用脏水不足2000毫升，未凑足一批。 |
| noFilter | 滤芯{C}份暂不计入：需要可用滤水器 |
| boiling | 可烧水处理，受锅、热源与燃料限制，未计入上述耗材可处理量。 |

- main：D>0才显示main；D=0隐藏main、缺耗材/不足一批/缺滤水器及烧水行，处理用品/热源原行仍可读。
- noMaterials：D>0且P+C=0时显示noMaterials；真实持有但被锁/预留的耗材不当可用。
- smallBatch：0<D<2000显示smallBatch；可与noMaterials同时出现，各一次。
- noFilter：D>0且C>0且F=0沿原显示noFilter；若只有滤芯但无滤水器，不再误写“没有净水片或滤芯”。
- boiling：D>0且当前存活同行含主角随身存在未锁/未预留锅时显示boiling；不统计候补/地面/柜/设施锅，不检查点火工具/燃料/场地是否够，句子只提示潜在路径并说明限制，不保证立即可烧。实际开工仍完整校验。
- order：main→noMaterials→smallBatch→noFilter→boiling，各按条件一次。容量V不加到当前净水/不抵扣缺口、不自动净化。
