## 1. 按任务交接文档

| 修改任务 | 主案与必读联动 |
| --- | --- |
| 新地点/路线/发现 | S02→S03→S05/S04→S14 |
| 调清理收益或次数 | S04→S03共享表引用→S06物资经济→S14预览 |
| 加新物品 | S06→取得系统→用途/消耗系统→S07白名单→S14图标 |
| 加配方 | S08→S06来源/保质→S01事务→S14 |
| 加锅/设施行为 | S09/S10→S11→S06重量/owner→S07/S14 |
| 改恢复/消耗 | S12/S13→S01倍率/阈值→各系统算例→S15引导 |
| 改主界面操作 | S14→相应S07/S09/S10/S12玩法入口，避免只改皮肤 |
| 开人物与战斗原型 | R01—R05成组评审；明确基础替换/开关/迁移，再映射S01/S05/S06/S12/S13/S14 |
| 开动物食物链 | R05→R06→S10/S11白名单→S06/S12→R02工具损耗 |

> 【实现同步 2026-10-27】"开人物与战斗原型""开动物食物链"两项已在 v0.6 完成：R01–R06 成组接入并直接开启，无开关，S01/S05/S06/S12/S13/S14 已按参考尺度映射，存档迁移 4→5（开发计划 v0.5 人物与战斗，M36–M48）。后续改这些系统按"改恢复/消耗""加新物品"等常规任务处理。

引用到别的系统不等于要求本轮重做它；程序先看本次改动主案和实际受影响边界。开始前检查待定P项，已明确规则不要再次自动选择默认值。
