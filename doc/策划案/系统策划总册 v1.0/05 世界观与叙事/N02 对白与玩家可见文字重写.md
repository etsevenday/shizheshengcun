## 1. 人物各自怎么说话

人物的用词来自他手头的活、和对方的距离，以及这场对话里他最在意的一件事。熟悉的人可以接上上句话，但一次性招募和身份未知时不预设亲密。主角可以谨慎、着急或直问，保留既有选择的余地。NPC 不代玩家承诺效忠、治疗、交出物品或选定身体观察。

| 角色 | 用词与停顿 | 说话时优先守住什么 |
| --- | --- | --- |
| 饱饱 | 先说身体感觉，再问一件具体的小事。饿时催得近，害怕时话变短 | 它不知道自己的来历，也不能替玩家解释医学数值 |
| 主角 | 问得直接，给明确边界，肯承认没看清 | 对身体、路线和合作自己做决定 |
| 程望 | 路标、走得通、把回程留出来。能用实物打比方 | 只保证认得的路，关心对方能否走回来 |
| 陆衡 | 先问来处和去向，再分清眼前这一关办到哪里 | 营门办授权，广场完成登记 |
| 许安 | 把桌上几份记录摊开，找能共同采用的一笔 | 公共事务方便人办成，归属和公用路线分开 |
| 陈芷 | 先问症状开始时间、伤口和用过的药，再给有限的结论 | 医务室能做的事受现有伤情、服务与物资约束 |
| 陶岑 | 分栏、看样本、确认这份是什么。谨慎的短句 | 原料性质、融合结果、教学样本各有边界 |
| 杜穗 | 记人名、问本人，能用一句平常话拦住把人当名额的提议 | 有床、有名额和本人愿意是三件事 |
| 罗铮 | 开图、对接口、检查零件，先问东西做到了哪一步 | 公开工坊的实际条件和既有记录 |
| 祁闻 | 先接住外来者的话，再递来教会的邀请 | 他真心希望对方公开讲述，却没有替对方表态的权力 |
| 白苓 | 看账、看领用人、看账上没填的地方 | 援助给到人，核实物资，接受如实记录 |
| 纪牧 | 抄本、存档、回执。用手续表达压力 | 他偏好认可教义，玩家仍能按既有其他路径留档 |
| 宋烛 | 指出哪页是路线、哪页是证言 | 记录的出处和抄录条件 |
| 傅珩 | 说得慢，会从众人如何安静下来谈共同解释 | 他能主持和邀请，不能处置玩家或替人作决定 |
| 温澄 | 先安排来访路径，再分别询问观察范围 | 科学院内部并非一套意见，公开路线对拒绝试验者仍适用 |
| 季闻 | 像在核对一份同意书，讲清这一项到底允许做什么 | 已有指标、额外取样与治疗严格分开 |
| 邵宁 | 翻页、画线、质疑报告里的同一个词 | 把证据和解释拆开，对未知有明确边界 |
| 何远 | 设备上手之前先验工具和条件，少讲抽象原则 | 门口告示和工坊真实开放能力分开 |
| 尹珂 | 指出观察范围和退出位置，问玩家是不是还愿意继续 | 当前许可范围、只读、退出及拒绝试验 |
| 林昭 | 直说自己巡路还不熟，愿从背包和警戒这种小事做起 | 主动分担，给别人留决定的余地 |
| 周砚 | 先验工具，再核对步骤。哪一步没弄懂就停手 | 检修靠确认过的步骤 |
| 沈禾 | 给人时间读完，说清风险后等对方点头 | 照护和知情同意 |
| 唐梨 | 谈弓、物资和纸上的归路。问得短 | 再好的收获也要有路回来 |
| 顾承 | 把人手、装备和出发顺序说清楚 | 旧巡防的习惯仍在，先准备再走 |
| 叶洵 | 将目击和转述分开，知道到哪儿该说「说不准」 | 把没见过的部分留白 |

岗位代班各自知道本岗正在办的事，沿用本岗同一本账。首次接续说明由代班说「我今天值这岗」这一类实际身份话。继续办旧事项时说清哪一份记录可接着用。无名代班保留原来的当班身份，头像采用岗位占位，记录保留岗位题名。任何名人经历、私人承诺和专业自我介绍只由本人说。代班接 EXQ 时保留任务专用信息与现有真实代班发言者。

## 2. 一句话放到它该去的地方

| 文字类型 | 当前界面放置 | 与交互的关系 |
| --- | --- | --- |
| 人物对白 | 中部对白流。保留主角左、实际发言者右，角色名在正文上方 | 仅用原来那条 ID 的继续或结束提交 |
| 场景旁白 | 对话流里的中性叙事段，无头像和发言者名 | 照原顺序展示。说明眼前能观察到的事 |
| 现有告示、残页、路线与档案 | 现有阅读面板中部，标题下按段落显示，引用的字句保留原分支边界 | 文档卡只给标题、状态和原入口。操作方法留在阅读面板脚注 |
| 工作目标和结果 | 工作区的“要做什么”和结算反馈。已有对白顺序内的系统行用中性状态样式 | 用引导或已发生的结果，具体条件仍取实时预览 |
| 教学操作 | 当前对白里的“操作提示”辅助行，可在既有说明入口重读 | 说明看得到的按钮和下一步。继续键维持原触发和去重 |
| 拒绝与忙碌 | 出错的控件旁或原全局行动位。真实原因可用触屏和键盘访问 | 任务锁、敌踪和本卡状态各有位置。忙碌提示不替换卡自身状态 |

任务类结果沿既有展示时机显示。`document` 类型只进入其现有阅读入口。若一条文档或工作提示本来就由强制对白播放，它仍出现在该次对白并遵守原有继续和锁定，用中性区分层。类型字段只决定表现，不能据此新增弹窗、自动确认、跳句、合并触发或移动位置。

### 旧档与实际发言者

已归档记录按保存时的正文、发言者和顺序显示。正在播放的对话保留已展示快照和当前进度。沿 Q245，仍在队列的未展示台词按原 ID 继续，实际首次展示时读新版配置。旧快照缺少本次显示类型时，按原说话方、空 speaker 和原 note 字段回落到原有表现。岗位名和实际发言者继续由现有岗位/代班判定提供。历史回看仍从快照取人名和正文。

## 3. 例子

- 开场。饱饱说「喂，你醒了没有？……我饿得睡不着。」营地和脑内声音由旁白交代，地面罐头、净水和出路列在操作提示里。
- 营门。陆衡先问来处和去向。拿到授权后说「授权记好了。沿通道去广场，到了再办登记。」玩家从状态读到办到哪一步。
- 医务室。陈芷先问症状何时出现。公开医疗线索把咨询地点、可带资料和仍无结论的部分写成三个可查段落。
- 教学融合。饱饱说自己感到玩家的手有些变化。「攻击力+0.1」进结算提示，下一句提醒未来的结果可能不同。现有预览和实际词条继续显示同一数值。
