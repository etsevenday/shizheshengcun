## 1. 首期范围

饱饱吞噬融合来自敌人的道具卡“活性物质”。当前新手区域仅丧尸正常掉落白色品质，每只独立概率0.5%；普通实例融合后无属性。暂不设计大量正面/负面词条，不开放更高品质物质掉落、词条刷新/洗练/转移/合成升级、额外饥饿或病毒惩罚。

唯一例外是首战剧情教学：**白色物质品质不变，融合结果固定是一条绿色词条“攻击力+0.1”**。物质品质和词条品质是两个字段，不能为了给绿色词条把道具卡改成绿色，也不能让普通白色实例继承这个效果。用户已确认这是独立教学特例。

## 2. 物品与实例

| 项目 | 规则 |
| --- | --- |
| itemId | active_substance_white_unidentified |
| 名称/品质 | 未鉴定的活性物质 / 白色 |
| 道具类型 | 饱饱吞噬融合材料，不是食品、药品、尸体或锅食材 |
| 物理数据 | 建议50g/份、普通同来源兼容批次stackMax20，教学实例独立；本期无保质/失活。均为T02已批准实装初值 |

教学与普通实例不合并为同一底层批次；界面同名归组也必须保留来源。道具可按S06在当前地面和随身之间转移；能否放入未来其他容器另案定义，当前不能入锅/火堆。初次奖励由最终胜利落在field地面，背包满不会吞奖。

> 【实现同步 2026-10-27】合堆键为“物品＋到期＋grantEventId”（src/Core/Engine/GameEngine.Items.cs Normalize）。普通实例的 grantEventId 按“battleId＋世界敌人ID”生成，因此教学实例与普通实例不合堆，不同敌人掉的普通实例也各自成堆，“同来源兼容批次”实际每批1份；来源存读保留（提交 1b4c425）。拖进锅或火堆一律拒绝。

## 3. 普通掉落与教学必掉

| 来源 | 数量/概率 | 融合结果 |
| --- | --- | --- |
| S15剧情首战游荡尸，最终胜利且存活 | 固定1份白色未鉴定，唯一grantEventId；不再抽该敌普通活性物质 | 指定绿色词条“攻击力+0.1”，仅一次 |
| 当前新手8地点的普通丧尸 | 每只独立0.5%，命中给1份；动物不掉（T08已确认） | 无属性、无随机正负效果 |
| 逃跑/绕行/撤退/死亡终局/处理尸体 | 无额外活性物质奖励 | 不适用 |

普通活性物质作为附加独立掉落，不覆盖丧尸原空/布料/废金属互斥掉落或动物尸体。与R05一样在敌人死亡时锁计划，最终整场胜利且唯一轮末tick存活后一次发放；重接/读档不重抽、不重复发。未能最终胜利则不领，已死实例不通过巡游复活。动物不掉活性物质，击败/逃离/处理尸体均不做该抽签。普通丧尸掉率0.5%是每只的独立伯努利抽签，不是多杀200只的保底，不因其他战利品抽空而提高。新手区不掉其他品质。

## 4. 吞噬融合操作与结果

玩家空闲、所在位置可访问道具且未被预留时，点选卡片→卡下“吞噬融合”→显示所选实例与数量1→明确执行。按钮/道具图标保持S14统一信息表达；不新增左侧自身卡、不用拖到人物页偷偷消耗。战斗内、主/子行动执行中不可融合；建议仅空闲可用，不加入暂停补给白名单（T02已批准实装初值）。

正式执行前重验道具与来源，消耗1份并一次提交融合结果、饱饱对白和存档。无效来源、重复requestId或不足数量不部分扣除。建议吞噬固定5游戏分钟，按wait身体速率、额外E0；不得又扣一次“融合体力”。消耗/效果先一次提交，再以固定5分钟自用子状态推进，期间不得取消或另开行动，读档只续未推进的段，不再次消费/加属性。若5分钟内V100或H0仍按常规死亡，效果不复活玩家；完整事务中记录效果已提交与pendingTick，避免卡和效果分两次丢失。此为T02已批准实装初值。

教学成功：登记唯一效果ID tutorial_attack_bonus_001、绿色品质、显示“攻击力+0.1”，与首次融合完成标记及物品消耗原子提交。它不是物品装备，不随武器丢失而被重复发放；建议适用所有玩家武器与拳的正基础伤害直接攻击，在技能/招式/站位/暴击乘算后、扣甲前平加0.1，防御再×0.5；不被暴击或技能再次放大。群攻每个命中目标各生效一次；推挡这类基础0伤动作和出血持续伤害不加0.1，未命中也不加。具体插入层为T02已批准实装初值，+0.1数值与绿色品质已由用户确定；开发不得只显示词条而不实际结算。

普通成功：消耗该实例，显示“饱饱吞噬融合了活性物质。本次未产生属性变化。”不增加攻击、经验、免疫、病毒、饱食/水分或隐形累计成长，不暗抽负面效果。鉴定状态是否转为已鉴定、是否要独立鉴定动作/费用待后续专案；首期不能用未设计的鉴定门槛卡住教学。

> 【实现同步 2026-10-27】入口与事务（提交 e5c07c4、baa1d80）：选中随身或当前地面的活性物质卡，卡下按钮“吞噬融合1份·5分钟”，悬停时右栏预览结果，点按钮即执行，不另弹确认框（开发假设 A5）。战斗中、主/子行动中、暂停中禁用并写原因。开始时一次提交消耗1份、词条（仅教学实例且尚未完成教学融合时）、完成标记与对白，之后5分钟按 wait 推进、不可取消；读档只续剩余段；同 requestId 重发不重复（开发假设 11、12）。教学融合完成后，之后任何实例融合都按普通处理。词条存于人物状态，人物页“词条”区绿色显示“攻击力+0.1”（开发假设 A6）。平加攻击力只对招式伤害系数>0 且武器伤害上限>0 的直接攻击生效（含勉强拳击、霰弹散射逐目标），推挡与出血不加，预览与实际同一算法（开发假设 15）。

### 4.1 T02可调初值与算例

**以下为用户已批准实装的可调初值（2026-10-27）。** 程序可直接按本案实现，用户测试后不合适再调整。批准不等于程序已完成；后续调整直接更新本案和更新日志，不另建并行配置。

假设本次乘算后伤害1.20、护甲0.30：无词条0.90，有教学词条1.00；防御时分别0.45/0.50。若本次暴击已把伤害乘到1.80，则有词条为1.80+0.10−0.30=1.60，不是(1.20+0.10)×1.5−0.30。

融合5分钟按现行wait：N−0.125/W−0.25/S−0.416667/M−0.041667，E额外0；免疫/V、燃料、设施与保质随同一个世界tick推进。普通融合不提供额外属性，不等于暂停世界自然变化。教学与普通使用相同耗时，不把教学消耗强制免费后又隐扣时间。首次执行前预览真实费用，取消预览不扣物。

## 5. 存档、旧档与扩展边界

存储道具来源、教学奖励发放ID、教学融合完成标记、词条实例和融合事务ID。消耗与效果同事务保存，不允许断线后既少卡又无效果，也不允许重试双加0.1。新局不跨局继承，T06已确认新剧情/教学只对新局启用，旧档不补首战、教学物质或+0.1词条；具体存档schema由开发方选择。

未来增加鉴定与随机词条时，应另行给出品质/权重/正负词条池、累计/替换/移除、代价、概率展示、可重复性与旧档迁移。当前只留清晰字段，不提前编造稀有词条和随机负面惩罚。饱饱本体的持续V输入独立按R04结算，不是普通材料的负面词条，融合一次不额外加一份病毒。
