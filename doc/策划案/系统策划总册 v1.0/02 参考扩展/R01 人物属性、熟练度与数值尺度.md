## 1. 属性尺度与显示

健康H上限20、初始20；体力E上限20、初始18。饱食N80、水分W80、清醒S90、精神M60的初值与0—100范围保留。免疫I初始70、范围0—100，病毒程度V初始0、范围0—100；初始未感染，饱饱持续体内输入与高免疫控制按R04/T09，不能把V0理解为之后只有咬伤才会感染。

健康20不是另开“战斗生命”；受伤、饥渴、疾病和战斗都影响同一个H。健康≤0生命终结；V≥100尸变结束本局，即使健康还高也不能继续。

内部保存至少1e−6精度，不按UI显示两位小数回算，不在每5分钟先舍去小数。小于0.01但仍正的成本/生命显示“<0.01”，不显示为0。阈值比较使用统一数值策略，浮点实现允许≤1e−8的比较容差；不能因累计误差使理论100病毒永不尸变。验证脚本感染部分采用有理数计算精确核对边界。

> 【实现同步 2026-10-27】界面统一显示两位小数，按四舍五入到百分位（先加 1e−6 个百分位的吸附量，避免 3.60−0.80 因浮点误差显示成 2.79）；正且小于0.01显示“<0.01”（0.006 不进位成 0.01），负号用“−”。内核保存原始 double，不在每段 tick 里舍入（src/Core/Engine/Fmt.cs；开发计划 v0.5 开发假设4/35、试玩修复 D1，提交 a9e2366、2e7d872）。四舍五入在阈值附近的显示（如体力3.996显示4.00而状态已标“偏低”）是否接受，见开发计划 v0.5 待确认15。

旧H/E全部按0.2缩放，包括当前值、上限、警戒线、恢复、损伤、招式体力和历史伤害提示。例：健康高危25→5，低体力20→4，绷带基础恢复5→1，饥渴归零损血也缩放。N/W/S/M、物品重量、时间与食物的饱食补水效果不缩放。

## 2. 技能与无封顶成长

制造、医疗、枪械、刀斧、矛、拳、弓箭、钝器共8项，初始1级，各自经验。移除10级上限，不再出现“满级停止经验”。升级门槛继续为50×(当前L+1)，逐级扣经验；等级和经验应使用能覆盖长档期的整数/数值类型，溢出报错而非静默回零。

“不封顶”指等级和能力收益不被人为截断。概率仍不能超过100%，损耗不能为负，生命恢复不能超过当前上限；这些是结果范围，不是10级/95%的成长硬上限。

| 收益 | 公式 | 说明 |
| --- | --- | --- |
| 对应武器伤害倍率 | 1+0.035L | 持续增长，无1.4或2.0倍率硬截断 |
| 对应武器命中能力A | 武器基础A+3L | 能力值持续增长，之后与目标闪避共同换算概率 |
| 对应武器体力成本 | 基础成本/(1+0.025L) | 持续减少且正值，不减为负，不硬钳至某一固定成本 |
| 制造工作量 | 原始工作分钟/(1+0.025L) | 不再“最多减少30%”；设施被动受热和处理尸体不吃该加速 |
| 绷带健康恢复 | 1×(1+0.02×医疗L) | 无技能硬上限，实际只补缺少的健康 |
| 绷带病毒抑制量 | 2×(1+0.01×医疗L) | 仍不能把已感染程度降至1以下或清感染状态 |

制造仍按5分钟tick。高等级单件即使基础工作量小于5分钟，也不能让世界倒流；同一已预留批次可在一段内制作多件、结转该批剩余工作量，使高熟练度继续提高批量产量。不得跨到无关配方白送进度、超出材料或重复产物；普通单件最低一段是时钟精度约束。

经验按有效制造、有效医疗、攻击命中发放，预览、空治疗、装填、防御不刷经验；群攻逐目标计，打中几只算几次，护甲完全抵消直接伤害仍计命中经验。同一世界敌人/技能最多计3次命中经验，计数随worldEnemyId保存，巡游、撤退、换encounterId都不重置；这是反刷规则，不限制技能总等级。

技能ID固定：crafting制造、medicine医疗、firearms枪械、blade刀斧、spear矛、unarmed拳、archery弓箭、blunt钝器；8项初始均1级、经验0。不另增总等级、力量/敏捷/智力加点。

## 3. 经验来源主表

| 来源 | 经验 |
| --- | --- |
| 成功有效手工/建造配方 | 制造clamp(ceil(原始配方分钟/10),1,12)，批次按实际完成次数 |
| 有效医疗 | 医疗+4，同次治疗只一次；实际改善健康/出血/病毒至少一项 |
| 玩家攻击命中（含护甲完全抵消为0伤害） | 每个符合防刷额度的命中目标给对应技能+2，同指令可多次 |

> 【实现同步 2026-10-27】有效医疗：草药绷带、抗生素实际生效时各给医疗+4，病毒特效药清除感染同样+4，同次只给一次（详见R04 §4）。工具维护完成按配方基础30分钟给制造经验（clamp(ceil(30/10),1,12)=+3）（开发计划 v0.5 开发假设26/28、试玩修复 L2，提交 afd1af9、aacec17、2e7d872）。

预览、取消、空治疗、被动烹饪、装填、防御不发经验。攻击逐目标独立判命中；同一worldEnemyId/skill最多3次命中经验，巡游、撤退、重接不重置。命中且该目标额度未满：该目标计数+1并给技能+2；未命中不计，已满则该目标不给，但不影响同指令其他目标。推挡属于有命中判定的技能动作，命中同样按本规则计；出血等后续持续伤害不重复计命中。

> 【实现同步 2026-10-27】群攻经验计数（待定 P01）现行口径：一条攻击指令只要有一个受伤目标对该技能未满3次，就给对应技能+2一次；每个受伤且未满3次的目标各自计数+1，并按其 worldEnemyId 保存（撤退、巡游、重接不重置）；已满3次的目标跳过；所有受伤目标都已满则不给；0直接伤害（未命中、护甲完全挡住、推挡）不计数也不给（src/Core/Engine/GameEngine.Combat.cs 约1022–1041行；提交 4fe7736）。注意配置 `xp.counterKey` 字面仍写 encounterId/enemyInstanceId/skillId，程序实际按 worldEnemyId＋技能计数。是否采纳待策划确认，见 [开发方待确认问题](<../00 总则/02 开发方待确认问题.md>) Q4。

升级在完整指令提交后发生，经验逐级扣门槛，不回算本次已结算伤害/医疗；胜利/撤退保留已得经验，死亡不跨局继承。

## 4. 身体消耗与恢复

所有世界时间推进只结算一遍。浏览、预览、排序、拾取、放下、投料、装水是0时间/0体力操作；不能因拖卡次数再扣隐藏E。固定5分钟的食用、饮水、包扎/用药按wait身体速率，额外E=0。点火5分钟按craft速率E−0.1，不算过劳工作；自动设施本身不再扣角色E。

| 行动 | E每游戏小时 | 典型成本/恢复 | N/W/S/M |
| --- | ---: | --- | --- |
| 移动 | −1.6 | 15分钟−0.4 | −1.875/−4.5/−5/−0.5每小时 |
| 探索 | −2 | 30分钟−1 | 同上 |
| 采集/搜集/清理 | −2.4 | 清理20分钟−0.8；采集30分钟−1.2 | 同上 |
| 制造/建造/维护 | −1.2 | 30分钟−0.6 | −1.5/−3.75/−5/−0.5每小时 |
| 等待/食用/饮水/用药 | 0 | 5分钟不改变E | −1.5/−3/−5/−0.5每小时 |
| 休息 | +6 | 30分钟+3 | −1.5/−3/−5/0每小时 |
| 遮蔽睡眠 | +4 | 5小时可由0回20 | −1.5/−3/+12/+1每小时 |
| 露天睡眠 | +3 | 约6小时40分由0回20 | −1.5/−3/+6/−0.5每小时 |
| 战斗 | 自然E率0 | 只付本轮实际招式成本 | −1.875/−4.5/−5/−0.5每小时 |

床垫使睡眠额外+1E/h；精神<20时全部正E恢复×0.5。遮蔽休息额外+2M/h，健康恢复仍需旧营养/遮蔽条件并改为+0.2H/h。零饱食损H0.4/h、零水分1.6/h、零清醒0.4/h、零体力工作0.2/h；腹泻额外W−3/h不随H/E尺度缩放。

木材采集划伤旧H−3改−0.6；村庄杂物箱−2改−0.4；废料场−6改−1.2，概率不变。旧低体力倍率线改为E<4，原夜间/负重/低体力综合倍率上限2保持；变慢后按**实际世界耗时**扣E，不能只按基础分钟扣。

制造高熟练缩短实际耗时，因此也减少相应时间型身体消耗；战斗则用对应武器技能明确省力。不要给所有世界行动再统一乘武器技能省力，避免重复减耗。
