在未实际进入战斗、原请求和地点／角色／资源等条件允许开始探索时，不因当前地点存在已到期且原可主动接近的敌踪先行开战或拒绝探索。玩家点“开始探索”，成功请求按原费用、工作／物资计划与Q605唯一随机签／检查段正常开工；原有到期敌踪等这项探索结束后再检查。不是只容许先做5分钟，也不是为敌人重新抽接近时间。原未到期、探索中才到期的卡同样按本次探索延后。

“一次完整探索”是这次成功开工的同一ActionId自然完成；暂停、做合法补给／休息子行动、中途随机战后暂停、撤退暂存及回原地继续，仍是同一次未完探索，不重抽计划或建立第二次探索。等待结束沿原Q605：原允许的合法退出／放弃或确实无法继续的自动中止，也结束这次延后，立即回原应有检查边界；不借本题新增退出按钮、强制所有探索不可取消或让已取消行动永久保护。只在原探索地点／区域适用，异地活动不受保护。

延后只约束普通敌踪的自动接近。探索本身的随机事件仍在原唯一检查段按原概率／资格判定，命中时短提示后直接被动开战，可中断未完探索；剧情／强制战及真正死亡／尸变继续原优先。当前已有可见组卡使随机概率为0等原门槛不放宽，不因原有卡到期额外抽随机敌人。未能合法开工的请求不产生延后、不扣开工成本／不抽探索签，原失败原因及原边界保持。已经正式提交的战斗不能被后来点击或旧窗口请求撤回为探索。

### 只读、确定性的标准战力估计

本估计用于相对风险排序，取当前编队的直接攻击和承伤能力，不自动替玩家规划治疗、装填、换位、换页、控制连招或潜行成功。没有承诺的先手／受惊结果不计：战外普通查看双方均不预加×1.5或随机恐慌，原来已有真实持续状态照常派生；不会为假设潜行成功先降低等级。此估计不调用真实入战／出手，不消耗随机序列。

1. 建立只读的原合法入场位置与属性投影。双方总健康 `H_A`、`H_E` 为上述活成员的当前健康之和，最低0，不把未发生治疗、未来出血或中毒伤害提前改进真实HP。已经生效的伤病／恐慌等对命中、速度、护甲的修正沿原查询；尚未触发的敌人下一步计划不读取。
2. 对我方每个成员，枚举其当前武器页、当前技能等级／状态／冷却／AP／体力／弹药条件下可以合法发出的直接伤害攻击，含原允许的应急拳击；不含未学技能、无伤害增益指令、未投道具和别人的材料。可选目标集合、保护重定向、穿甲、防御、命中、暴击及伤害区间同原战斗预演，只读不扣费。战外AP取该角色原正常激活预算（`NormalActivationAp`语义，含已有阶位等真实加值），不是沿用上场战斗清零后的AP。未计追击赠AP、随机先手或尚未施放的支援增益。
3. 每个攻击的单次期望伤害 `d = p_hit × [(1−p_crit)×(d_min+d_max)/2 + p_crit×(c_min+c_max)/2]`。区间均已按原目标护甲／格挡等预演扣减，每段各算后相加，不二次扣甲；无暴击能力令 `p_crit=0`。这是评分区间均值，不是修改原伤害抽样算法。概率均为0—1内部实数，不用显示四舍五入后的百分比。单目标技能对所有合法目标的d取算术平均；一次影响多个目标的技能先对该次真实可影响集合加总，再对合法选择集合取平均，不能把同一承伤者重定向重复计两次。
4. 此攻击可重复次数 `n` 为原该正常激活允许次数、`floor(AP预算/AP成本)`、`floor(当前体力/体力成本)`、实际弹仓可供次数／每次耗弹量、剩余耐久可供次数中的最小整数。零体力／弹药／耐久成本项不设该项上限；AP成本为0的攻击和有本回合冷却的攻击最多1次，不能得到无限分。其余原次数限制保持，原不允许重复的动作不能按AP除出两次。为评分只按当前资源快照计算次数，不把第一击后尚未发生的回能、击杀或追击收益再充进n。每成员 `D_i = max(n×d)`，无合法攻击为0，不自动预演一次换位／装填后冒充现在可攻击。
5. 敌人每成员用本敌种配置中原普通攻击／近袭的只读属性和真实位置、AP、状态、已有装备／护甲／增益评估，n同样不超过其原正常激活允许的普通攻击次数。普通攻击定义沿原“意图表第一个抓击／普通攻击类，没有则面板普通攻击，后排型沿其原弱近战”口径；不查询已锁的下一步意图／目标，不把蓄力／信号／保护本回合未攻击当作零战力。对所有合法我方目标的单次d取算术平均。若此刻无正常攻击射程，原规则允许主动前压／迫近后攻击，则使用该原合法动作组合的AP余量与原弱近袭倍率估计；不改真实位置、不触发迎击／随机。完全无原合法伤害路径才记0。后备波次使用该波原合法入场位置同口径，不提前抽AI。
6. 求 `D_A=ΣD_i`、`D_E=ΣD_j`。双方速度 `V_A`、`V_E` 取各自活成员当前原派生速度的算术平均，最低1；只用于有限修正，不把速度当每回合多激活次数。风险指数 `R = (H_E×D_E)/(H_A×D_A) × clamp(sqrt(V_E/V_A),0.75,1.5)`，内部双精度计算，不先取整。原命中／伤害／速度函数继续唯一，评分不反写原参数。

| R区间（后台） | 首屏等级 |
| --- | --- |
| R < 0.35 | 交战风险：很低 |
| 0.35 ≤ R < 0.75 | 交战风险：较低 |
| 0.75 ≤ R < 1.35 | 交战风险：中等 |
| 1.35 ≤ R < 2.20 | 交战风险：较高 |
| R ≥ 2.20 | 交战风险：极高 |

零值优先：没有有效敌方活成员不显示旧风险，详情写“这处敌踪已失效，请重新选择。”；无有效我方活成员／`H_A=0`／`D_A=0`一律极高，双方输出均0也归极高（当前编队不能完成交战），不除0、不输出NaN；我方有有效输出而 `D_E=0` 则很低。数据读取失败或必要定义缺失不猜等级，显示“交战风险：暂无法评估”，开发日志可记缺字段，玩家不见内部ID。这不隐藏其他真实原因或开放无效战斗入口。以上常数为主控授权设计的可调初值，修改需同步本节和验收；不由开发方暗改阈值去迎合某张卡。

不计尚未使用的治疗／支援、反击条件未来触发、未来噪声和感染后果，不能把这个直接攻防估计说成完整胜率。原感染、受惊、主动接近风险提示等真实后果仍在原操作预估中完整保留；不能用“风险很低”盖掉必定触发的剧情／路线限制、不能撤退或感染风险。不展示后台公式、分值、阈值、组成权重或敌方未来动作；玩家只看等级和通用提示“按当前编队与状态评估，仅供参考。”不把成员统计明细拼成公式解释。

### 1. 两类来源不能混用

- **本次探索随机突遇**：按下面的一次检查命中并有真实合法名单，给短提示，然后直接被动入战，不再先出一张让玩家主动处理／再等20—40分钟的随机卡。它可以在探索尚未完成的真实段末中断探索。
- **本地原有卡的主动接近计时到期**：计时仍正常消耗，到期保留0／已到期事实，不重抽、不刷新、不抬回正数；在同一次未结束探索原地点暂缓自动开战，等该探索结束再检查。不是把计时到期当作探索随机命中，也不因此额外抽随机敌人。

延后涵盖同一次探索的运行、原提醒暂停、补给／休息子行动、随机战后原探索暂停，以及原撤退暂存／恢复；这些都不是“探索已完成”。只在玩家当前位于这项未结束探索的原地点／区域时抑制该地普通到期主动接近，原忙碌限制仍不许借此开始其他不合法工作。暂存探索不保护异地的新移动／新地点敌踪，NPC安全区照原硬限制。离地时原地卡只保留其真实到期状态，不追到玩家异地强开战；回到原工作地点而该探索仍未结束时，继续适用该同次延后。

新探索开工前，原空闲边界已到期且此刻可合法入战的卡先按原顺序处理，不允许抢点“开始探索”遮掉已经应开的一战；尚有原保护／权限阻断的卡仍按原理由等待。延后从成功开工的这项探索起生效；继续同一次暂停探索不是新开工，不重抽或重设到期。此条不是“看见敌踪就禁止探索”，未到期普通卡仍不额外拦住原合法开工。

正常完成、原合法退出、原永久失效自动中止、终局／读档实际不再有这项探索时结束延后。取消／中止不是免费完成：先沿原规则处理探索度／物资／经验／预留与已耗时间，再在原安全边界处理当地仍实际存在且有主动资格的到期卡。旧5分钟不可退出规则保持，不新加退出按钮。完成边界先提交探索真实成果一次；死亡／终局和原强制对白优先，之后按Q468先到期、同刻固定→组→单、同类稳定编号检查，一次仅一场。不冻结敌人巡游／死亡／隐藏／保护等真实世界状态，不保留已离开或失效敌人来补战。

### 2. 随机风险仍一次一签，检查提前到真实探索段末

保留原Explore单次风险公式、地点覆盖基数及本地未交战敌对密度；当前全人口全局基数原为0.02，地点有自己探索风险配置时用其原值，不把2%写死所有地点。首战未胜、随机开放日前、NPC／城市／公共／安全地点、旧档保护、已有可见随机组卡等原资格与0概率分支保持。仍只从当地已有合法、未交战敌人选组，沿原容量／组上限、Q436非动物筛选；不凭随机事件新造人口，不用非法动物／固定挑战填名单。

新开探索仍锁一次原EncounterRoll命中签，不按5分钟多次抽。另在同一开工事务锁唯一检查段号：N=max(1,ceil(开工时真实预计分钟/5))，K在1…max(1,N−1)间均匀抽一整数，使用与命中签独立的一次抽签；N=1时K=1。预计取完整倍率与余量，不用30基础分钟冒充预计。K只计本次探索已实际提交的5分钟段，不计暂停补给、休息、战斗或返程段；K与原命中签、已检查回执随原行动／暂存快照保存，预览不抽签，继续／读档不重抽。

在第K个真实探索段完整提交后，以检查当刻真实本地密度和资格，将原命中签与原公式比较一次；无资格、无人可组成组或未命中也立即记已检查，不在末尾再抽／再比。若倍率／余量变化使探索在K之前就完成，则把唯一检查落在该实际完成边界；单段同理。先完成本段世界时间、身体／设施、有效进度和死亡／强制剧情优先事项，不在半个5分钟段插战。由于检查时点改变，取该时点实际密度；不增加每段独立概率或把一次风险累加六遍。

检查命中且名单仍有效时，按原组卡真实身份／名单保存并直接调用被动入战：来源“探索遭遇”，受惊／敌方单方先手沿原被动接敌口径，不发我方潜行成功加成。新组不再抽一份20—40分钟时限来拖延本次遭遇；此次组以已到期／已交战身份保存，原被吸收单卡不再独立排一次到期。超容量、其他未入场卡不被删除或顺带加入；它们仍按本节探索延后或原安全边界等待。原已有可见随机组会使本次随机概率为0，不借新流程叠第二组。撤退后幸存组／真实HP、同卡60分钟保护、死亡／人口／掉落／经验回执继续原规则。

若到检查点时先有原强制对白／剧情要承接，先保留“本检查点待处理”与原行动快照，优先承接它，不提前组敌／入战；对白结束在同一安全边界接续一次检查，不额外推进5分钟。原地点／探索／入战资格已失效则消耗该次检查、不补抽或追到异地；死亡／终局不新开战。待处理与已检查是互斥状态，不能继续和读档各做一次。

### 3. 随机打断不提前交探索成果

若该真实段后探索尚未完成，保留同一ActionId的已做工作、原开工物资计划／遭遇签与已检查回执，转原战斗打断／暂停流程；探索度增量、计划物资、完成经验、余额结算仍须真正完成才一次提交，不能因为进战就先给整次探索成果，也不把已做工作清零。战后回真实暂停画面、玩家明确继续，若撤退则沿原离地保留／返回重验，不自动续做；继续不重复本次随机事件，剩余敌踪到期仍等此同一次探索结束。

若唯一检查落在探索实际完成边界，先提交完整探索结果再随机入战，无未完探索要恢复。随机事件与旧完成后随机卡只保留一条路径，不双形成组／双抽／双写结果。完成边界若随机命中，同时另有在地卡已到期，先承接这次已锁随机战，其他卡留原到期状态；不嵌套战斗或抢在提示之前另开一场，战后原边界再查。中途随机战且原探索仍未完时，其余到期仍延后到探索结束。

### 4. 短提示与真实入战只结算一次

真实入战事务先一次锁定本场、名单、原探索暂停／完成与随机已检查回执；表现上**先提示，后显示可操作战斗画面**，不在提示时推进首回合或敌方动作。提示逐字“探索中遭遇敌人，即将进入战斗。”，可并列真实敌踪名但不泄露未来敌方动作。原入战日志／身份前缀使用“探索遭遇”，不冒充主动接近／潜行，不重复一条“发现敌踪”后再抽计时。

提示为0额外世界分钟的短展示，沿现有单段展示基准：标准1200现实毫秒、快600、慢1800；减少动态效果用静态文字，保留同源可跳过提示。点击／Enter／Space只跳过本提示并交到同一次已锁战斗，不同时执行第一条指令；ESC按真实战斗情境开菜单并暂停提示进度，关菜单续播，原权限保持。展示实现【交开发方定】复用原单段展示／Q572播放层，不新增二次接敌确认或“是否开战”选择。

实际入战时按S14同批清最高顶栏页与整条战前返回链、草稿和旧默认Enter；战后不恢复原窗口，不自动继续探索。到期还在延后、仅查看或普通UI刷新时不提前清窗口。已提交真实战斗随原保存边界保存；读档／刷新若已处战斗直接显示该真实场次，不重新抽遭遇／名单、重播短提示、重新结算探索或发奖。提示被更高强制剧情接管时沿原优先队列，不重启领域事务。

### 5. 预览、状态与旧局

探索正常风险行改“本次探索途中随机遭遇概率{概率}（本地敌对{数量}/上限{上限}）；随机遭遇会短暂提示后直接进入战斗。”。原首战／日期／安全区／已有组／历史保护等排除原因仍各按真实条件；其中探索分支“不会形成随机组卡／完成后发现敌踪”同义词改为“不会触发探索随机遭遇”，清理分支保留原形成卡表述与风险。提示状态“该敌踪已到期，将在本次探索结束后尝试接近。”，必须只对实际被本节延后的合法卡显示，不把可选强敌／中立卡或有撤退保护者误标为即将开战；原保护／性情／时间原因仍优先。

新旧探索按开工规则版本区分。旧已开始且无K／检查回执的探索不逆插中途事件，沿其原已锁签在实际完成边界只检查一次，命中则同样短提示后直接入战；不重抽原计划或中途补奖。对旧未完探索，原地到期延后规则立即按本节读取；旧已存在组卡、战斗、已完成探索回执和已授物资均不因迁移重开／追溯随机战。Q605是全局正式入战窗口清理，其他行动未被本节改成探索或套用其延后。

### Q505 正经验才占现身回执

### Q488 返还来源持续到本次工作终结

因战斗撤退离地而保留过的同一工作，开工来源与Q466返还适用范围持续到该行动最终完成、退出或终局收束。回原地点／区域并成功继续，不删除来源，不改成普通「原料一律退当前地面」：以后再次暂停、恢复、暂存、续接或读档，仍按原随身／原地面来源各释放一次；适用类型继续用Q471单套预告／结果。完成后的正常产物与已经提交的消耗照各自原规则，不把完成当取消返料。

此来源生命周期与Q473「保留暂停期间地图前往放行」分开：成功继续只结束那一次暂停的移动例外，工作历史及来源仍在；普通后续暂停不能仅凭历史标记再移动，除非又满足新的撤退离地保留条件。新一轮保留同一工作不覆盖最初开工来源。原来已保存的同一工作历史／来源随档保存，缺失来源仍按Q466既有真实归属迁移，不按读档时当前地面猜测。其他未曾撤退离地保留的普通工作退出不扩围。

### Q489 出安全屋不触发敌方主动入战检查

成功出屋只提交原出屋状态及原结果，出屋本身不检查、不排入「地图到达」入战边界，不在同一次通知／重绘中补一次检查。屋外已到期的敌踪仍保留到期与排队身份，已有保护按原截止，不刷新接近时限、不额外发保护，不因出屋重抽。下一次原本合法的段提交、战后、强制对白结束、退出行动或真正地图移动到达等边界，才在其原输入锁、事务结算及Q468排序下检查；没有后续边界就保持等待，不凭现实时间或空闲刷新主动开战。出屋带来的单纯提示／浏览不算新边界；确有后续独立强制对白结束则按该独立边界检查。玩家仍可按原入口主动接近。原出屋可用条件与Q473有未结束工作不能进出屋的阻断不变，也不因此跳过下一行动已经应有的边界。

### 潜行与躲避判定

两种判定都耗 5 世界分钟，身体按等待费率。提交时快照队长身份、清醒、精神、潜行等级及目标警惕。清醒、精神用队长实际 0–100 值，等级用 1–10。预览和结算同公式。

```text
Δ（百分点） = 5 × (队长潜行等级 − 敌踪警惕等级)
             + 0.25 × (队长清醒 − 90)
             + 0.20 × (队长精神 − 60)
潜行接近成功率 = round(clamp(50 + Δ, 10, 90)) %
躲避成功率     = round(clamp(60 + Δ, 15, 95)) %
```

round 为最近整数，0.5 向上。持久随机源等概率抽 0–99 的整数，小于显示的成功率为成功。潜行1对警惕1，清醒90、精神60时为50%／60%。潜行4对警惕2、身体值相同时为60%／70%。

#### Q472 只有当前移动可操作，原工作暂存

## 3. 巡游、接敌、噪声与持久化

每180游戏分钟对未交战敌做一次20%巡游判断，至多走一条世界物理相邻边；目标不为camp、不超过目标上限。原地点扣1与新地点加1原子提交，全局数量不变。物理边不依赖玩家是否已发现路线；未知地块名称仍不向玩家泄露。交战敌锁住不巡游，死亡敌不复活；离线不刷新不迁移。

首战胜利后，角色当前地点已有的可见敌人卡可主动接近。雄鹿初始中立，不参加随机攻击池，主动攻击才转敌对。新出生避开当前地块，巡游可进入当前地块并提示“新的敌踪出现”，但不立刻强插战斗。
