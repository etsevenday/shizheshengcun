# R04 免疫、感染与扩展医疗系统

## 2026-11-14 Q652：多途径病毒暴露与同伴不自然增殖（当前优先）

用户明确：抓伤、刮伤、携武器／变异丧尸攻击也可传播病毒，概率和量不同，缺失参数由主控补齐；随后追加“同伴感染病毒不会持续自然增长，可以高免疫和药物治疗”。本节及[Q652参数与当前42敌种逐动作映射](<../assets/20261114/exposure-profiles-q652.json>)为完整策划合同，待开发实现／实机平衡。取代本案、R03、R05、S12及N02／UI逐字稿中“仅咬伤传播”“抓击／喷吐／死亡喷溅不感染”及“同伴与主角完全相同的病毒自然正增长”的对应范围；原正文、【实现同步】和修改记录保留。没有改变免疫小时率、既有药品／医疗冷却、唯二彻底治愈、饱饱归属或V100尸变。

### 传播类型、概率和感染量

仅真实带病毒来源的有效受伤才有外部暴露。基础概率沿原参数同源：p0=clamp(0.05+0.55×(1−clamp(I,0,100)/100),0,1)，I为实际承伤者当刻免疫。各类概率p=clamp(p0×类型倍率,0,1)，内部不按显示百分比先舍入。

| 类型 | p0倍率 | 未感染者成功后V | 已感染者成功时V增量 |
| --- | ---: | ---: | ---: |
| 咬伤（bite） | ×1 | 20 | +10 |
| 抓伤／刮伤（scratch） | ×0.5 | 10 | +5 |
| 污染器械伤（tainted_weapon） | ×0.35 | 8 | +4 |
| 变异体液（mutant_fluid） | ×0.75 | 15 | +8 |
| 冲撞擦伤（impact_abrasion） | ×0.25 | 5 | +3 |

咬伤完全沿原20／10及原概率；其余是本次主控受托设计的可调初值，不是现实医学主张。例I70时，咬伤21.5%、抓伤10.75%、污染器械7.525%、变异体液16.125%、冲撞擦伤5.375%；显示沿原概率精度，真实用未舍入值。每类的“首次”按受伤前infected=false判断，不另建“曾经咬过”终身标记；已因饱饱感染的主角也按再次增量，不重设首次值。未感染成功设infected=true与该类型首次V，已感染成功V=min(100,旧V+该类型增量)，两者均将连续高免疫治愈计时归0。失败不加V、不重置治愈计时。数量和V为原病毒单位，不按本次伤害大小再乘剂量，也不额外扣健康／免疫。

### 真实来源与当前动作覆盖

参数合同对当前42敌种的每一opening／cycle步骤、咬击替换、普通物理攻击回退及死亡喷溅均列明确profile。运行判定用真实敌种／步骤键与实际事件类型，不按中文动作名猜分类、不读取下一次尚未执行的意图。丧尸真实咬击优先只用bite一次；普通爪抓／挥击为scratch，防护尸撞击和一般身体冲撞为impact_abrasion；机修敲击、指定重型污染器械、扫击／带伤缠线拉扯为tainted_weapon；酸液喷吐及膨胀感染者死亡喷溅为mutant_fluid，具体逐项以JSON为准。污染器械是传播来源分类，不给敌人生成可掉落武器或改其伤害动作。

追击、迫近弱近袭和降格弱近战仍不改成咬击，但有真实丧尸来源的伤口按该敌种defaultPhysicalExposure判定；不能继续用plain／不是bite作为全部免感染条件。纯拉扯0直接伤害、标记、格挡、保护、蓄力、嚎叫、鼓动、装填、移动、逃离等非伤害步骤为none，不凭名称附加感染。普通人类、普通动物所有现有攻击为none；动物撕咬／出血不等同丧尸病毒。没有带病毒来源的普通采集刮伤、饮食／腐败／尸体加工、环境伤害不被本题泛化为病毒事件；以后新增传播源须明确其profile，不借旧物名暗加病毒。当前映射不得漏项；新敌种／攻击种类接入须补合同及配置校验，不静默以未知名字猜成咬伤或无感染。

### 命中、承伤、生命态与随机顺序

须命中且扣护甲、格挡、掩护等原实际减伤后的伤害D>0；未中、完全挡住、纯控制、0伤不取感染随机数。实际保护者承受伤害则只对保护者用其本人I／V判，原被保护者不多判；范围／多段每个真实承伤者、每个真实正伤命中各一次，单次命中不得把bite与抓伤或体液重复叠算。持续出血／同伤害的日志与动画不再暴露。死亡喷溅逐我方原1、2号位实伤者判，原目标／护甲扣减不改，只有其真实正伤才暴露。原喷溅没有命中抽签，按已造成的真实正伤事件进入暴露，不新增一次命中判定。

该命中先沿R09提交真实伤害和生命判定；已确死者停止后续感染，不为死者抽感染或运行新警告。濒死仍存活者（包括H0→H0但真实D>0）继续合法感染判定，不能看HP扣减差是否0漏判；V达到100仍原独立尸变，意志不能抵抗。感染加入原命中后续感染阶段，原控制／出血／反击先后保持；“非咬也判感染”不能把原非咬控制／出血else分支吞掉，也不因普通攻击plain新增本来没有的控制／流血。原成功咬伤随机位置保持，新途径在同阶段增加自己唯一的一次判定，后续仍原顺序。

均匀u∈[0,1)，u<p成功、相等失败，沿原可信随机流。稳定真实命中事件＋承伤者＋类型的一份结果、随机游标、V／计时／日志与原攻击同事务唯一提交；预演、hover、信息折叠、播放、重复请求、保存重读均不再抽签或加V。不是每次打开右栏重新掷感染。一次攻击范围多人仍各本人I独立判定，不复用第一人的结果；沿原目标顺序，不改变敌人抽目标／咬击替换概率。

### 同伴病毒不随时间自然上涨

以稳定角色ID区分主角与所有非主角可控同伴，同行、候补、驻屋／留守一致，不按当前FocusOn对象或右栏查看者误认主角。同伴已感染时自然病毒速率r_companion=min(0,原R04按I／药效算出的自然速率)：I<80原正增长段改为0，I≥80原−1.5/h保留及原未彻底治愈前最低V1；未感染仍V0。主角原自然增长、下降和饱饱输入完整保留，同伴无饱饱持续输入，不能因新感染类型给同伴造体内菌株。

这只免除自然正增长，不免疫新的成功攻击暴露、原明确瞬时病毒事件或V100尸变；同伴可因新的真实暴露按本表再次加V。抗生素即时减V8、包扎原减量与独立6小时冷却／抑制剂最低1等照旧，正增长抑制因子在同伴0速率上不产生负增长或额外治疗。I≥80连续720分钟且V≤10的原自然彻底治愈、原特效药清感染都可用于同伴；不因“不增长”直接清infected、不新增普通药第三治愈，也不绕原位置、材料、次数和医疗冷却。高免疫计时仍按原段首／段末共同满足规则，成功新暴露仍重置。

同伴详情／预估的每小时病毒变化必须反映真实0或下降；禁止从旧全员增长公式显示“约X小时尸变”。说明句：“同伴病毒不会自然增长；新的感染暴露仍可能增加病毒量，高免疫和药物治疗按实际效果结算。”没有新暴露时低I静置不会自己涨到100，不因后台离地、休息、撤出或候补推进换回主角速率；主角则仍有原进展风险。

## 2. 病毒暴露、增长与尸变

外部暴露仍只有**丧尸咬击命中且造成正直接伤害**才判；另有饱饱的持续体内输入，见§7。抓击、动物撕咬、护甲完全挡住的攻击不判外部僵尸病毒暴露。动物仍可造成出血，不混同为僵尸感染。

```text
一次有效咬击的感染暴露概率 = 0.05 + 0.55×(1−I/100)
I=0：60%；I=40：38%；I=70：21.5%；I=85：13.25%；I=100：5%
```

初次暴露成功：infected=true、V=20、连续高免疫计时=0。已感染后再次成功暴露：V+10、计时重置；判定失败不额外加病毒。一次咬击不做两次暴露判定，结果随攻击事务保存，不因读档重抽。

已感染时V按段首I进展：

| 段首免疫 | V每小时变化 |
| --- | ---: |
| 0≤I<40 | +4 |
| 40≤I<70 | +2 |
| 70≤I<80 | +0.5 |
| 80≤I≤100 | −1.5，但未满足治愈前最低1 |

V≥100即尸变，本局结束。未感染状态下V为0，但饱饱输入仍参与后续世界tick；实际净增长导致V>0时进入感染状态。T09建议首次体内净输入为正时infected=true、V最低置1，不套外部初次咬伤V20；后续连续进展见§7.2，数值已批准实装。V不低于0。20/50/80提供阶段警告、当前变化速率与理论剩余时间；理论时间假设I与用药条件不变，不能写成必定死亡倒计时。

## 3. 唯二的彻底治愈

### 高免疫持续自然治愈

必须同时满足：I≥80连续720游戏分钟，且V≤10。满足后将infected清除、V归0、计时清0。

任何一段I跌到80以下，或发生新的成功咬伤暴露，连续计时归0。计时只在该段段首与段末均≥80时增加5分钟，避免刚跨线就白拿完整一段。达到12小时但V还高则继续维持I，直到V≤10才治愈，不在12小时无条件清病毒。

例：I80、V20，营养与状态维持良好，12小时后自然V已到2，满足条件治愈；I80、V80，12小时后仅降至62，仍感染。高免疫可能需要更长照护；抑制剂能降低V、帮助进入可治愈区间，但不替代连续时间。

### 病毒特效药

使用antiviral_cure1份立即清infected、V和高免疫计时；不额外回健康、回体力或永久加免疫。战外5分钟wait、战内2AP。游戏已尸变/死亡后不可补救。

> 【实现同步 2026-10-27】特效药清除感染时给医疗经验+4（见§4）。清除感染后，左栏的抗生素作用与给药间隔仍显示到原截止时刻（对病毒已无影响）；是否在清除感染时一并结束待确认（开发计划 v0.5 待确认11）。

免疫与V在同一tick更新后，先判健康死亡/尸变，再判自然治愈。病毒达到100不能被同段计时刚满强行拉回。医疗技能、睡眠、绷带、抗生素或其他食品不能额外提供第三个“清感染状态”入口。

## 7. 饱饱与丧尸感染的背景边界

用户已确认：饱饱会持续缓慢提高R04同一病毒程度V，高免疫能将其遏制在安全范围。自然治愈或病毒特效药清除的是当前感染/病毒程度，不移除饱饱，也不永久停止它的输入；之后仍可缓慢重新积累。它不另设第二条病毒值，也不直接提供免疫加成。新局仍按当前I70/V0开始，后续世界tick接入其输入；输入速率、免疫抵消与安全目标已给T09已批准实装初值，见§7.2，不沿用外部初次咬伤V20。

外部咬伤概率、I70/V0初值、唯二彻底治愈入口与V≥100尸变终局保持；“感染只来自咬伤”被本次饱饱持续输入取代。吞噬普通白色活性物质本身仍不额外改变I/V、不治疗感染、不新增随机免疫词条；不得把持续输入按每次融合或每次对白重复触发。

### 7.1 持续输入与免疫结算约束

- 只随唯一世界时间tick推进，移动、睡眠、战斗与药物耗时均计，浏览/离线/对白不计。输入是持续源，不是每段新增一次咬伤暴露，不反复抽感染随机、不每段重置高免疫计时。
- 将饱饱输入、现有免疫控制与药物作用放在同一病毒结算中处理。高免疫条件下必须能让V净增量≤0并保持安全；不是只把+速率变小但最终必定尸变。T09建议I≥80时体内输入被完全压制，已感染时仍按原高免疫进展率−1.5/h降低V；安全管理目标V≤10，见§7.2。
- 已感染时，绷带与抗生素仍只能抑制且不能直接清状态；特效药和连续高免疫仍为唯二治愈入口。治愈事务只清当前infected/V/高免疫计时，baobaoPresent保持true；下一段仍可产生新积累，不同一治疗请求重复清除或发医疗经验。
- 已感染的最低1约束、未感染0状态以及体内输入首次转感染的边界必须一起定义，不能出现V>0却写“未感染”，也不能因每段重新种入而让12小时自然治愈永远无法完成。先判死亡/尸变，后自然治愈的优先级不变。
- 右栏与感染说明明确“饱饱持续影响”“当前净变化”“高免疫可压制”，不宣称治愈后永久免疫。本次新参数待程序对齐，不因文档已批准就宣称已实现。

```text
B(I) = 0.05 × clamp((80 − I)/40, 0,1)   # baobaoPresent=false时B=0
R(I) = 原§2已感染进展率：4 / 2 / 0.5 / −1.5
已感染净速率 = B(I) + R(I) × 药物系数
药物系数：抗生素有效且R(I)>0时0.5，其余1；不把负恢复减半
未感染时：只看B(I)，若本段B=0则保持V0未感染；若B>0才按上表种入
```

抗生素只减缓已感染进展R，不永久/暂时关闭饱饱输入B；绷带和特效药仍按原规则影响当前V。I70时B≈0.0125/h，已感染净+0.5125/h；I40时净+2.05/h；I0时+4.05/h；I80以上B0、已感染净−1.5/h。B不因为本tick感染标记已存在而被重复加两次。

自然治愈/特效药清当前infected/V，饱饱不被删除；I仍≥80时B被压制、不会下一tick无条件再种入。之后I跌低使B>0，可重新积累/进入感染；这是既有输入源恢复作用，不是新药物失效或永久免疫。连续高免疫计时不因持续源本身重置；只有原规则的跌破阈值或成功外部咬伤重置。

既有旧档不自动开启饱饱输入，不补教学+0.1；若将来决定为旧档开放共生机制，应另做明示迁移，不按字段缺失反复初始化。世界里已存在的高层敌人保留，未来出生按当前日期阶段过滤。
