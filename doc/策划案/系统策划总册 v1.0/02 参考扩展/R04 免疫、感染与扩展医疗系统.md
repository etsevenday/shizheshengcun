## 1. 免疫变化主表

每5分钟读取段首状态，按每小时速率×5/60更新I并限制0—100。以下修正相加：

| 条件 | 免疫每小时变化 |
| --- | ---: |
| N≥50、W≥50、S≥50、H≥健康上限50%、M≥40同时满足 | +0.5 |
| 遮蔽睡眠/露天睡眠 | +2 / +1 |
| 遮蔽休息/露天休息 | +1 / +0.5 |
| 其他动作、等待、浏览本身 | 0；浏览不推进任何恢复 |
| N<20 / W<20 / S<20 | −2 / −3 / −2，可叠加 |
| H<5 / M<20 | −2 / −1 |
| 腹泻 / 已感染病毒 | −1 / −0.5 |

睡眠不是无条件免疫药：缺水、缺营养等惩罚照常计算。感染但营养良好的清醒角色，健康奖励+0.5与感染惩罚−0.5相抵；遮蔽睡眠在此基础上+2/h。食物仍按其N/W/M效果间接支撑免疫，不再让每吃一口普通食物直接加I。

I是生存管理结果，不是打怪升级属性；不会用制造/医疗等级自动把I永久推满。离线不恢复。

## 2. 病毒暴露、增长与尸变

外部暴露仍只有**丧尸咬击命中且造成正直接伤害**才判；另有饱饱的持续体内输入，见§7。抓击、动物撕咬、护甲完全挡住的攻击不判外部僵尸病毒暴露。动物仍可造成出血，不混同为僵尸感染。

```text
一次有效咬击的感染暴露概率 = 0.05 + 0.55×(1−I/100)
I=0：60%；I=40：38%；I=70：21.5%；I=85：13.25%；I=100：5%
```

初次暴露成功：infected=true、V=20、连续高免疫计时=0。已感染后再次成功暴露：V+10、计时重置；判定失败不额外加病毒。一次咬击不做两次暴露判定，结果随攻击事务保存，不因读档重抽。

已感染时V按段首I进展：

| 段首免疫 | V每小时变化 |
| --- | ---: |
| 0≤I<40 | +4 |
| 40≤I<70 | +2 |
| 70≤I<85 | +0.5 |
| 85≤I≤100 | −1.5，但未满足治愈前最低1 |

V≥100即尸变，本局结束。未感染状态下V为0，但饱饱输入仍参与后续世界tick；实际净增长导致V>0时进入感染状态。T09建议首次体内净输入为正时infected=true、V最低置1，不套外部初次咬伤V20；后续连续进展见§7.2，数值已批准实装。V不低于0。20/50/80提供阶段警告、当前变化速率与理论剩余时间；理论时间假设I与用药条件不变，不能写成必定死亡倒计时。

> 【实现同步 2026-10-27】20/50/80 阶段警告只写日志与提示（含当前变化速率与理论剩余时间），不暂停当前行动，与其他会暂停行动的阈值提醒不同（src/Core/Engine/GameEngine.Immunity.cs 约96行；开发计划 v0.5 开发假设25，提交 aacec17）；是否符合预期待确认（开发计划 v0.5 待确认6）。尸变复用死亡结算界面，文案与生命耗尽区分（开发假设12）。

## 3. 唯二的彻底治愈

### 高免疫持续自然治愈

必须同时满足：I≥85连续720游戏分钟，且V≤10。满足后将infected清除、V归0、计时清0。

任何一段I跌到85以下，或发生新的成功咬伤暴露，连续计时归0。计时只在该段段首与段末均≥85时增加5分钟，避免刚跨线就白拿完整一段。达到12小时但V还高则继续维持I，直到V≤10才治愈，不在12小时无条件清病毒。

例：I85、V20，营养与状态维持良好，12小时后自然V已到2，满足条件治愈；I85、V80，12小时后仅降至62，仍感染。高免疫可能需要更长照护；抑制剂能降低V、帮助进入可治愈区间，但不替代连续时间。

### 病毒特效药

使用antiviral_cure1份立即清infected、V和高免疫计时；不额外回健康、回体力或永久加免疫。战外5分钟wait、战内2AP。游戏已尸变/死亡后不可补救。

> 【实现同步 2026-10-27】特效药清除感染时给医疗经验+4（见§4）。清除感染后，左栏的抗生素作用与给药间隔仍显示到原截止时刻（对病毒已无影响）；是否在清除感染时一并结束待确认（开发计划 v0.5 待确认11）。

免疫与V在同一tick更新后，先判健康死亡/尸变，再判自然治愈。病毒达到100不能被同段计时刚满强行拉回。医疗技能、睡眠、绷带、抗生素或其他食品不能额外提供第三个“清感染状态”入口。

## 4. 抑制治疗与药物取得

| 物品 | 病毒/身体效果 | 限制 |
| --- | --- | --- |
| 草药绷带 | 止血；医疗公式回血；已感染时V减少2×(1+0.01医疗L) | 回血60分钟冷却；病毒减量另有6小时冷却；V最低1，不清infected |
| 抗生素 | V立即−8，之后6小时正向进展×0.5 | 给药间隔6小时；不叠乘，负向自然恢复不被减半；V最低1，不清infected |
| 病毒特效药 | 清病毒状态，V归0 | 极稀有，只有本条药物入口能直接治愈 |

绷带处于回血冷却但病毒效果就绪，可只抑制/止血；两种效果都无实际收益且没有出血时禁用，明确原因。病毒减量实际生效或健康/出血实际改善才给医疗经验，同次使用只发一次。

> 【实现同步 2026-10-27】草药绷带、抗生素实际生效时各给医疗经验+4，病毒特效药清除感染同样+4，同次只给一次（GameEngine.Immunity.cs 约275行；开发计划 v0.5 开发假设26、试玩修复 L2，提交 aacec17、2e7d872）。绷带在回血冷却中使用时，卡下操作条、右栏预估与结果都写“回血冷却中（还需N），本次不回血”，已感染且减量就绪时列出“病毒a→b（仍感染）”；药品预估一律写使用当下的实际效果（开发假设36、试玩修复 G4，提交 2e7d872）。

回血冷却与病毒冷却分别仅在对应效果实际生效时启动；未感染时包扎不消耗病毒减量冷却，只止血不延长原回血冷却。抗生素的6小时作用按段首是否在有效期判断，最后一个完整5分钟段仍可生效，不提前少算一段。

药物把V从2减到1时，角色仍感染；不能把“数值接近0”当治愈。若玩家另外已经满足高免疫720分钟，药物减量后在下一次世界tick可能触发**自然治愈**，日志必须记为高免疫治愈，而不是宣称绷带或抗生素直接治好。

特效药取得建议：诊所探索100%新增一次性医药补给箱，固定抗生素2+实验室试剂1，另独立1%概率附带特效药1；村庄探索100%新增一次性废弃冷藏箱，20%抗病毒前体1、80%草药绷带2。旧箱内容不覆盖、不读档重抽、不为已访问旧档补发。

特效药配方：医疗≥15、制造≥12，抗病毒前体1+实验室试剂1+抗生素2+草药4+净水2，营地制作、原始120分钟，需明确指定取下并清空的锅作为不消耗催化工具。净水作为明确原料消耗，不自动装锅、补水或倒出原锅内容。稀缺前体与高技能门槛让制作困难，不保证每局都能找到前体；自然免疫是稳定可规划的主要治愈途径。

## 6. 显示、保存和接入边界

I初70、V初0、infected=false；小数与精度按R01。人物详情在S14右栏人物页，状态警告显示当前I/V、进展、药效和连续高免疫时间；不能用“已恢复”掩盖V最低1且仍感染。左HUD若扩展状态指示也只引用同一数据，不恢复左侧自身投放卡。

保存infected/V/I、高免疫分钟、药效截止、独立冷却与暴露随机结果。每段先使用段首状态计算，再更新并判健康/尸变终局，之后才判自然治愈。离线不恢复免疫、不自动服药、不拼接不连续高免疫时间。

本案所称病毒和药物效果为虚构游戏机制，不套现实药理。没有新增感染的第三治愈入口、部位咬伤、缝合或复杂外科系统；后续新增必须修改本案治愈白名单与终局验证。

## 7. 饱饱与丧尸感染的背景边界

用户已确认：饱饱会持续缓慢提高R04同一病毒程度V，高免疫能将其遏制在安全范围。自然治愈或病毒特效药清除的是当前感染/病毒程度，不移除饱饱，也不永久停止它的输入；之后仍可缓慢重新积累。它不另设第二条病毒值，也不直接提供免疫加成。新局仍按当前I70/V0开始，后续世界tick接入其输入；输入速率、免疫抵消与安全目标已给T09已批准实装初值，见§7.2，不沿用外部初次咬伤V20。

外部咬伤概率、I70/V0初值、唯二彻底治愈入口与V≥100尸变终局保持；“感染只来自咬伤”被本次饱饱持续输入取代。吞噬普通白色活性物质本身仍不额外改变I/V、不治疗感染、不新增随机免疫词条；不得把持续输入按每次融合或每次对白重复触发。

### 7.1 持续输入与免疫结算约束

- 只随唯一世界时间tick推进，移动、睡眠、战斗与药物耗时均计，浏览/离线/对白不计。输入是持续源，不是每段新增一次咬伤暴露，不反复抽感染随机、不每段重置高免疫计时。
- 将饱饱输入、现有免疫控制与药物作用放在同一病毒结算中处理。高免疫条件下必须能让V净增量≤0并保持安全；不是只把+速率变小但最终必定尸变。T09建议I≥85时体内输入被完全压制，已感染时仍按原高免疫进展率−1.5/h降低V；安全管理目标V≤10，见§7.2。
- 已感染时，绷带与抗生素仍只能抑制且不能直接清状态；特效药和连续高免疫仍为唯二治愈入口。治愈事务只清当前infected/V/高免疫计时，baobaoPresent保持true；下一段仍可产生新积累，不同一治疗请求重复清除或发医疗经验。
- 已感染的最低1约束、未感染0状态以及体内输入首次转感染的边界必须一起定义，不能出现V>0却写“未感染”，也不能因每段重新种入而让12小时自然治愈永远无法完成。先判死亡/尸变，后自然治愈的优先级不变。
- 右栏与感染说明明确“饱饱持续影响”“当前净变化”“高免疫可压制”，不宣称治愈后永久免疫。T09未定前不把新机制描述为已完成实现。

### 7.2 T09持续病毒压力建议初值

**以下为用户已批准实装的可调初值（2026-10-27）。** 程序可直接按本案实现，用户测试后不合适再调整。批准不等于程序已完成；后续调整直接更新本案和更新日志，不另建并行配置。

| 参数 | 建议初值 | 用意 |
| --- | --- | --- |
| baobaoPresent | 新局true；本轮旧档false，不自动补发共生剧情/机制 | 新局体验完整；旧档原玩法保留 |
| 低免疫最大体内输入Bmax | +0.10V/h | 持续缓慢压力，不取代已感染后的进展率 |
| 完全压制阈值 | I≥85 | 与现有高免疫自然治愈门槛一致 |
| 输入减弱带 | I40至85线性降低 | 免疫提升在到达85之前已有收益 |
| 安全管理目标 | V≤10 | 同现有自然治愈病毒门槛；仍感染，不等于免咬伤/免死亡 |
| 首次体内转感染 | 净输入为正且当前未感染时，V置max(1,本段实际增加)，infected=true | 最低1沿用感染下限，不跳到咬伤V20；初次明显变化只一次 |

```text
B(I) = 0.10 × clamp((85 − I)/45, 0,1)   # baobaoPresent=false时B=0
R(I) = 原§2已感染进展率：4 / 2 / 0.5 / −1.5
已感染净速率 = B(I) + R(I) × 药物系数
药物系数：抗生素有效且R(I)>0时0.5，其余1；不把负恢复减半
未感染时：只看B(I)，若本段B=0则保持V0未感染；若B>0才按上表种入
```

抗生素只减缓已感染进展R，不永久/暂时关闭饱饱输入B；绷带和特效药仍按原规则影响当前V。I70时B≈0.033333/h，已感染净+0.533333/h；I40时净+2.1/h；I0时+4.1/h；I85以上B0、已感染净−1.5/h。B不因为本tick感染标记已存在而被重复加两次。

自然治愈/特效药清当前infected/V，饱饱不被删除；I仍≥85时B被压制、不会下一tick无条件再种入。之后I跌低使B>0，可重新积累/进入感染；这是既有输入源恢复作用，不是新药物失效或永久免疫。连续高免疫计时不因持续源本身重置；只有原规则的跌破阈值或成功外部咬伤重置。

既有旧档不自动开启饱饱输入，不补教学+0.1；若将来决定为旧档开放共生机制，应另做明示迁移，不按字段缺失反复初始化。世界里已存在的高层敌人保留，未来出生按当前日期阶段过滤。

本组参数需检查：玩家不管理I时有长期危险；正常饮食/遮蔽睡眠能逐步达到85并控制V；治疗只清当前值、低免疫后仍可再次积累。数值推演见A02新增记录，不能当作工程试玩通过。
