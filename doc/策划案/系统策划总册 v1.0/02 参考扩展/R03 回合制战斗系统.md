## 1. 战斗结构、站位与先手

单玩家对至多3敌：前排F1/F2、后排B1。玩家每次激活2AP，敌每次激活1动作；每轮每人只激活一次，未用AP清零。近战/远程目标范围读R02。

有效速度`max(0.1,基础速度−[E<4]−[S≤20]−减速2)`；每轮先手=有效速度+均匀整数1—4，降序、平手稳定实例ID，轮初固定队列，不在轮中因付体力重排。意图轮初锁定公开，实际不合法时按公开的前压/等待备用，不偷换高伤害。

前排死即移除；轮末存活后排压到最左前排空位，不多激活。轮中前排全空可直接攻击后排；仍有前排屏障时后排近战敌执行前压/等待，不隔人抓咬。远程/嚎叫可按合法意图行动。

## 2. 命中、暴击、伤害与恐慌

命中能力A与闪避能力D均为正值：

```text
A = (武器基础A+3L) × 招式命中系数 × 身体状态系数
实际命中概率 = A/(A+D)
暴击能力C = 武器基础C+0.3L
命中后暴击概率 = C/(C+100)
直接伤害建议 = max(0, 随机基础伤害×技能倍率×招式倍率×站位倍率×暴击倍率 + 平加攻击力 − 护甲)
平加攻击力：无词条为0；教学词条为+0.1（结算层为待审阅初值，数值+0.1已定）
防御生效时，直接伤害再×0.5
```

随机基础伤害在武器区间内连续均匀取值；暴击倍率1.5。敌人用固定攻击能力，无技能倍率、无暴击。取消原5%—95%命中夹紧、30%暴击上限和最低1伤，不对最终伤害取整。护甲高于伤害可完全挡住该次直接伤害；此时仍按R01计命中经验，但不触发要求正伤害的咬伤暴露。

玩家闪避能力36。普通游荡尸攻击能力20，对玩家命中20/(20+36)=35.71%。1级简易斧命中能力27，对游荡尸闪避25，命中51.92%。玩家每轮2AP，敌人一次动作，且玩家H20而普通尸H3.6，提供前期优势；低命中不等于让前期玩家与怪物完全对等。

身体修正乘命中能力，不直接扣百分比：E<4时×0.85、S≤20时×0.85、P≥60时×0.85、P≥90改×0.70（后两者择一）、失衡×0.90。技能越高仍持续改善，不被固定95%封顶。恐慌基础值(100−M)/2，受惊附加值依下方§2.1；直接受伤后P增加实际伤害×1.5；战后精神−min(5,P/20)，不因缩小伤害导致恐慌完全不涨。

> 【实现同步 2026-10-27】受惊加成：敌踪选择里选“接敌”按受惊遭遇入场，恐慌在 (100−M)/2 之上额外+10（配置 `panic.surpriseBonus: 10`，取自 v0.5“受惊遭遇再+10”）；主动接近地块敌踪卡不加（src/Core/Engine/GameEngine.Combat.cs 约175行；开发计划 v0.5 开发假设21，提交 4fe7736）。是否保留待策划确认，见 [开发方待确认问题](<../00 总则/02 开发方待确认问题.md>) Q3。

本次命中的低体力修正以支付本次招式成本后的E为准，预览也按这一值计算；轮初先手仍按轮初E，不能在轮中重排整个队列。

实际能力值趋近无穷时概率趋近100%但不超过；这与“允许100%后继续变成150%命中”不同。若未来需要溢出命中转暴击，应单独立项，不在本版暗中转换。

玩家基础速度/闪避/护甲读R01。群攻按槽位逐目标独立判命中、暴击和伤害，成本每指令一次。敌无暴击、无技能成长。恐慌P限制0—100，入战与战后公式见上；S/N/W生存损伤仍沿世界tick。

> 【实现同步 2026-10-27】群攻的经验计数（待定 P01）现行口径见R01 §3 的【实现同步】：每指令至多+2一次，受伤且未满3次的目标各计1次，0伤害不计。

### 2.1 本轮Q3：精神与敌人威慑的受惊模型

本节取代§2和R05§3中“敌踪接敌固定恐慌+10、主动接近必不受惊”的【实现同步】，原记录保留。恐慌基础值仍为(100−M)/2；额外受惊改为概率事件，不再不经判断固定+10。

每类敌人具有“基础惊吓概率”与“惊吓值”两个独立字段，主表归R05。每次新入战时用实际入战精神M及合法参战敌人生成受惊计划，概率必须随精神升高而下降；按遭遇情境区分主动接近、探索/清理接敌、剧情首战，不把按钮文字当唯一判定条件。同一battleId只判一次，读档/回调/换目标不重抽；受惊只改变本次恐慌，不直接扣精神、H或E，战后精神仍按现行恐慌公式结算。

**以下数值为策划建议初值，按用户要求供审阅，尚非用户逐项确认或程序已实施的参数。** 用户已定的规则方向保持，接受/调整后直接修改本案，不另建并行配置。

T01建议公式：

```text
q = 主惊吓源敌人的基础惊吓概率（R05）
p = q × (1 − clamp(M,0,100)/100) × K
入场P = clamp((100 − M)/2 + [u < p] × 该敌惊吓值, 0,100)
K：主动接近0.5；探索/清理接敌1.0；剧情首战1.0
```

多敌只选一个主惊吓源：基础概率最高，平手取惊吓值较高，再平手按worldEnemyId稳定顺序。只判一次，不对每敌叠加惊吓；这个选择只维护一次惊吓的来源，不改变敌人实际攻击。

为防撤退重接刷受惊结果，每世界敌人存均匀随机u及生成世界分钟，60游戏分钟内用同一个u；每次新入战仍按当时M/情境重算p。超过60分钟首次再入战才重新生成u。主来源改变使用该敌自己的缓存；同一battleId的M快照、u、p和结果始终锁存，读档不重抽。

例：M60遇游荡尸，随机/教学受惊率14%，主动7%；未受惊入场P20，受惊P26。M85随机游荡尸5.25%，M0遇嚎叫尸65%，M100所有敌种受惊率0；基础恐慌、受伤增P与战后精神结算继续有效。

P01经验现采用逐目标命中+2（含0伤命中），额度与防刷由R01唯一维护；推挡命中也计，持续伤害不重复计。教学首战使用普通战斗规则，场上唯一游荡尸，不自动调入其他敌人，见S15。

## 4. 临时状态

| 状态 | 时序与效果 |
| --- | --- |
| 出血 | 自己激活开始扣H0.4，最多3次；不叠伤害，重复刷新次数；丧尸免疫 |
| 失衡 | 下次实际攻击命中能力×0.9，用后消失，最迟下一轮末 |
| 减速 | 下一轮速度−2，下一轮末清除，同来源不叠 |
| 防御 | 下次自身激活开始清除，此前挡一次直接伤害，挡后移除 |

激活顺序：自身出血→判死→清旧防御→恢复该次AP。出血不吃甲或防御。战后剩余出血改每世界tick扣0.4并继承次数，下一次tick才触发，退出轮末不额外重复扣。

## 5. 撤退、胜利与死亡

撤退概率`sigmoid((己方有效速度−敌方最高有效速度)/3+0.7)`，P≥60×0.9、P≥90改×0.8；体力不足可强撤，概率再×0.75，无旧20%—90%夹紧。sigmoid(x)=1/(1+exp(−x))。

成功回当前地点，不传回营地；失败耗AP、其余敌正常行动。胜利为敌全死或逃离；符合条件的最终战利品落当前地面，生命/体力不自动补满。撤退不发未结尸体/掉落，存活敌HP与经验计数交R05保留。所有终局优先健康0或尸变，不因同指令杀最后敌复活。

> 【实现同步 2026-10-27】撤退成功放弃本场已倒下敌人的尸体与掉落（只有胜利才一次落地）；只有场上确有倒下敌人时，结果文案才写“放弃了场上的尸体与掉落”。存活敌回世界池并保留HP与经验计数（开发计划 v0.5 开发假设31、试玩修复 L3，提交 4fe7736、2e7d872）。是否符合预期见开发计划 v0.5 待确认5。

## 6. 唯一世界tick

每个已有有效指令的轮只推进一次5分钟；中途胜利/撤退也由pendingTick防重，只浏览未确认指令不推进。N/W/S/M按战斗小时率−1.875/−4.5/−5/−0.5，E只付动作，不再扣gather自然E；E=0的过劳健康伤害按R01缩放值。

燃料、烹饪、清理恢复、保质和免疫/病毒同tick更新。直接伤害或轮初出血致死时不补未来轮末tick；轮末tick致死则该段已发生，不回滚/不多补。

战内低值用非阻断警告，不打开旧补给子行动；食用/饮水禁用，医疗走2AP，不能从卡下按钮绕过。普通地图移动/制作/休息、地面转移/投料/装水也禁用。

> 【实现同步 2026-10-27】战斗中卡下的绷带、抗生素、特效药改发2AP战斗指令（U728），食物、饮水禁用（开发计划 v0.5 开发假设9，提交 b42b111）。
