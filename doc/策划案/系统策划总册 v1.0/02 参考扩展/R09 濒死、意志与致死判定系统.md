# R09 濒死、意志与致死判定系统

提出日期：2026-11-14。来源：Q616用户直接新增规则及四项补充答复。状态：完整策划目标，待开发接入与实机验证；本案不是运行代码或已上线说明。数值与状态参数见[Q616策划参数合同](<../assets/20261114/dying-willpower-q616.json>)，与本案同步维护。

## 1. 已定目标与替代范围

我方角色健康归零先进入濒死，后续正伤害才判定彻底死亡；意志越高，抵抗致死的概率越高。角色濒死时保留原合法战斗与战外操作，不附加属性减益；必须用药或医疗实际回血才能脱离，濒死期间不自然回血。敌人没有濒死，健康归零直接死亡并退出战场显示，不留阻挡攻击的尸骸。

本案取代R01／S01／S12／R03／R08及相应【实现同步】中“我方H≤0立即死亡／主角终局／队友清队列并留遗物”的对应范围；原实现同步和修改记录保留，由开发对齐新规则。取代Q571／Q616旧“出血归零只更新状态而不表现”的生命姿态变化部分。没有修改病毒达到尸变阈值等独立终局、实际死亡后的永久性、我方容量、掉落、医疗资源／冷却、原伤害计算或时间推进规则。

## 2. 角色三态与资格

| 领域状态 | 健康与事实 | 资格与显示 |
| --- | --- | --- |
| 正常存活 | H>0，未被确认死亡／尸变 | 原正常动作／治疗／成长／名册规则。 |
| 濒死存活 | H=0，尚未确认死亡／尸变 | 仍是活人、仍在原槽位／编队／队伍；可按原条件攻击、支援、用药、移动、撤退以及战外赶路、探索、采集、制造、休息、补给等。显示黯淡的单膝跪／全跪／趴卧姿势；不自动清AP、不跳过激活、不交遗物、不触发同伴死亡恐慌。 |
| 确实死亡 | 致死抵抗失败，或原独立尸变／死亡事件已确认 | 原永久死亡／遗物／终局等规则；医疗不能复活。 |

适用于主角、同行者、在册候补／驻屋者等原有真实身体状态的人物；不因新案把服务NPC变成战斗／医疗对象，不给敌人增加意志或濒死。濒死不删除原已生效出血、感染、虚弱、恐慌等状态，也不新加濒死／恢复后的攻击、命中、速度、防御或其他减益。原低体力、低清醒、伤病等真实修正继续，不能误写成“濒死免疫既有负面效果”。

原业务里把H>0直接等同“存活”的筛选必须改为三态资格：治疗、入战名单、目标、敌方随机选目标、队列、编队／队长有效性、经验发放者、工作与被动加工发起者等均不能把濒死者误作死者。原位置、人数、装备、状态、技能、时机与资源锁继续校验；保留动作不表示无视AP、体力、距离、敌踪阻挡、材料、医疗冷却或原不允许的整理。

即使主角或全部在场我方都濒死，仍未彻底死亡，不因“全员健康0”自动败北／终局；有正常激活资格者继续下令。主角确实死亡仍按原规则结束本局，不转由队友续局。队友确实死亡才原子清原号位、离队、记死亡、迁遗物并使其他在场者按原值恐慌+8；每人每次死亡只处理一次，容量C不降低，其他人不自动压紧站位。

## 3. 正伤害与致死判定

### 3.1 一次真实伤害事件

伤害D是按原命中、护甲、格挡、保护重定向、减伤等结算后，实际落到这个人身上的正伤害；不能用“HP变化差”代替D，因为濒死者H=0仍会受伤。使用原内部精度，不用显示取整或0.01阈值判断，任何D>0都有效。未命中、完全格挡成0、仅控制／恐慌／费用、只减体力不扣健康，都不进行致死判定。

1. 事件开始前H>0：按原伤害扣到最低0；归0就进入濒死。本次D无论多大都不再额外抽致死；没有“过量伤害穿透濒死直接死”。
2. 事件开始前已濒死且D>0：按本案意志致死抵抗率抽一次，抵抗成功仍H=0、仍濒死；失败确认死亡并只走一次原死亡后果。
3. 已确实死亡：不再接受伤害、治疗、经验或新判定，不复活、不重复迁遗物。

同一目标多段攻击按各段原顺序：第一段从正H打到0只入濒死，之后每段实际正伤分别判一次；反击、迎击、死亡喷溅按原真实事件顺序各自处理。某段已让该目标确实死亡，后续本来锁该人的攻击不重新随机补打另人，也不重抽目标；原其他目标／连段中断规则继续。群攻仍按原真实承伤者逐人处理，保护者实际承伤就仅保护者处理，原被保护者不多判。

正伤害引起的原后续感染、出血、控制、装备磨损、恐慌等，在目标濒死但仍活着时继续按原合法条件结算；不能沿旧“H0立即return”漏掉它们。确实死亡后不再给死者执行后续反应／新状态，原同一复合事务先后与主角死亡优先收尾保持，不借动画先后重排领域事件。

### 3.2 战外、持续伤害与世界段

所有健康伤害统一接入：敌方攻击、反应／喷溅、回合出血、战外出血、饥渴／低清醒／过劳的健康损伤、搜集划伤、遗迹练习风险、疾病等原已存在扣健康来源。原本“只降到最低1、不致死”的事件包仍保留原非致死语义；不擅自把它变成正伤致死判定。病毒V达到原100阈值的尸变是独立终局，意志不能抵抗；没有新增饥渴直接秒杀例外。

事件粒度固定：一次原直接伤害段／一次出血触发／一次独立风险扣血分别是一个事件；同一个5分钟身体速率阶段里的饱食、水分、清醒、过劳等负健康小时率，先按原规则求实际负项总和，再乘本段5/60，合为该人一次“身体损伤”事件，不按每个负率各加一次抽签。该段原TickBody中的出血仍是随后独立事件。因此一次身体损伤把H打到0后，同段随后出血可以成为后续致死判定；不会仅因同一损伤列了两个原因就判两遍。

不能把健康正恢复和负损伤相加为净额后再判断是否曾受伤。保持原身体阶段顺序，但分离负项伤害和正项恢复：先提交本阶段负项事件并处理生死；若已进入濒死／死亡，该阶段自然正恢复为0；正常存活者才按原条件处理自然正恢复。之后原出血／感染等阶段继续，不改变5分钟世界时钟、既有伤害量、受热快照、费用或额外补tick。明确用药／医疗的即时回血在其原事务位置处理，不能事后补救此前已经确认的死亡。

濒死、抵抗或恢复不自动结束／取消真实工作。原低值提醒与暂停按原安全边界处理，新濒死提示只提醒一次，不变成永久循环暂停；如果本段合法完成工作且本人仍活，成果／原经验照常。锁定5分钟行动不新增退出入口；真死亡才走原终局／释放与同伴死亡收束。原撤出途中不可用药、战斗不能吃喝等限制也不因濒死解除。

## 4. 意志熟练度（主控授权设计定稿）

新增 `willpower`“意志”，第17项独立被动熟练度，沿现有角色各自保存的技能框架；放成长“求生与行动”，不新增主动战斗按钮、独立体力消耗、装备槽或新材料。新局、新招及旧档缺字段的存活角色初始1级0经验，最高10级，不按姓名、主角身份或敌人种类加隐藏抗性。意志不等于精神M，不拿临时精神或免疫替代它；本期不增加装备／蓝图／任务的额外意志加值。

`致死抵抗百分点 P = 65 + 2 × (L − 1)`；`致死抵抗率 r = P / 100`；`本次致死概率 q = 1 − r`。P按整数百分点求出，最后一次除以100，不用逐级浮点累加，避免83%边界变成0.8300000000000001。

### 4.1 成长来源与防刷

沿原门槛50×(L+1)，1→10累计2700经验，升10清溢出并停止发该门经验。意志仅被动增长，不另开练习或付费训练入口；关键等级1／3／5／7／10在成长页说明对应65／69／73／77／83%，不虚构五个主动技能节点。

真实敌方对该角色造成正直接伤害，且该完整出手事务结束时该角色仍存活，可给该人意志经验，基准10点。每个稳定 `actorId + worldEnemyId` 本局最多3次，每人每世界日最多60点；同一次敌方完整出手即使多段打同人也只给一次，分别打不同我方者各自记账，实际保护承伤者得经验。反应与普通攻击共用同敌额度，追击／撤退重接／巡游／入队／换编队／读档不清账；新生成的真实世界敌ID才是新来源。

实际给值=min(10，当日剩余额度，距10级尚可获得经验)，须>0才占该敌一次回执并累加日账；满级、当日已满或角色确实死亡不给，不记0收益占额。达到新世界日才清日账，永久同敌3次不清。升级在完整原出手提交后生效，本次多段所有致死判定用各段开始时已生效的旧等级，不在段中插XP升级倒算抗性。

流血／疾病／饥渴／环境风险、自伤、队友伤害、0伤和未命中不发意志经验；进入濒死、成功抵抗本身也不额外发第二份。不要用伤害量乘经验，不增加人为自残／环境受伤练意志的入口。敌方真实伤害时即使未濒死也可获得上述有限经验，避免必须临死才能成长。来源敌已在同指令中死亡，仍可按已锁稳定ID结账；无稳定真实敌ID的来源不猜造ID、不发经验。

## 5. 恢复与医疗

用户补充选B：濒死期间所有自然健康恢复为0，包括符合原条件的休息／睡眠、候补公共照护／安全屋自然恢复等；不累存“欠下的回血”，不在恢复后补发。E／S／M等原其他恢复和I／V机制照常，这不是暂停世界。

必须由原合法药品、医疗技能或现有医疗服务实际增加健康，H>0时立即脱离濒死、恢复正常生命姿态；0.02等任何实际正回血均可，内部>0但显示不足0.01仍不是0。只止血、解除虚弱／失衡、降病毒或安抚恐慌而没有H正恢复，不脱离濒死。应急护理等无回血医疗特写不能当复活。食物／普通补给、普通休息和没有实际医疗效果的剧情奖励不因通用正H写入绕过此门；不新增食物治疗或自动发药。

普通存活者的原自然／食物等恢复不变；已确定死亡者任何治疗均拒绝。原合法医疗可以选同场濒死者含自己，但原使用位、距离、装备、物资来源、共享回血60分钟冷却等原条件保持，不因濒死豁免冷却／物资。原有效医疗经验仍给真实施术者、沿原防刷；给0H活人实际回血属于有效医疗，不额外加一份“救命经验”。医疗给几个人、能否对候补使用仍按原服务／请求范围，不为本案开放远程医疗。

医疗与脱离濒死在同一事务确认，更新原HP、生命态、实际消耗／冷却和结果；请求失败／材料不足／仅预览不得站起或扣药。同一请求重试不重扣、不重复起身。回血不额外清出血／感染等，除非原药物／技能本就有该效果。脱离后再次归0重新先入濒死，不保留一个让下次首次归0直接死的隐藏累计惩罚。

## 6. 原终局、名册与持久化

为伤害事件稳定关联事件ID、受伤角色ID、来源、D、前后生命态、判定时意志等级／r、是否需要抽签及已提交结果；内部结构由开发定，结果与原随机游标同事务保存。读档、请求重试、动画跳过／重复渲染不重判。未提交随机不得单独推进游标；不以现实帧、播放索引或新随机数“还原”生死。

濒死／抵抗存活不运行Kill／CompanionDown，不清队长、不发死亡对白、不卸装备或创建遗物，也不重置战斗／工作记录；仍可按原合法队长规则使用本人既有潜行等数据。真正死亡才运行原永久后果，主角终局释放在办主／子／暂存工作一次，队友死时对应工作沿原离队／死亡规则处理，其他活人继续。病毒尸变等原独立终局仍在其原边界优先；若同一已提交序列先确认死亡，则不再让之后医疗救回，同段自然治愈也不能盖掉尸变。

旧档有可信已死亡／尸变／本局终结标记的，保持原终局及遗物，不倒推“当时应濒死”而复活，不退费或补历史经验。旧进行中战斗／工作保留进度、名单、已消耗随机和真实HP；未确死的在册人物H=0归濒死，H>0归正常，缺意志补1级0经验及空账一次。旧已完成伤害不补致死判定、不回放镜头。已有合法意志数据不覆盖，历史死者未记录的意志只读写“意志：未记录”，不编造历史技能或触发初始化领奖；非法等级按原技能迁移1—10夹紧，坏档按原兼容／拒读流程，不造未保存角色。保存生命态与新账，跨槽不串；刷新只显示该档真实已提交状态。

## 7. 姿态、特写与播放

生命态改变（正常→濒死、濒死→恢复正常、存活→确实死亡）均给特写；流血／回合末／战外伤害造成的变化也一样，不能静默改贴图。黯淡、单膝跪／全跪／趴卧是视觉姿势，不是减益。每名角色选其已制作的合适姿势，绑定稳定角色美术；不在每次刷新抽随机姿势或造另一个同名角色。正式姿势美术不足时【交开发方定】沿现有该角色站姿到原倒地式动作做受控过渡＋静态濒死姿态占位，必须有“濒死”状态，不能用死亡／移出画面占位，也不能因缺图跳过领域规则。

因攻击／医疗正在播同一次特写时，姿态变化合入该次结果帧，不再为同一转变另播一整段。出血等原没有出手镜头的来源新增一次生命状态特写，单个转变沿原1200毫秒标准与快／慢倍率；同一原结算段多个人变化可在同段按真实次序表现，不因重复入列让同一人改变两遍。抵抗成功仍濒死，没有新的姿态转变，不另播假“倒地再起”特写；原攻击结果上显示抵抗事实。普通待机、切武器页、一般走位不是本案生命姿态转变，不额外升级成生命特写。

战外特写同样只播已提交结果，期间锁原业务输入，ESC菜单可开并冻结表现；跳过／减少动态沿原同级特写规则，不增加世界时间／重复工作。若该真实事务还触发强制对白／主角终局等，按Q572先播完或跳过已提交片段再承接，不能趁镜头未到死亡帧继续操作。没有战场的场景用原角色与当前场景的只读镜头，不生成临时战斗。

敌人H归0即领域死亡、清出原敌方在场名单；在表现快照里只保留到它的死亡结果帧，然后战场位置显示原空位，不留尸骸阻挡。原其他敌人号位不自动压紧；范围、保护、援兵和锁目标失效仍按原规则。原动物尸体／掉落在胜利后作为地面物品按原规则结算，属于物品，不是战场障碍，不因本句删除掉落。
