# Q239 更新说明

选C，由总控补正式组名。48组统一采用“{岗位名}：代班闲谈／代班事项提示／代班进度提醒”，不用原人物名作代班记录标题。16个岗位名及全部48个组ID到标题的绑定见A11/N01与Q239数据；实际发言人仍为对应机构当班接续员，正文与触发规则不变。

**scope**：仅新增Q236的16岗位×3状态共48组在“对话记录”中的正式组名。原institution_substitute介绍、本人在岗台词、其他任务与招募邀约标题不改；不以原命名人物姓名作为这48组代班标题。岗位名仅用于记录定位，不是新增人物或服务。

**binding**：按明确dialogueSetId绑定title，沿原稳定岗位npcId取组，不按显示名、文本或代班人数猜；三类后缀依次固定为代班闲谈、代班事项提示、代班进度提醒。下表48项为最终逐字标题；实际对白speaker和发言内容保留原机构当班接续员数据，不把岗位名写入本人Greeted。

**display**：只给已实际产生、按原对话记录规则可查看的组显示标题；不为展示目录预先生成未见对白条目，不泄露未知地点、任务或未接分支。对话当场、历史回看和组标题引用处如显示该组名，应使用同一title；仅改名不自动播放、不创建新记录。

**migration**：线上尚无这48组，新增组直接用定稿。若开发测试/导入旧记录已有可信组ID，标题可按组ID解析为新定稿，不改原发言内容、speaker、时间或已示事实；无可信组ID保留原通用“对话”，不按台词猜组、不补建条目。进行中的旧对白沿原队列播完，不重复排队。

**effects**：改标题与查看/回看均0分钟0物资，不改Q235自动一次、Q236可重复/分支、Q237服务收尾或Q238本人首次记录；不改变任务、配额、知识和奖励。Q240—Q243为独立待答题，本题不裁定其日志/筛选/接取/延后触发。
