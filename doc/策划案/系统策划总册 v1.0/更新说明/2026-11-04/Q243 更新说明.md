# Q243 更新说明

选B。原服务结束入口需展示的首次代班说明被战斗/敌踪挡住时，保留未展示并记待补播；处理完后若主队仍在该岗位地点、该代班身份仍在岗且满足原安全/对白条件，自动补播一次。已离开则停止自动补播，等下次合法交谈、接取或原服务结束入口。实际开始显示才记已示，不重结算服务或奖励。

**scope**：只补足Q243所问的原服务结束入口应播而尚未开始显示的首次机构代班接续说明。原入口原本不触发说明、该身份已示、岗位不存在、主角死亡或本来不在该岗位地点，不因本题新建补播；Q177鉴定/换物成功原无结束钩子仍不新增。战斗/待处理敌踪及其后原显示锁挡住合法说明时，按本题保留待补播；不把未接触游荡敌人另加为显示锁。

**record**：待补播绑定本局campaignId、稳定岗位npcId、原岗位locationId与Q235稳定代班身份键；同键合并一条，不把待补播视为已展示。原服务的真实结算/日志已经发生的保持只一次，待补播仅含机构接续说明，不重放服务、任务或完整旧对白队列。

**automatic**：战斗/待处理敌踪处理完成后，在下一个原合法安全显示边界自动重验；主队仍在原岗位地点、仍由同一代班身份接续、该身份未示且原对白显示条件满足，才显示接续说明一次。若原移动/动作/其他对白/强制事件锁尚未释放，不打断它，保留待补播，到锁释放后第一个仍在原地的合法边界重验；不要求玩家再点击入口，不为补播推进世界时间。

**departure**：只要在补播前实际离开原岗位地点，该条自动补播资格即取消，不跨地点追播；该身份仍未展示，后续须由下一次本岗合法交谈、实际接取或原服务结束入口按Q235/Q242重新触发。仅返回原地点、打开地图/只读面板或旧计时回调不恢复这条已取消的自动补播资格。不在合法边界播出的跨地点服务收尾不新建待补播。

**identity**：自动显示前若本人已回岗或岗位改为另一稳定代班身份，取消原待补播，不以原人名发言、不复活本人，也不把新身份标已示；新身份的首次接续仍依其下一次合法入口。主角死亡依原规则不显示。待补播不设置本人Greeted，不影响Q238本人首次或六人邀约规则。

**receipt**：待补播入队与解除安全锁的重复回调不记已示；说明实际开始显示时才按Q235原子持久化已示并移除同键待补播/候选队列，关闭后不再自动重复。补播前若玩家合法交谈/接取/服务结束已先触发同身份说明，只显示一份，实际打开后清待补播，专属任务对白照原顺序保留。只读回看不消耗未示资格、不新建补播、无奖励。

**save**：待补播与“已离开取消自动资格”状态须随原存档机制持久化，具体字段由开发方确定，本题不指定新schema号。读回可信待补播且仍在原岗位地点/同身份/未示的存档，原安全条件满足后可在首个合法边界自动显示；仍有锁则等待，读档不复制队列或重结算。旧档没有可信待补播证据则不按Talks、旧服务日志或未示状态猜造自动补播，等下一次合法入口；Q240版本42原句不变。已在显示的旧队列沿原规则可播完，不截断其他剧情。

**effects**：仅改变首次接续说明被挡住后的显示时机。0分钟0物资，不增任务完成、工作进度、知识/物品/经验/配额/容量或身体恢复；保留原服务完成/取消/失败日志与原因。Q239的48组普通闲谈标题、Q241面板待接筛选、Q242实际接取入口均保持。

取代范围：本题明确取代Q235 receipt“下个合法安全边界”的服务结束首次说明时机歧义，以及开发本地“仅等下一次入口、不记录自动补播”的做法。Q240—Q242正文里本题仍待答的当前状态改为已答；历史更新说明/修改记录原样保留。
