# Q213 更新说明

选A。野外铺野营遮雨布、建固定火堆时，“无敌踪”仅指无已触发、需先接敌或绕行的待处理遭遇；未接触的当地游荡敌人不阻止。战斗、原行动/移动/强制对白及物品预留锁仍阻止，设施不消除敌人、不提供遭遇安全。

适用Q173许可内的field_tarp部署与wild_fixed_fire建造，只澄清“敌踪”口径，不扩大地点许可、不改变建造材料/时间/技能、铺取耗时、区域唯一火源、睡眠遮蔽和点火燃料。预览和确认都检查待处理遭遇，存在时拒绝并显示具体原因，不扣材料、不推进时间；不能通过铺布或建火清掉既有遭遇。未接触游荡敌允许开工，其后随机遭遇仍按原世界规则，若触发则沿原动作中断/暂停/取消与材料保留规则，不以本题自动胜利或免遭遇。本条不推广到安全屋建造、地牢固定战或m02任务阻挡的不同条件。旧档不删敌、不改人口/已成设施，旧在办动作保留原开工快照，新预览/新请求按此规则；不补材料/经验/时间，重试读档不重复提交。
