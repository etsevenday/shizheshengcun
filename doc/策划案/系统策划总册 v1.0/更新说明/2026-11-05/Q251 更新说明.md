# Q251 更新说明

选A。kind=gear的全部35件装备（armor、上衣、下衣、战斗饰品、生存饰品）都用防具线索；pot金属锅、ration_canteen分量水壶用容器线索，不按其tool/material落入工具/材料；4种动物尸体及未鉴定活性物质用通用兜底线索。稳定ID、元数据及完整映射见本轮合同；Q219逐字稿和Q250无任何可获取来源才显示的门槛保持，当前未有的查询入口不因本题新增。

规范合同：`assets/20261105/source-hint-classification-adjudications.json`。

**scope**：本题补足Q219公开来源线索的特殊物品类别匹配，只定分类，不改逐字稿、来源可获取资格或Q250显示门槛。全部装备在本题特指kind=gear的非武器装备，含8防具、6上衣、6下衣、9战斗饰品、6生存饰品，共35；不把武器、弹药、医疗物品一并改成防具。

**gear**：物品kind=gear统一匹配armor线索，包括战斗饰品和生存饰品。35项清单为当前版本核对快照，规则按gear元数据判断而非只写死这35个ID；将来同类gear仍依此规则。槽位名称是已有装备槽，不要求为了线索修改物品kind或槽。

**containers**：以明确稳定itemId识别pot与ration_canteen为container线索；这条语义优先于它们原kind=tool/material的通用分支。不要求存在kind=container，不按中文名称包含锅/壶猜分类。只查询容器本身时用容器线索；独立查询其中水或食品仍按被查询物品自身原类别，不随外层锅壶改成容器。

**fallback**：当前4种kind=carcass动物尸体及active_substance_white_unidentified用fallback，不按处理产物或可融合用途改成食品/材料/医疗。未知或未匹配类别沿Q219原fallback，分类不鉴定活性物质、不提前公开其真实性质。

**priority**：沿Q219顺序water→food→medicine→ammo→weapon→armor→container→tool→material→fallback；在armor分支将gear包含完整，在container分支纳入pot/ration_canteen，因而二者不会提前落入tool/material。其他类别及其冲突优先级保持，不重排武器和医疗。

**display**：仅当Q250原当前来源列表没有任何可获取行时，在末尾追加一条所选hintKey对应的Q219原文。有任一原可获取行不显示，原来源行与排序/状态保持；分类不替代可获取条件。只读0世界分钟/0AP/0资源，不开图、不授知识/物品/任务/经验，不承诺必得，不报未知地点、坐标或深房。

**entry**：当前来源查询入口仍只按原已实装制作缺料等入口开放；42种物品中现在点不到的类别，先配置好分类，不为本题增加卡片按钮或新查询入口、不提前生成来源目录。未来由合法入口查询时采用同一分类。

**save**：分类为当前查询的只读结果，重开按当前元数据/来源资格刷新。不新增存档迁移或日志、不重置知识/登记/任务/配额/存量，不改变进行中的制作、抄录或动作快照。旧存档同样按新分类显示，不补过去没展示的线索。

**supersedes**：明确补足并取代Q219 hintPolicy和Q246—Q250合同中Q251特殊归属仍待定/本批不裁定的当前状态；前批日期更新说明和校验报告作为历史交付保留。Q246—Q249迁移与五句来源、Q250门槛及fallback逐字稿完全保持。所有实际【实现同步】与完整修改记录原样保留，不能把本次策划静态验证说成开发实装或界面试玩通过。

### 三类逐字提示（沿Q219）

- armor：可查看已掌握的防护制作和已发现的装备记录；具体材料与等级以配方条件为准。
- container：可查看已掌握的容器制作和已发现的物资记录；空容器不等于已经装有补给。
- fallback：暂无已知来源。可继续调查已经发现的地点与公开资料；此提示不代表未发现区域一定存在该物品。
