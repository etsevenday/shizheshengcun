# 系统策划总册改动说明

## 2026-10-27 按独立系统重编 编目1.0

原策划按v0.1—v0.7分散维护，同一系统的规则跨多个版本文件，部分旧正文与后续答复并存。本次将有效规则直接合并到固定编号的系统主案，供策划后续定向修改和程序按功能查阅。

### 文档结构

- 建立15份基础系统策划案，编号S01—S15：世界时间/行动/存档、地图移动、探索发现、清理掉落、定向搜集、物品背包、拖拽、手工制作、营地火堆、容器液体、设施烹饪、基础状态饮食医疗、休息恢复、主界面UI、开局引导终局。
- 建立6份参考扩展案，编号R01—R06：人物成长、武器耐久、回合战斗、免疫感染、敌人种群与遭遇、动物尸体及肉类加工。保留参考状态，未因重编自动启用。
- 原始XMind中的侵蚀、超能力、轮回、善恶、任务事件、招募交易、天气生产与联机等收进后续储备；早期Word净化目标也保留为暂缓构想。
- 增加总纲、维护约定、系统模板、规则迁移与待定清单、属性索引、历史验证记录、来源映射及程序验收索引。

### 合并的规则与交互

- 探索/清理共用当地随机表；探索满100%永久结束并移除按钮，清理次数独立按世界时间恢复。
- 地块栏分地图/场景第一行、设施/资源第二行；锅与内容物直接嵌在设施卡内，不再层层打开内容物菜单。
- 点火绑定具体工具，拖入或在点燃菜单中选工具即开始5分钟点火；删除左侧自身投放卡，人物信息进入右栏，可用物品在选中卡片下方操作。
- 设施按游戏世界时间自动净水、烤制或水煮；空锅不烹饪，取消自动补水。真实内容物归属、预留水、容量、重量、打断与完成顺序合并进对应系统。
- 普通制作/建筑仍是角色行动；角色暂停后需手动继续，与设施复燃自动续行分开。
- 早期12行动点、10日侵蚀失败、槽位背包、旧空锅主动配方及旧菜单等按后续已明确规则替代，不因归档恢复。

### 后续维护与程序交接

- 每份主案标出职责、参数归属、联动系统、失败/取消/存档边界、来源及验收目标；共有142项系统验收目标。
- 固定文件路径和系统编号，后续直接修改对应主案并同步联动，不再以多份增量问答作为并行生效规则。
- 将群攻经验计数、锅的并行磨损、敌人首次可见、尸体保质起点、弹药取得、扩展分阶段范围共6项缺口单列P01—P06，未擅自补成新玩法。
- 保留历史文档与数据快照，不把旧测试/模拟结果当作本次已验证工程。文档编目、程序版本和存档schema分别维护。
