## D4 相邻地点的出发动作放哪里

紧接 S02 Q916／Q1001—Q1006 的相邻卡浮窗和地图路线区。参考猎人局已从地点卡点「北方」到下一站，开关地图不耗时。

| 方案 | 玩家实际看到或做到的变化 |
| --- | --- |
| A 沿现有两步 | 点相邻地卡，在浮窗看路线与代价后确认。 例「溪流浅滩」→「点地点卡」→「路线、耗时、确认移动」。保持现有的点击顺序。 |
| B 当前位置集中找路 · 推荐 | 当前位置加「附近路线」，按方向列已开通邻地和已有时长；点一条仍走原移动确认。 例「附近路线」→「打开附近路线」→「向东 · 溪流浅滩、选中后确认移动」。把反复横向找相邻卡的步骤集中到本地点，保留原风险确认。 |

## D5 设施空槽怎样提示可以放什么

S07 / S10 / S11 / S14 · 拖生肉，当前可放直接加工位，锅内该位不接收。

S07/S10/S11/S14 沿 Q1028—Q1029 显示真实槽位并拒绝非法热区。参考运行确认槽位和物品相配，拖起时高亮效果未验证，空槽指引只见本地化键。

| 方案 | 玩家实际看到或做到的变化 |
| --- | --- |
| A 沿真实槽位 | 先显示实卡和空位，拖到目标时按现有规则反馈。 例「○ 直接加工位、○ 锅内槽」→「拖近目标」→「可放加工位、○ 锅内槽」。非法槽仍静默拒绝。 |
| B 起拖即标合法槽 · 推荐 | 从起拖到松手，让当前可操作层中每个实际合法槽先亮起。 例「○ 直接加工位、○ 锅内槽」→「起拖生肉」→「直接加工位 ✓、○ 锅内槽」。在玩家找目标时提示，松手照原规则重新核验。 |
| C 参考《奇幻森林》空槽文字 | 空的服务槽按实际用途写短指引，例如「拖入食材」。 例「○ 空槽」→「查看空槽」→「拖入可加工物品」。原安装有空槽拖入文案。参考截图中的空位没有文字，具体显示条件尚未实测。 |

**验收场景**　同时摆一个可接收空槽、一个满槽和一个条件不合法槽。检查标记、放手结果、遮罩覆盖和投放后真实占位。

## D6 从水源取到容器要经过几步

S05 / S07 / S10 · 以持有空壶、到达本地可用的溪流水源为例。

S05 取水、S10 Q929/Q1011 水壶装水当前各有原入口。参考实跑已在陶碗和湖泊间验证合法取水配对，重载后可读真实水子对象。

| 方案 | 玩家实际看到或做到的变化 |
| --- | --- |
| A 沿采水后装壶 | 先按原流程取水成卡，再从实际水堆装入壶。 例「空水壶」→「先取水」→「选择水堆、装水」。使用现有取水与装水两个入口。 |
| B 采水前选择去向 · 推荐 | 在水源原取水面板选「装入容器」，点选壶后确认。 例「溪流 · 脏水」→「选目的水壶」→「去向 空水壶、沿原耗时」。点确认才走原采水，能实际装进去的水进入所选壶，多出的沿原落点。 |
| C 参考《奇幻森林》物对物 | 把真实可用水壶拖到本地水源，按当前项目许可执行一次取水。 例「空水壶、溪流水源」→「拖壶到水源」→「壶得到脏水、多余水按原落点」。参考版陶碗与湖泊的配对动作已验证。项目继续用原耗时、产量和水种。 |

**验收场景**　同一水源验证空壶、半满同类、异种、已失效的壶。比较原取水耗时、取得总量、实际壶内水和落地余量。

## D7 在火边要等一项还是整座

S01 / S11 / S13 / S14 · 同一火堆的两个任务分别还需 10、25 有效分钟。

S11 全部等待绑定一座火源的合法目标。当前 FireQuickActions 文案与入口直接等全部。参考前台截图有火边等待按钮，实际停止条件未运行验证。

| 方案 | 玩家实际看到或做到的变化 |
| --- | --- |
| A 等全部 | 点击现有「等待加工」，绑定本火源当前目标并等到最晚。 例「生肉 10分钟、锅 25分钟」→「等全部」→「生肉、锅、最晚目标 25分钟」。原燃料不足和身体风险仍可让行动提前停。 |
| B 增加等这一项 · 推荐 | 保留设施级全部等待，并在可等待的实际工位或锅内卡提供「等这一项」。 例「生肉 10分钟、锅 25分钟」→「点生肉的等候」→「生肉 10分钟、锅同步正常推进」。停止目标限于这一项，其他工作仍随世界时间推进。 |
| C 参考火边等待入口 | 设施主层仍就近等待。项目适配为先等到第一项完成，再由玩家决定是否继续。 例「生肉 10分钟、锅 25分钟」→「在火边等下一项」→「生肉完成、锅继续占位」。原版截图只证明有「在火边等待」按钮，先完成即停是本项目提案。 |

**验收场景**　并行两项时执行所选等待方式，查选定目标、其他项实际进度、燃料不足和完成时点。同名的另一座设施不纳入目标。

## D9 反复操作的对象能否快速回找

S06 / S07 / S14 · 同一营地反复给一座火堆投料，旁边还有另一座同名火堆。

参考 GuideManager_AllTips[0] 和 SelectBookmark 等支持从卡描述设书签，操作时机本次未跑。项目现有安全屋收藏针对安全屋，与临时卡片定位不是同一用途。

| 方案 | 玩家实际看到或做到的变化 |
| --- | --- |
| A 沿现有选卡 | 每次从设施栏找到对应卡并打开。 例「火堆、火堆」→「找对应火堆」→「所点火堆」。维持现有选卡和返回行为。 |
| B 记住一个本地对象 · 推荐 | 允许在对象详情临时标一个本地对象，下次只定位这张真卡。 例「已标记的火堆」→「定位已标记对象」→「实际那座火堆 ✓」。离区或对象消失时清除。定位不点火也不自动执行。 |
| C 参考《奇幻森林》书签 | 在卡片详情设多个书签，通过书签入口跳到对应卡或同排位置。 例「火堆、水壶」→「点击「火堆」书签」→「高亮真实那座火堆」。参考证据来自本地帮助与代码。是否跨区记忆、编号及同类书签规则需按项目定。 |

**验收场景**　两张同名火堆分别绑定身份，移除、跨区和失去权限时不会跳到另一个同名对象，也不会代玩家执行动作。

参考本地 FILTERS_HELP、CLEAR_CARD_FILTERS、Filter_Food 与 CardFilterGroupButton.Click 提供筛选证据。项目 S07 基线没有普通卡区筛选。

| 方案 | 玩家实际看到或做到的变化 |
| --- | --- |
| A 维持当前列表 | 沿现有分区、牌组和滚动阅读物品。 例「木材、绷带、罐头」→「滚动地面行」→「找到罐头」。不新增筛选入口。 |

**验收场景**　过滤后重量、根卡和合法来源统计与默认全部一致。新掉落、匹配与不匹配库存和回到默认状态可核对。
