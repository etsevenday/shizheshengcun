# 新增系统策划案模板

将本模板复制为独立系统文件，赋予未占用编号。不要用“补充1/补充2”长期替代系统正文。

系统编号：待分配；单案修订：1.0；更新日期：填写。

规则状态：基础设计 / 参考扩展 / 后续储备（选一，并说明接入证据）。

## 1. 目标、职责与边界

解决什么玩家问题；本系统维护什么；哪些规则只引用其他系统。

## 2. 玩家流程

入口→条件→选择/预览→确认→时间推进→结果与反馈。列出哪些点击直接执行，哪些仍需确认。

## 3. 对象与主数据

ID、名称、来源、用途、数值/单位、范围、初值、概率表及唯一维护归属。新物品必须有取得与消耗闭环；概率明示互斥还是独立。

## 4. 规则与结算

开始费用/预留、持续条件、成功、失败、取消、暂停、死亡、到期、满容量/超重、同刻事件顺序。

## 5. UI与输入

显示位置、图片/图标、选中状态、按钮文案、滚动、拖拽与点击等价、禁用原因；引用S14通用规范。

## 6. 状态、事务与存档

最少语义字段、随机生成/锁定时机、唯一owner、幂等、旧档兼容；引用S01，避免第二套时钟。

## 7. 联动改动

列出需要一起更新的系统编号、参数/示例/引导/验收；参考转正时写替代的基础规则和开关。

## 8. 验收目标

编号 / 场景 / 明确预期。覆盖正常、边界、失败、取消、重复请求及读档。分清计划验收与已执行证据。

## 9. 待定与来源

尚缺什么、在哪个P问题记录；用户裁定/旧规则来源/策划补齐初值分别标明。

## 修订记录

修订 / 日期 / 改了什么 / 为什么 / 联动系统 / 程序接入状态。
