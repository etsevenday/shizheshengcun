## 3. 阈值、归零和腹泻

| 条件 | 效果 |
| --- | --- |
| H≤25 | 高危提示；只有H≤0才死亡 |
| N≤20/W≤20 | 低值提示；N=0额外H−2/h，W=0额外H−8/h |
| E<20 | 工作倍率×1.25；E=0且工作额外H−1/h |
| S≤20 | 睡眠提示；S=0额外H−2/h |
| M<20 | 全部正向E恢复×0.5，不直接致死 |
| 腹泻 | 额外W−3/h；脏水后持续12h，再喝刷新不叠倍数 |

伤害用段首值：段末刚到0，下一段才记该归零伤害；多个归零伤害可相加。即时补给先应用再进入5分钟，所以可避免本次该项归零伤害。

首次向下越过N/W/E/S/M20或H25，在该段后暂停；继续后同区不反复提醒，恢复越线后可再触发。进一步归零再暂停一次；归零/死亡高于普通提醒。E速度阈值严格<20，不能拿整数显示20替代内部判断。

## 4. 食用、饮水与基础药物效果主表

| 物品 | 即时效果 | 限制 |
| --- | --- | --- |
| 净水1份 | W+30 | 每份500ml |
| 脏水1份 | W+30，腹泻12h | 风险明确展示 |
| 罐头1 | N+35 | 不生成空罐 |
| 野果1 | N+10/W+5 | 必须未腐败 |
| 烤熟块根1 | N+25/W−2/M+2 | 原cooked_root沿用ID |
| 水煮块根1 | N+23/W+5/M+3 | 不再额外返加工水 |
| 草药绷带1 | H+5 | 角色级60分钟回血冷却，不治腹泻 |
| 生块根、腐败食品、原草药 | 不允许直接使用 | 不扣物不耗时 |

各可用物先扣1并夹紧应用效果，再按wait推进5分钟，不可中途取消；同次不能多次扣。例W50饮净水→即时80→5分钟结束79.75。临近上限提示浪费但不自动替玩家取消；绷带冷却中禁用不扣物。

来源允许随身、当前地面、当地可访问容器中未预留成品/水；选中卡下操作按S14，明确来源，不自动换锅或批次。移动途中只允许随身，忙碌权限归S01。

## 5. 收支校核与边界

每日基础N消耗36、W72，重活动另增加；食用烤根每份再额外W−2，水煮则另消耗加工净水。旧“两份熟根+三份净水一定足够”的简化结论不继续当保证。日程构成、腹泻和溢出都需计入，参考日程记录见附录A02（其中E/H已采用参考尺度）。

医疗扩展R04的止血、病毒抑制与抗生素不属于基础绷带现有效果；不能因为文档并列就让绷带直接清病毒。体温、营养素、部位伤、寄生虫等未定义项见储备清单。
