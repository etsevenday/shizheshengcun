## 3. 阈值、归零和腹泻

| 条件 | 效果 |
| --- | --- |
| H≤25 | 高危提示；只有H≤0才死亡 |
| N≤20/W≤20 | 低值提示；N=0额外H−2/h，W=0额外H−8/h |
| E<20 | 工作倍率×1.25；E=0且工作额外H−1/h |
| S≤20 | 睡眠提示；S=0额外H−2/h |
| M<20 | 全部正向E恢复×0.5，不直接致死 |
| 腹泻 | 额外W−3/h；脏水后持续12h，再喝刷新不叠倍数 |

> 【实现同步 2026-10-27】按 v0.6 尺度（`thresholds`、`healthRules`、`workFactors`，M37 a9e2366）：高危为H≤5；低体力为E<4（严格小于），工作倍率×1.25；归零额外伤害为N=0时H−0.4/h、W=0时H−1.6/h、E=0且工作时H−0.2/h、S=0时H−0.4/h；N/W/S≤20、M<20 与腹泻各行不变。

伤害用段首值：段末刚到0，下一段才记该归零伤害；多个归零伤害可相加。即时补给先应用再进入5分钟，所以可避免本次该项归零伤害。

首次向下越过N/W/E/S/M20或H25，在该段后暂停；继续后同区不反复提醒，恢复越线后可再触发。进一步归零再暂停一次；归零/死亡高于普通提醒。E速度阈值严格<20，不能拿整数显示20替代内部判断。（【实现同步 2026-10-27】提醒线实际为N/W/S/M 20、H 5、E 4，E速度阈值为严格<4；显示为两位小数四舍五入，E=3.996 会显示4.00但已按低体力处理（开发计划 v0.5 待确认15））

## 5. 收支校核与边界

每日基础N消耗36、W72，重活动另增加；食用烤根每份再额外W−2，水煮则另消耗加工净水。旧“两份熟根+三份净水一定足够”的简化结论不继续当保证。日程构成、腹泻和溢出都需计入，参考日程记录见附录A02（其中E/H已采用参考尺度）。
