## 2. 归属与区域

每实例唯一owner：角色随身、某地点地面、某设施、某锅；owner决定实际显示位置与访问范围。固定设施不能进包；锅进火堆后只在火堆内显示，锅内物品只在锅内显示。选择、排序、展开UI不改owner。

携重=全部随身根实例及其后代总重量，只算一次。（【实现同步 2026-10-27】已装进武器弹仓的弹药按其单重计入该武器重量一次：src/Core/Engine/GameEngine.Items.cs）地面及固定设施物资不计随身；装备栏若启用只引用已有随身实例，不复制。整锅转移必须带全部内容并整体校验。

| 携重 | 规则 |
| --- | --- |
| ≤20kg | 轻装 |
| >20且≤30kg | 相关工作倍率×1.25 |
| 拾取后>30kg | 拒绝整次，不静默只取一部分 |

地面无重量上限，不自动销毁。拾取/放下不耗时，但需角色当前所在地和行动状态允许；其他地点不可远程访问。UI可提示最大可取数量，必须由玩家重新提交。

## 3. 批次、合堆与消耗

数量为非负整数，工具/锅独立实例。自动合堆要求物品相同、到期时刻相同及目标归属一致，超stackMax分堆。UI可按同种归组，但不能丢失底层批次、预留与保质。

未显式指定来源时，默认消耗最早到期的有效批次，平手按实例ID；显式卡片/锅水使用锁定所选来源，不换别的批次。预留物不能二次转移、合堆、投料或使用。

同区排序改变有序ID列表，不改变数量或重量。新产物追加在地面组并高亮，不打乱玩家顺序；固定地图/设施不开放拖动排序。

## 4. 保质与腐败

expiresAt在生成时按绝对世界分钟记下；携带、地面、其他地点和锅内使用同一游戏时钟，离线不额外流逝。转移、合堆、读档、放火边不能刷新期限。

到期标腐败，卡与重量保留，不可食用/作有效材料；本版不做冰箱、垃圾转化或新销毁功能。玩家可以放下或依现有明确处理入口操作，不凭“丢弃”一词新增物品自动删除。

原料仅预留不冻结保质；手工配方完成时恰好到期仍按S08中止返料。Q16新增设施烹饪例外：原料新鲜且实际获得有效受热进度后，按S11 §10保护至该次加工结束；熄火保留、取出解除。已变质物品不得开工，未受保护到期物留原处占位。所有合法烹饪/复煮成品从完成时刻计24小时，不再继承烤肉旧截止。

## 5. 数据与UI

ItemConfig至少id/weightGrams/stackMax/shelfLifeMinutes；实例至少instanceId/itemId/count/expiresAt/durability/owner/reservedBy。按真实实例建立各区布局索引，实体不同时出现在两处。

卡片图标+名字+数量+关键状态，选中展示批次/来源/重量；水量、耐久、库存、加工进度分标签，不用同一种百分比混淆。卡下自用与转移入口按S14。

## 7. 携重展示位置（本轮UI修订）

## 8. 随身最多五张根物品卡（2026-10-29新裁定）

用户明确最多5张根物品卡：同批合法堆叠算一张，独立工具/武器各算一张；锅及锅内真实水/食物整体算一张，弹仓内容不额外占根卡。不同到期批次或堆叠超限拆出的卡分别计数；不能仅UI归组就绕过容量。装备引用的根物品仍计数，不新增隐藏装备槽。五张上限与原30kg上限同时校验，原负重倍率保持。
