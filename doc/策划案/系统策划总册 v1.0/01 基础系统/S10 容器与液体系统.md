## 1. 容器结构与容量主表

只开放“地点固定火堆→锅→水/食材”，不开放锅套锅、建筑任意储物或背包嵌套。锅在地面/随身只存放，实际属于燃烧火堆加工位才能受热。

| 维度 | 当前容量/规则 |
| --- | --- |
| 锅水区 | 1000ml，按500ml整份转移；空0%、一份50%、两份100% |
| 液体类型 | 空/脏水/净水，不混净脏水，不自动倒出或替换 |
| 锅食材区 | 2份，各占1位；现阶段生块根及本锅熟成的水煮块根 |
| 锅空重 | 1000g，另加真实水和食物；满水2根总2600g |
| 两容量关系 | 水和食材各自独立，满1L可有2食材；2食材不等于可装2L |

腐败内容仍占位，等待玩家取出。完成熟食也保留占位。空锅可存根但缺水不加工；不自行干煎。生肉及肉类成品仅在R06启用后扩展白名单。

## 2. 唯一归属与重量

锅入火堆后owner=facility:<id>，水/食物owner=pot:<id>；锅及后代不在地面/随身留副本。取整锅时后代全部随行，进入随身按合计重量校验一次。随身水装随身锅总重不变，地面水装随身锅增加水重。

火堆最多一锅的容量由S09负责；玩家明确放哪一口，不自动按锅位/随身/地面顺序挑锅。锅位满提示当前锅与内容，不能悄悄替换。

## 3. 操作契约

| 操作 | 结果 |
| --- | --- |
| 水拖锅装水区 | 扣源整份并加入该锅，容量/同种/锁校验 |
| 食材拖锅食材区 | 成为真实内容；满足条件后由S11处理 |
| 锅拖当前地面/随身 | 整锅转移，保留内容，关联进度按S11中断 |
| 锅内水/食物拖出 | 转移指定子物，不误取整锅 |
| 点击子物图标/箭头 | 选该实例，卡下选择数量与目标，执行后才转移 |
| 合法锅水饮用 | 卡下“饮用1份”，按S12费用，不自动换其他水 |

所有装入/取出/倒出到地面或随身均0游戏分钟，仍受忙碌白名单与负重限制。整次失败不改owner、不清热进度。显式锅热区失败不落父火堆。禁止自动补水，包括配方入口、进程缺水或半锅情况。

## 4. 锅内显示

锅主图、名称/实例、水量条、液体图标与数量、两个食材图标与进度直接出现在锅卡；火堆内也是同组件。内容物不靠再开子菜单查看，箭头只负责转移选择。显示总水与可用/预留水，预留水不能因“仍在锅里”被饮用。

空锅明确0/1000ml与0/2食材，缺水/等待净化/加工中/完成/腐败用图标+文字。点击内容只刷新右栏与卡下操作条；不改变实体。容器卡与子卡起拖把手、滚轮和事件冒泡规则见S07/S14。

## 5. 状态与跨系统边界

保存instanceId/owner/contents、liquidType/amountMl/foodSlots；每次移动原子更新来源、目标、布局与总重。水预留与热进度归S11；“什么时候可使用”由S01/S12校验，本系统不再建立第二套锁。
