## 1. 开局唯一清单

第1日08:00，角色在camp，六状态初始值读S12；仅camp↔field连接开放。camp已访问探索100，field已发现，其他地点未知；资源初始库存读S05，清理次数读S04。

| 位置 | 初始物资/设施 |
| --- | --- |
| 随身 | 金属锅1、打火器1 |
| 营地地面 | 罐头2、净水2、木材2、植物纤维2、布料2、石块2 |
| 固定设施 | 火堆未点燃、燃料0；棚和床垫未建 |

新局不为参考战斗/感染自动生成武器、敌人或药品。若采用参考扩展，初始化和迁移按对应R系统成组调整。

## 2. 建议引导与标记

| 建议时段 | 引导 | 完成标记 |
| --- | --- | --- |
| 第1日 | 探索荒地，找水/树林，第一次饮食睡眠 | field≥50；访问stream或woods；至少睡眠一次 |
| 第2日 | 完成安全水、熟根与遮蔽建设 | 净水处理和块根熟成各一次；建棚 |
| 第3日 | 到村庄，储备次日补给 | 访问village；随身或营地净水≥3份、熟制块根≥2份 |

这些是建议日程，超日不失败、不锁顺序；动作/库存实际达成才锁存，之后消耗不回退。净水含随身/营地锅内净水；熟制根按烤熟+水煮合计，允许营地设施与锅内有效成品，按实例去重。其他地点的储备不算营地储备。

旧引导文案的“cook一次”改为对应有效熟成事件，不要求完成已废止的主动空锅配方。库存标记不把预览引用或虚拟物品算已获得。

## 3. 七日检查

到第8日08:00存活即触发七日基础生存检查；只要求存活，记录安全饮水、食物加工、棚及地点访问进度。触发段结束记事件，主行动结束后展示，不插断行动。主按钮“继续生存”，无10日硬终局、世界轮回或跨局奖励。

## 4. 死亡与重开

基础仅H≤0死亡，立刻锁玩法；若R04启用则新增V≥100尸变终局。界面展示原因、存活时长、地点、探索/检查目标与种子；不自动复活、不继续未来tick。

历史死亡原因按最后使H下降的来源，同段多因取饥饿→缺水→缺睡→过劳→受伤首个；新增战斗/尸变原因接入时必须映射，不能改写为不存在的旧原因。

新游戏覆盖单槽前确认，重开完整重置世界与角色，不跨局继承。继续游戏恢复原存档；返回标题/关闭浏览页不等于重新开始。死亡、七日完成和保存失败使用不同反馈。
