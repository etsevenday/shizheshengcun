## 1. 定位

清理翻找地块零散基础物资，不改变探索度，不发现路线/资源点，不删除或自动拾取地面物资。当前已访问地块有次数即可开始，0%或100%探索均可；远端不可清理。

## 2. 次数与恢复主表

| 地点ID | 地点名称 | 清理次数上限/初始次数 | 单次恢复间隔（游戏分钟） | 满空槽全部恢复所需 |
| --- | --- | --- | --- | --- |
| camp | 临时营地 | 3/3 | 360（6小时） | 18小时 |
| field | 农野荒地 | 4/4 | 240（4小时） | 16小时 |
| stream | 溪流浅滩 | 3/3 | 360（6小时） | 18小时 |
| woods | 树林边缘 | 4/4 | 240（4小时） | 16小时 |
| village | 废弃村庄 | 3/3 | 480（8小时） | 24小时 |
| hardware | 五金店 | 2/2 | 720（12小时） | 24小时 |
| clinic | 诊所 | 2/2 | 720（12小时） | 24小时 |
| scrapyard | 废料场 | 3/3 | 480（8小时） | 24小时 |

初始按上限；未访问地点也维护世界状态但不提前泄露。开始先更新到当前世界分钟，再立即扣1；取消、死亡、空结果均不退。

每地点一个串行恢复进度：不满时，累计世界分钟每到interval恢复1；余数继续积累下一次，达到上限后余数清零，不存欠额或额外次数。重复清理不清空原恢复进度。

```text
elapsed = now - lastUpdatedWorldMinute  # 负值报告异常，不恢复
if charges == cap: progress = 0
else:
    total = progress + elapsed
    charges = min(cap, charges + floor(total / interval))
    progress = 0 if charges == cap else total % interval
lastUpdatedWorldMinute = now
```

全部地点按同一世界时间更新。清理、移动、睡眠、补给的游戏分钟都算，浏览和离线不算，午夜不额外回满。

例：树林08:00从4扣为3，08:20累计20/240，12:00恢复满。若08:20又扣为2，原20分钟保留，12:00回3，16:00才回4，不是两份并行恢复。

每次成功完成只抽一个互斥结果，非空产1份；无第二次数量抽取、无保底、无工具/探索度加权。清理和探索都引用本表同一lootTableId，空结果用null，不创建空物品卡。每行权重合计100，按表顺序用r∈0,100)累积命中。

树林顺序：空[0,20)、木[20,50)、纤维[50,75)、石[75,90)、野果[90,100)。结果开始锁定并隐藏，完成揭示。食物/草药按完成时刻生成保质期；产物落当地地面，不自动拾取，不扣原定向资源库存。

本表不给成品工具、锅、打火器、罐头、净水、绷带、熟食，稳定水源仍由定向取水提供。石块/废金属/零件新增零散可再生来源是明确经济变化，不代表原遗迹箱恢复。

## 4. 成本与结算

clear为20基础工作分钟，使用gather身体速率，无最低体力硬锁、无清理专属划伤；工具不影响也不磨损。轻装白昼20分钟N−0.625/W−1.5/E−4/S−1.666667/M−0.166667。倍率1.5则30世界分钟，E−6/W−2.25。（【实现同步 2026-10-27】R01 尺度下 clear 体力 −2.4/小时（config `hourlyRates.clear.energy`）：轻装白昼20分钟实际E−0.8，倍率1.5时E−1.2；N/W/S/M 不变）

完成且存活才给隐藏产物；空结果是正常完成，不退次数。低值暂停保留原计划，补给后明确继续；取消不发物，恢复累计仍按已流逝分钟增加。未来采用敌人扩展后再按R05判接敌，不套定向资源划伤概率。（【实现同步 2026-10-27】R05 已开启：第2日起在非营地完成清理、先提交原结果后，按开始时锁定的判定检查接敌，概率=1%×本地未交战敌对数/本地上限；命中则形成敌踪，可接敌或绕行10分钟。出处：config `encounters`，src/Core/Engine/GameEngine.World.cs）

## 5. UI与观察

当前地图卡清理按钮显示次数、基础/预计时间与恢复；0次禁用并说明，满次无继续积攒倒计时。右栏显示本次扣1、可能物资、空概率、五项预计变化和产物落地。执行中不泄露已抽中的物品。

理论每次期望：营地0.75份，荒地/溪流/树林0.8，其他0.7。树林清理理论0.9木/h，低于无斧采木2木/h及有斧4木/h；清理用于杂项补充，不取代稳定采集。实际试玩仍需记录空手次数、停留时间和资源产量。
