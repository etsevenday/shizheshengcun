## 1. 可选行动

| 行动 | 可选时长 | 目的 |
| --- | --- | --- |
| 休息 | 30/60/120分钟 | 恢复E，不恢复清醒 |
| 睡眠 | 2/4/8小时 | 恢复S和E |
| 等待 | 30/60分钟 | 推进世界以等天亮/加工，不额外恢复 |

任何地点、任何昼夜可选，固定世界时长，不应用夜间/负重/低体力工作倍率。面板打开默认：夜间或S<50选睡8h，否则休息60分钟；只默认选项，不自动开始。

## 2. 条件与加成

基础小时率读S12，不在本案复制另一张速率表。五金店、诊所天然遮蔽；营地已建棚为遮蔽；其他露天。移动中暂停休息按露天，不能因为起点室内而隔空享受床。

| 条件 | 当前额外效果 |
| --- | --- |
| 营地已建棚时休息 | M额外+2/h |
| 营地有床垫且睡眠 | E额外+1/h |
| M<20 | 全部正向E恢复含床垫后×0.5 |
| 遮蔽休息/睡眠，段首N≥40/W≥40/M≥20 | H+0.2/h |

> 【实现同步 2026-10-27】按 v0.6 尺度（M37 a9e2366）：床垫睡眠体力额外+1/h（`facilityEffects.bedExtraSleepEnergyPerHour`）；遮蔽休息/睡眠且段首N≥40、W≥40、M≥20时健康+0.2/h（`healthRules.shelteredRestRecoveryPerHour`）；建棚休息M+2/h、M<20时正向体力恢复×0.5不变。

露天/遮蔽清醒恢复分别见S12；火堆没有额外体温、睡眠护卫或无定义的舒适加成。R01与本表采用同一现行尺度，E恢复与H恢复不重复叠加。（【实现同步 2026-10-27】R01 已采用，实际值见上条）

## 3. 推进和暂停

逐5分钟消耗饮食、处理腹泻、燃料、资源和加工，不暗场瞬间跳过。E/S满值不自动结束，提示剩余收益/溢出；计划耗尽、玩家取消、条件暂停或死亡才结束。

低值、高危、归零按S12暂停，允许合法补给后明确继续剩余时长。补给/维护子行动保留原休息计划，不能另开子行动栈。休息不替代睡眠，露天睡眠不能被UI写成与遮蔽同恢复。

## 4. 预览与维护

预览当前条件、设施加成、实际恢复、N/W消耗、结束时刻和途中阈值；精神低值减半直接反映。等待期间可预览设施完成，但不自动吃成品。取消保留已恢复与已消耗，未来时长不继续结算。

## 5. 中央推进、退出及烹饪定向等待（本轮新增）

普通等待30/60分钟、休息30/60/120分钟及睡眠2/4/8小时的开始入口保持；执行中按S14 §11显示中央条、剩余时间、快速淡入淡出与“退出”，右侧不重复执行进度。玩家随时请求退出，在当前原子5分钟段后取消未来时长，保留已恢复/消耗；既有阈值暂停仍保留原计划并允许继续或退出。

火堆“等待烹饪”新增为目标驱动的wait入口，不受普通等待30/60分钟选项限制。开始时长和目标取S11 §9：等本火堆开始时全部当前可加工项目完成，含锅内净水后的食材链；并行不累加、已完成不自动吃。仅角色空闲且当前地点合法可开始，不插入原暂停主行动做第二主行动，也不替代点火维护子行动。基础速率仍引用S12的wait，无额外体力恢复/休息加成；同世界tick被动加工不再收费。退出/燃料失效/未保护目标到期/身体阈值/死亡分别按S01/S11/S12处理，进度与世界状态照实保留。
