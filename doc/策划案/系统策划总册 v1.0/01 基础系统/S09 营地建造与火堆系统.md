## 1. 营地与建筑

开局camp有固定未燃火堆，棚/床垫未建；火堆不能拾取，不新增其他地点造火堆的配方。未建建筑有插画和虚线状态，展示不等于已生效。

| 建筑 | 材料 | 基础工作分钟 | 条件与效果 |
| --- | --- | ---: | --- |
| 遮蔽棚 | 木材4、植物纤维4 | 120 | 仅营地且未建；获得遮蔽睡眠条件，营地休息精神收益见S13 |
| 床垫 | 植物纤维4、布料2 | 60 | 仅营地、已有棚且未铺；睡眠体力收益见S13 |

两者均主动建造、craft消耗、S01倍率，材料随身/当地地面，预留/取消按S08。成功修改设施状态，不生成可搬物品；再次建造拒绝，不扣料。基础建筑不开放任意储物。

## 2. 火堆容量与燃料主表

| 参数 | 当前规则 |
| --- | --- |
| 加工位 | 2个；最多1口锅。每口锅占1位，每份直烤食材占1位 |
| 燃料上限 | 240分钟 |
| 每木材 | +60燃料分钟，投料即时、不自动点燃 |
| 持续燃烧 | 每流逝1世界分钟扣1燃料分钟，不按加工对象倍扣 |
| 主动熄火 | 不耗时，剩余燃料保留，不退成木材 |
| 照明 | 只照当前火堆地点，离开不随身；移动始终无照明 |

投木必须完整容下60分钟：`maxAdd=min(可用木材,floor((240-fuel)/60))`；燃料180加1到240，190时连1也拒绝。投料是消耗，不是可取消返还的配方预留。

## 3. 点火入口与选择

必须指定随身或当前地面可用打火器，不能空手点火；本版白名单不含火柴等新工具。拖该工具到指定火堆松手即校验开始；或点击火堆卡下“点燃”，在带图标的次级工具菜单点选实例即开始。即使只有一把也要点选；无工具显示原因；不自动挑另一把，不追加第二次开始。

右栏在悬停工具/落点时展示5分钟、身体消耗、燃料与自动投木后果。工具菜单明确“选定即开始”；Esc/点击菜单外关闭不扣费。已燃火堆不能重复点燃。

## 4. 点火费用与边界

点火固定5分钟、craft身体速率但不算过劳工作，基础打火器不损耗。燃料0且有可用木材时自动投1木材获60，无木材拒绝；燃料1—4拒绝，≥5可点且不强制另加木材。自动投木需在预览明确，与取消自动补水相互独立。

开始时校验、投木、工具锁与行动建立原子提交；失败不先扣木材。0燃料自动投木后完成剩55分钟；燃料恰好5会在完成后耗尽，预测提前告知。刚点燃火堆这5分钟不加热，其他已燃设施照常。

S01主行动执行中不能插点火；暂停可做维护子行动，完成原主行动仍暂停。火堆复燃时S11被动进程自动续行，不能把它与角色“继续主行动”混为一个按钮。

## 5. 展示与状态

第二行火堆卡直接显示图片、燃烧、燃料、加工位和内嵌锅；点图只选中，不开内容物覆盖菜单。燃料与水量/受热进度分别显示。保存facilityId/locationId/lit/fuelMinutes/processingSlots和棚/床垫状态。锅/水/食材唯一归属由S10维护。
