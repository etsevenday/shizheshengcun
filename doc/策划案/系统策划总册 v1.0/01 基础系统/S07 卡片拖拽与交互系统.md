## 1. 操作目标

物品以卡片整理、跨区转移、投料和组合；卡片相叠不代表任意合成。点击/拖拽调用相同玩法校验，UI不直接扣物。固定地点、资源点、火堆、棚和床垫是目标，不可搬走或拖动排序。

## 2. 起拖与数量

左键移动超过6px起拖，否则松手为点击；起拖后的松手不得再次触发点击。影像显示名称、数量、来源，拖动预览不扣物。工具/整锅按1实例；同区排序整张堆卡不拆，跨区、合堆、投料、装水默认1份，Shift松手选择数量。

数量框按实际源量、堆叠、容量、重量给范围；取消不提交，不把已确认数量静默截断。Esc、失焦、拖出窗口无效返回；最高层弹窗存在时背后不接收拖动。

| 水煮肉→锅食材区 | 即时存放，不重复水煮 | S10/R06 |
| 生块根→火堆直烤位 | 即时存放，热源合格自动烤 | S11 |
| 锅/锅内水/食物→地面或随身 | 即时取出所选实体；进度/预留按S11 | S10/S11 |
| 随身刀/斧→对应资源点 | 预览绑定工具，明确开始 | S05 |
| 原料→另一原料/配方材料槽 | 打开候选/补引用，不直接扣料开工 | S08 |
| 原料→营地地点/棚卡 | 打开适用建造候选，不自动建造 | S09 |

不再有“食物→左侧自身卡”的投放目标；选中可自用物品后点卡下按钮。左状态条、右人物页签均不是隐形使用区。

## 4. 热区优先级与回落

明确锅内热区→锅卡→火堆明确热区→普通区域；子卡阻止向父对象冒泡。根落锅只能入锅，缺水显示未加工，不改烤制；锅满失败不回落到火堆。木材走燃料，水直接扔火堆不灭火/不产净水。

普通物品卡面无组合时可回落所在区域插入线，按排序/转移；明确设施/资源热区非法则说明原因并回原位。不能用普通回落吞掉一个本应拒绝的设施操作。

合法即时目标绿色+动词；需另确认的普通采集/制作目标琥珀+“查看”；点火专用落点写“松开后开始点火·5分钟”；非法目标禁止符号+具体原因，不只靠颜色。

## 5. 嵌套卡、滚动与请求

锅标题/主图拖整锅，水和食物图标拖对应内容；箭头、按钮、水量条不是整锅把手。火堆/锅内容直接显示，不再逐层菜单。拖动中可滚轮移动目标栏，之后重算热区，不能投到滚动前坐标。

DropRequest至少sourceId/targetId/verb/quantity/requestId，解析为动词、原因、即时或行动请求。起拖可预解析可见目标，松手须再验；同拖拽使用同requestId。GameEngine.Drop等旧类名仅是历史映射，语义不要求另造内核。

沿用S01的忙碌/锁/所在地限制，无触屏、筛选、自动排序、自由画布、任意容器嵌套。新增可交互对时，先更新本表与对应玩法案，再由UI复用。

## 6. 点击转移与新增用途边界

Q5-2：所有用于转移的三角箭头，点击即转移1份/1实例，不打开操作条。地面→随身、随身→当前地面；设施中的整锅、直烤物、锅内液体/食物→随身，均沿用同一所在地、负重、预留与占用校验。方向和目的地须在悬停说明；若要其他目标或数量，点物品图标后在操作条明确执行。失败不回落到其他目标，也不先清加工进度。

拖动与按钮仍走同一玩法请求。活性物质不开放“拖向左栏自身/右栏人物/饱饱”的新投放热区；首期从选中卡片的“吞噬融合”按钮进入R07，后续若增加拖拽用途须另改白名单。

## 7. 对话层与卡片输入

人物对话按S14 §10覆盖地图/设施两行，并锁住全局游戏输入至读完，不因地面/随身仍可见而放开拖拽、箭头或使用。出现对话前取消尚未提交的拖拽与落点预览，物品保持原归属，不补一次松手点击。对话形象、文字框和记录正文均不是投放热区；不得拖给主角或饱饱自动使用/融合。正文滚轮只滚对话，不透传背后卡片栏。记录浏览层同样不接收物品投放；关闭后恢复原选择，重新发起的操作仍走现有玩法校验。
