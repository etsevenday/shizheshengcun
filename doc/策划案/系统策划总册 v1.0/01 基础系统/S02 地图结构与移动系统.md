### 门槛运行规则

1. **方向与锁存**：from固定为数据原edge.from，不能用运行时currentLocation代入。世界门槛第一次满足写campaignId+edgeId永久解锁；正反共享同锁。未满足时正反均查原锚；首次走通返程绝不再要求原to探索100。单向出口无reverse。世界旧已开边保持；不等于免费传送，仍付原分钟并检查位置/终局/事务。
2. **实例与重验**：房间探索、守卫及核心clear使用当前campaign+dungeon+generation；实例边锁只活在该代，重置后重新探索/战胜。核心出口每次验证当前代recordClaimedAndClear，旧首通/别地牢/只杀守卫均不算。即便世界任务锁存，进入还须通过同队/实例状态/非战斗等通用检查；01反走外部仍由S01远征状态决定免罚或有代价，边解锁不免撤出惩罚。
3. **登记不会循环**：h01公开登记人位于城外营门，0分钟明确登记提交registration_authorized；持此可走h01→h02原5分钟边，到达成功事务才hub_registered、QMAP01登记完成与C2。其他9条register边必须hub_registered；不允许仅看鸟瞰完成登记。
4. **固定路障**：clear_checkpoint专指m02的单局固定拦路迟缓尸任务战最终胜利且主角存活后checkpoint_obstruction_cleared。它不取S04随机清理次数、不靠随机抽物或未来副本守卫；旧该任务完成等效。
5. **城市先可达再服务**：c02/r02真实首次抵达分别记church_contacted/academy_contacted，公共城内边据此开放。公开城市/服务23节点（含h05专用安全地）首次到访自动探索100，探索按钮禁用、不发探索里程碑物资、不随机接敌，避免要求不可探索建筑100的循环。普通野外与副本按逐节点探索表，不全局套固定30分钟/+25；土地与城市类别不从zone字符串推断。
6. **选择拒绝不锁主线**：c02接受调查或拒宣誓领取公开路线同写FA02_route_briefed；r04仅环境/拒检测领公开路线同写FA03_environment_briefed。两套accept/入口gate各复用同一个事实，不设置含糊“已接或到某步”。r05入口不前置室内同意；r07门旁免费公开告示确认仅观察可得academy_observation_pass，拒绝实验照样通行。关窗不提交可再谈；岗位替代告示不依赖特定NPC活着。
7. **核心主线**：FA04先具两种不同记录资格（或相应Legacy等效），到h02明确开始wait10，两个5分钟段实际完成才FA04_merged；离开保段。FA05_power_owned读取d03_08已领取电源的campaign事实communication_power_claimed，不是背包持有量。d05—08父地探索100入内，不要求先在未进房间探索，也不要求可选任务全清。
8. **旧档与触发边界**：每个首次条件完成/到达/对话事务后重判，先满足后到访不漏；历史已有世界边锁保持，不补旧奖励或伪造组织对白。可信旧主线记录给等效资格，不把所有世界边或新实例守卫门一键开放。迁移缺路线事实可在相应公开地点免费交谈补，不生成第二个claim。

### 3.1 地块相对方位（本轮新增）

地块卡增加相对主角当前所在地的方向图标，方位与区域地图使用同一套布局。现行`data/config.v0.6.json`地点`mapX/mapY`已提供区域示意位置，`MapOverlay.razor`按其绘制；本次只读核对该来源，不修改配置或代码。S02维护地点布局的语义，S14 §16维护卡面位置/反馈。示意坐标不等于格子移动、距离或旅行分钟，不改变§3的物理连接和解锁条件。

以当前地点节点为原点、目标节点减当前节点得到方向向量；沿用区域图X向右、Y向下。取最接近的八方向：↑上、↗右上、→右、↘右下、↓下、↙左下、←左、↖左上。跨22.5°等分边界按统一规则归入顺时针下一扇区，双方互换应显示相反方向；不由卡片在横向列表中的左右位置推断，也不根据主角立绘朝向或上次移动方向旋转。

现行8条连接的方向核对如下，仅是现有布局推导结果，不是新增连接/可达规则：

| 连接两端 | 从前者看后者 | 从后者看前者 |
| --- | --- | --- |
| 临时营地→农野荒地 | →右 | ←左 |
| 农野荒地→溪流浅滩 | ↙左下 | ↗右上 |
| 农野荒地→树林边缘 | →右 | ←左 |
| 农野荒地→废弃村庄 | ↓下 | ↑上 |
| 废弃村庄→五金店 | →右 | ←左 |
| 废弃村庄→诊所 | ←左 | →右 |
| 树林边缘→废料场 | ↘右下 | ↖左上 |
| 五金店→废料场 | ↗右上 | ↙左下 |

主角移动中仍以原当前位置为参照，到达事务成功提交后统一刷新；取消/死亡留起点，不提前翻转。当前地点标“当前地点”/当前位置点，不给自身一个移动方向。只对已按原规则可见的地块显示方向，未知节点不因方位泄露；已发现但不可直达的区域图节点可以显示方位，但原不可达/未解锁标记与移动禁用保持。

布局数据缺失或两个不同地点重叠而无法判向时，不能临时按卡序编方向；不显示伪箭头，在详情说明“方位未配置”并由程序登记数据缺口。现有坐标足以覆盖本期8地点，无需另建独立方向配置或存档字段；未来调整布局时，区域图/卡片方位由同一来源同步更新。
