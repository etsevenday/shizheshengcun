# 适者生存 · 系统策划总册

整理日期：2026-10-27。编目版本1.0；各系统从单案修订1.0开始独立维护。本总册基于原始XMind与现有v0.1—v0.7策划重编；不代表游戏发布1.0，不修改游戏代码。

## 从这里开始

原来按时间版本散放的规则，现已重编成**15份基础系统案、6份参考扩展案**。每份有职责、有效规则、数值表/参数归属、边界、相关系统、验收目标及来源。正文可以作为对应系统的开发输入，不需要先叠读所有旧版本。

基础设计含原案策划补齐的可调初值，表示当前整理采用的设计口径，不等于全部经用户逐项确认或已接入程序。参考扩展保留人物/战斗/感染方案，不能因整理进总册就自动开启。原始特色系统进入储备，仍暂缓。

- [策划总纲与维护约定](<00 总则/00 策划总纲与维护约定.md>)：系统边界、数值归属、后续怎么改。
- [规则迁移与待定清单](<00 总则/01 规则迁移与待定清单.md>)：已合并的冲突、仍需决定的缺口。
- [程序交接与验收索引](<04 附录/A04 程序交接与验收索引.md>)：按功能交给程序的文档组合、验收入口。
- [改动说明](<CHANGELOG.md>)：本次重编的结构调整、规则合并、验证范围与GitHub交付说明。

## 后续怎么提修改

可以直接说“修改S11烹饪系统：新增……”，或“调整S04树林清理掉落表”。我会更新对应主案和必要联动，不再为每轮问答创建一组并行版本文件夹。涉及多个系统时，先在待定/变更清单登记，再同步各案。

各系统文件路径与编号保持稳定；小改增加单案修订，重要阶段再做归档快照。旧文档与图片保留作历史依据，日常开发优先使用本总册；不移动/删除旧文件，不把历史JSON直接当最新运行配置。

GitHub阅读说明：系统案和内部链接完整保留；历史原案未随本包上传，包外链接已改为来源文字。来源快照仅供追溯，不是运行配置。
