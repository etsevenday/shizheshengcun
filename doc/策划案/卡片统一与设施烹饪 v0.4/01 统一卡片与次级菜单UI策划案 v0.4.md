# 适者生存：统一卡片与次级菜单UI策划案

> **基础UI修订 v0.7（2026-10-26）：** 地块两行布局、火堆与锅内容物直接内嵌、拖工具/选工具即开始点火、全菜单滚轮、右栏人物入口与卡下自用操作，以[基础UI布局与操作修订案](<../基础UI交互修订 v0.7/基础UI布局与操作修订案 v0.7.md>)为准。本文第4节逐层内容物菜单及相关U403/U411验收属于历史方案；其余未被替代规则继续有效。

版本：v0.4。配套：[裁定与交接](<00 需求裁定与开发交接 v0.4.md>)、[设施与烹饪](<02 设施内容物与烤制水煮策划案 v0.4.md>)。

## 1. 地块卡片区的结构

用户截图1红框内由“场景底图+文字胶囊”改为“地点卡、连接卡、资源卡、设施卡”的统一卡片桌面。场景底图可作为弱化背景保留，但不能代替具体对象的图片。左侧HUD、下方当前地面/随身栏、右侧信息栏保留。

卡片分组顺序为当前地图卡 → 已发现相邻地图卡 → 固定设施卡 → 已发现资源卡。当前地图始终一张，邻接卡仍遵守发现与连接规则，不提前展示未知地块。固定设施不可拖入背包，图卡化不等于新增可搬建筑玩法。

“地图卡”指具体地点的图卡；顶部“区域地图”导航按钮继续保留，不在本次移除范围。尚未建造遮蔽棚/床垫用建筑插画、虚线框及“未建造”标识，点击查看建造条件，不将其计为已建成设施或真实可转移物品。

## 2. 卡片统一规范

| 组成 | 地面/随身物品 | 地图与设施 | 设施内物品 |
| --- | --- | --- | --- |
| 卡框 | 沿用现有浅色卡面与描边 | 复用同一圆角、描边、标题、图片区 | 复用物品卡框，可紧凑排列 |
| 名称 | 物品名 | 地点名、火堆、遮蔽棚等 | 真实物品名与实例标识 |
| 主图 | 当前物品图标/插画 | 地点环境、火堆、建筑各自图片 | 与地面/随身同物品使用同图 |
| 角标 | 数量 | 当前/相邻、已建/未建、燃烧状态 | 数量、所属设施与加工状态 |
| 底部 | 重量、保质、耐久、水量、操作 | 探索/清理或设施操作 | 水量、加工进度、取出/拾取 |

同一物品全局通过itemId/instanceId找到同一图标，不用不同地方各写一张相似图。烤熟与水煮块根使用不同图或处理标记+文字，不只依赖颜色。设施总量、物品堆数、水量百分比和进度使用独立标签。

主图至少占卡片可用内容高度的约三分之一；卡名与关键按钮不得因加图缩成难读小字。卡片基准宽度沿用现有物品卡，设施卡允许占两张基础卡宽以容纳内部卡片，不能缩成文字胶囊。视口不足时地块区内部滚动/换行，不覆盖HUD和地面栏；正文至少16px，辅助文字至少14px，点击热区至少40px。

## 3. 地图卡内探索与清理

移除“地块行动 ▸”按钮及其独立行动菜单；不再要求先点地名才能看到探索/清理。当前地图卡下方直接列动作：

```text
[树林边缘图片]
树林边缘 · 当前地点 · 探索75%
[探索周边 · 30分钟]
[清理 · 20分钟]  次数3/4 · 恢复还需3小时40分
```

探索到100%时**不渲染探索按钮**，保留“已充分探索”文字与进度，清理上移。只针对已满探索隐藏；因角色忙碌而暂不可用时仍显示按钮和原因。清理0次时保留按钮并禁用，下方显示恢复倒计时。

已知相邻地图卡显示图片、名称、访问状态、单程基础时间及移动入口，不显示探索/清理按钮。移动入口沿用现有确认流程，不因探索/清理点击直接执行而一起改变。

探索/清理仍是**指向或键盘聚焦预览、单击直接开始**；不在右侧再放第二次“确认探索/清理”。开始时玩法层再次校验当前位置、进度、次数和占用。100%不显示按钮并不替代后端检查；过期点击、快捷键或旧请求仍应被拒绝。

开始请求发出后立即锁定动作输入，重复点击或按键不排队。最后一次探索完成并移除按钮时，清理按钮可以上移，但不继承旧探索按钮的按下状态或键盘焦点；必须有新的明确点击才能清理。卡内按钮阻止事件冒泡，不同时触发地图卡选择或移动。

默认右栏显示当前选中对象；悬停/聚焦具体动作时临时显示该动作预测，离开后恢复选中对象；执行中以当前主行动信息优先，不能用悬停盖掉进度或危险原因。菜单关闭、物品转移、燃料变化、身体变化后重算有效预测。不得展示已锁定的随机抽签结果。

## 4. 火堆内嵌卡片与内容物菜单

火堆卡保留主图、燃料、燃烧状态，并在卡内展示加工位缩略卡和“内容物1/2”入口。锅放入后至少在火堆卡里直接可见其图、名称、水量和加工状态，不只显示“锅位：金属锅”文字。

缩略锅卡本身就是可交互目标，可直接接收水或食材；展开火堆内容物菜单后显示更完整的同实例卡。嵌套界面可以显示同一实例的缩略图与详情，但两个视图都绑定同一个owner，不是两个物品，不分别计数。

点击火堆或内容物入口，在截图红框对应的地块区域打开设施次级菜单。次级菜单可覆盖该地块区域，HUD、地面、随身、右侧仍可见；不是恢复被移除的“地块行动”菜单。菜单包含设施图、燃料、2个加工位、实际内容卡、投料、打火器图卡选择及点火；点击锅卡继续展开锅内容层。

层级为“地块卡片区 → 火堆内容物 → 指定锅内容物”。返回或Esc只退一级；关闭菜单不取走内容物、不停止设施加工、不取消主行动。普通物品详情、配方选择等仍可用次级菜单，本次只移除专门承载探索/清理的旧入口。

## 5. 设施内转移与直接投放

锅进入火堆后，地面栏与随身栏都不显示该锅卡或标记副本。火堆内容物中该锅显示“临时营地／火堆／金属锅#实例”，不能只写“当前地面”。

| 操作 | 结果 |
| --- | --- |
| 拖锅到当前地面空白 | 取下，锅与内容整体归当前地面 |
| 拖锅到随身区 | 整锅拾取，校验锅壳+水+食物总重 |
| 点锅卡转移箭头 | 卡边打开图标、数量、目标的操作条，提供“取下到地面”“拾取到随身” |
| 拖水到火堆内的锅水量区 | 直接向该锅手动装水；不需先取锅 |
| 拖生块根到锅食材区 | 加入该锅真实内容；满足条件后水煮 |
| 拖生块根到火堆直烤空位 | 放入该位烤制，不能误入锅 |

拖动经过目标锅时可展开其水量/食材投放热区，实际松手命中的最深明确目标优先：锅内容热区 → 锅卡 → 火堆明确热区 → 普通区域。食材落到锅时不得冒泡到父火堆变成烤制；落点缺水、满容量或禁用时显示原因，不偷偷改投其他目标。明确设施目标失败不回落成地面排序。

水卡落锅水量区、食材落锅食材区；木材落火堆燃料区；打火器落火堆绑定点火工具。锅内水/食物也支持拖出与点击转移。单份默认1、Shift数量选择、整次超重拒绝、requestId幂等和世界时间不因整理流逝等规则保留。

## 6. 手工制作与其他次级菜单图标化

凡以物品或设施对象身份出现的独立展示项，必须同时显示图标、名称和数量/状态；不要求给普通说明句中每个名词插图，避免长段落碎片化。

| 位置 | 必须展示 |
| --- | --- |
| 配方列表 | 产物图标+名称+时间；设施加工标“自动加工” |
| 输入原料槽 | 原料图标+名称+所需/现有/预留数量+来源 |
| 输出预览 | 产物图标+名称+件数+实际留存位置 |
| 催化工具/容器条件 | 锅、打火器等图标+名称+具体实例/所在 |
| 投料按钮 | 木材图标+“投入1木材·燃料+60分钟” |
| 点火工具选择 | 每把打火器图标+名称#实例+随身/地面+选中标记 |
| 配方缺料 | 原料图标+名称+缺少数量，不用孤立红字代替整行 |
| 数量与转移条 | 来源对象图标+名称+数量+目标，不只显示“转移N” |
| 设施与锅内容 | 每个真实内容卡的图标、数量/水量和状态 |

烧水、烤制、水煮在制作菜单可以保留“处理说明”入口，但改为图示步骤、选择指定设施/容器及定位目标；不能继续显示会额外扣角色30分钟的旧“开始烹饪”按钮。普通石刀、斧、绷带、建棚、床垫的主动制作流程保持。

菜单中的可用原料默认来自随身与当前地面，设施/锅内物资是明确独立来源。普通手工制作不能自动从正在加工的内容物中抽料；若需要，先手动取出。自动补齐配方引用不等于自动补水，也不把物品自动搬入锅中。

## 7. 资源交付与空状态

需要地点8张图、火堆熄灭/燃烧状态图、遮蔽棚/床垫图、已有物品图标和新增水煮块根图。占位阶段可复用同一绘制风格资源，禁止仅以文字胶囊作为完成状态。缺图时使用统一占位图+名称，并列入资源缺失清单；不要显示破图或空白可点击区域。

锅空时显示空锅图、水量0%、食材0/2；空加工位显示明确空位图框与可放对象提示。未建棚与床垫用建筑图与未建状态区分；不凭插画显示就开启设施收益。

## 8. UI验收

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| U401 | 地块红框内地图、火堆、建筑 | 均有独立图片和统一卡框，不只文字胶囊 |
| U402 | 锅由地面/随身放入火堆 | 原区域卡消失，火堆内出现同一锅ID |
| U403 | 设施内锅缩略卡及菜单详情 | 绑定同实例，不重复计数/计重 |
| U404 | 拖水/根到火堆内锅 | 命中锅对应热区，不触发父火堆处理 |
| U405 | 从设施拖出或点击取下/拾取 | 两条路径结果一致，整锅内容跟随 |
| U406 | 当前地图75%与100% | 前者两按钮；后者无探索按钮，仍有清理 |
| U407 | 非当前相邻地图 | 有图和移动入口，无探索/清理 |
| U408 | 点击探索/清理 | 一次点击直接执行，无地块行动入口及重复确认 |
| U409 | 清理次数0或角色忙碌 | 按钮和原因可见；不会把所有暂禁用当作隐藏 |
| U410 | 制作输入、工具、投料、打火器选择 | 全部图标+名称+数量/状态，含缺料态 |
| U411 | Esc退出火堆/锅菜单 | 只退一级；内容物不丢失、不取出、不停止加工 |
| U412 | 窄屏或多卡 | 保持最小字号和点击热区，地块区滚动不遮HUD/地面 |
| U413 | 缺图与未建建筑 | 占位图可辨；未建收益不生效 |
| U414 | 右栏预测与设施完成 | 数值随实际变化更新，主行动执行信息优先 |
