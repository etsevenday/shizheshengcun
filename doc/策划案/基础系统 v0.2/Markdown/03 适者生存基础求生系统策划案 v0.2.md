# 适者生存基础求生系统策划案

基础系统 v0.2   |   2026年10月21日   |   三人团队单机原型

本版采用地点卡、资源点卡和物品卡呈现末日单人生存。三份系统案共同定义“发现地点 → 移动探索 → 定向搜集 → 搬运加工 → 补给休息 → 再次出发”的基础循环，供策划与开发直接拆分任务。

本次优先级高于旧版范围案中的对应规则：暂停侵蚀、轮回、超能力、善恶值、招募和联机；同时暂不接入战斗。取消10日硬终局，改用7日生存检查目标，达成后可以继续游玩。

统一使用游戏内分钟推进时间，替换每日12行动点。配置值为本项目原型建议值，可调但不能由开发各自补定。时间与状态由基础求生案负责，地图和搜集系统通过同一行动流程调用。

## 基础求生的职责

维护唯一游戏时钟、身体状态、行动速度、营地恢复、食物与饮水效果及死亡判定。地图与搜集系统只提交行动类型和基础工作量，不自行重复扣饥饿或水分。玩家浏览界面和整理物品时世界暂停。

## 时间基准

| **项目** | **本版约定** |
| --- | --- |
| 开始时间 | 第1日00:00为绝对分钟0，开局08:00即480。 |
| 最小推进 | 5游戏分钟；所有动作耗时为5的倍数。 |
| 昼夜与跨日 | 06:00至18:00为白昼；00:00切换下一游戏日。 |
| 状态范围 | 健康、饱食、水分、体力、清醒度、精神均为0至100，越高越好。 |
| 死亡条件 | 仅健康降至0直接死亡；其他状态通过明确惩罚影响健康或效率。 |
| 测试目标 | 抵达第8日08:00且存活；完成七日检查后可继续，不自动重置。 |

借鉴两作“时间推动身体与资源变化”的关系，首版只保留少量可解释状态。体重、营养素、免疫、寄生虫、多部位伤口、温湿度、季节和精神疾病均不在本版实现。理智暂归入“精神”这一简化指标，不连接侵蚀或超能力。

## 02 阈值伤害与危险提示

| **状态或条件** | **触发** | **实际效果** |
| --- | --- | --- |
| 健康 | ≤25 | 高危提示；允许继续行动，归0死亡。 |
| 饱食 | ≤20；等于0 | 低值提示；等于0时健康每小时减2。 |
| 水分 | ≤20；等于0 | 低值提示；等于0时健康每小时减8。 |
| 体力 | <20；等于0 | 工作时间倍率乘1.25；等于0且做工作动作时健康每小时减1。 |
| 清醒度 | ≤20；等于0 | 提示需要睡眠；等于0时健康每小时减2。 |
| 精神 | <20 | 休息与睡眠的正向体力恢复减半，不直接导致死亡。 |
| 腹泻 | 状态存在时 | 在基础水分消耗之外，每小时额外减3水分。 |

饱食、水分、清醒度归0造成的伤害可相加。体力归0不会锁死角色，可继续低效工作并承受额外健康损失，也可立即休息。工作动作包括移动、探索、搜集、制造和建造。

### 统一伤害计算

每个5分钟时间段先读取段首状态，确定基础变化、倍率和该段伤害。段首状态为0才累计该状态的归零伤害；该段末刚降至0时从下一段开始计伤。由即时食物、饮水或绷带恢复的状态在推进其5分钟消耗前生效。

### 提醒与中断

首次向下越过饱食20、水分20、体力20、清醒度20、精神20或健康25时，完成当前5分钟段后暂停行动，展示原因、剩余工作量与预计后果。继续后不在同一区间反复提醒；恢复至阈值以上再下降时重新提醒。【实现同步】状态继续降到0时再暂停主行动一次并说明正在扣健康，同一区间不重复，回到0以上再归零时重新触发；归零与死亡提示优先于普通提醒。

暂停支持继续、取消，以及满足当前位置条件的补给或休息。补给与维护作为子动作执行，原行动保留预留与进度；不允许另起移动、搜集或制造。归零与死亡提示优先级高于普通提醒。【实现同步】子动作本身不会被暂停：子动作期间越过的阈值只记录，结束后回到暂停层一并展示；同一时刻只有一个子动作，不做子动作栈。移动途中暂停时只能用随身物品补给，休息按露天结算，不能点火或整理物品。

## 03 饮食饮水与加工闭环

| **物品或操作** | **即时结果** | **后续约束** |
| --- | --- | --- |
| 净水1单位0.5升 | 水分加30。 | 最多100，溢出浪费；消耗5分钟。 |
| 脏水1单位0.5升 | 水分加30。 | 必定腹泻12小时；追加饮用刷新至12小时，不叠倍数。 |
| 罐头1单位 | 饱食加35。 | 无保质期，数量有限；不产生空罐副产物。 |
| 野果1单位 | 饱食加10，水分加5。 | 生成24小时后腐败。 |
| 熟块根1单位 | 饱食加25，精神加2。 | 生成24小时后腐败。 |
| 生块根或腐败食品 | 不可直接食用。 | 提示先烹饪或已腐败，不扣物不耗时。 |
| 草药绷带1单位 | 健康加5。 | 60分钟冷却；不是食物，不治疗腹泻。 |

### 安全饮水

溪流取脏水 → 带回营地 → 点燃火堆并把2份脏水拖进金属锅装满（不自动补水） → 烧水15分钟，锅内2脏水原地变成2净水 → 从锅里饮用或倒出【实现同步】。水量按0.5升单位离散计算，金属锅是容量1升的简化容器。基础水源不随机失效，首版不设置旱季或水污染浓度。

### 稳定食物

荒地采生块根 → 使用营地火堆和金属锅 → 烹饪30分钟，将2生块根变为2熟块根。加工不增加同类物品重量；食物效果可在卡牌上查看，食用前展示是否会溢出。

每天基础饱食消耗36、水分消耗72；若含8小时重活动，额外消耗3饱食、12水分。两份熟块根可提供50饱食，三份净水提供90水分，足以覆盖该示例日的39饱食与84水分。此为量纲校核，实际要考虑食用时机、加工和不同活动构成。

## 04 休息睡眠与营地恢复

### 休息

任何地点可以选择休息30、60或120分钟。基础每小时恢复20体力，不恢复清醒度；营地建成遮蔽棚时每小时额外恢复2精神。体力已满仍可休息，但应提示剩余收益与饮食消耗。【实现同步】休息面板同时提供“等待30／60分钟”：不恢复任何状态，按等待类别消耗，用于等天亮等场景。

### 睡眠

任何地点可选睡眠2、4或8小时。五金店、诊所及建成遮蔽棚的营地使用遮蔽睡眠；其他地点使用露天睡眠。不要求夜晚才能睡，睡眠开始前展示当前条件和恢复速率。不得默认跳过饥渴、腹泻和燃料消耗。

遮蔽睡眠每小时恢复12清醒度、15体力和1精神；露天睡眠恢复6清醒度、10体力，精神每小时减0.5。营地已有床垫时，睡眠体力每小时再加5；精神低于20时，对体力的全部正恢复量乘0.5。

### 自然恢复健康

仅在休息或睡眠中、处于遮蔽条件，且段首饱食和水分均至少40、精神至少20时，健康每小时恢复1。该恢复不抵消归零伤害判定的先后顺序；用同一5分钟时间段合并加减后再夹紧到0至100。

### 睡眠中的危险

低值或健康高危提示也会暂停睡眠，玩家可以饮水或进食后继续剩余时长。睡眠不会因清醒度或体力满100而自动结束，只有计划时长用尽、玩家取消、条件暂停或死亡才结束。

### 设施效果边界

遮蔽棚改变营地睡眠条件，床垫只改善睡眠体力恢复；火堆只提供当前地点照明和加工条件，不直接提高体温或防止野兽袭击。本版无随机夜袭，不能用未实现的威胁解释睡眠损失。

## 05 行动速度与统一时钟

### 工作量与真实流逝时间

移动、探索、搜集、制造和建造以“基础工作分钟”计进度。每个5分钟段在段首求修正M，工作进度增加5÷M，世界时间推进5分钟。进度达到目标即完成；不足一个段也按完整5分钟结算，不保留跨动作的工作余数。

M = min(2.0，夜间系数 × 负重系数 × 体力系数)。适用时夜间系数1.5，否则1；重量超过20公斤系数1.25，否则1；体力低于20系数1.25，否则1。每段重算，因此跨昼夜或在中途恢复体力会改变后续耗时。

夜间系数作用于移动、探索、搜集、清理，以及无照明的制造与建造。地点火堆燃烧则该地点视为有照明；只有移动始终视为无照明。休息、睡眠、等待、食用、饮水、绷带和点火按固定时长，不受这些工作倍率影响。

### 工作与固定时长

| **类型** | **推进方式** | **身体消耗** |
| --- | --- | --- |
| 探索基础30分钟 | 轻装白昼至少6个时间段。 | 按explore的实际流逝时间计算。 |
| 移动基础20分钟，M保持1.5 | 需6个时间段，共30分钟。 | 按travel计算30分钟，不只算20分钟。 |
| 移动20分钟，M保持1.953125 | 需8个时间段，共40分钟。 | 同理按40分钟消耗。 |
| 睡眠8小时 | 固定96个时间段。 | 每段都计算饥渴与恢复，无瞬间跳时。 |
| 饮水5分钟 | 先应用即时补水，再推进1段。 | 用wait类别的基础消耗。 |

体力降至0依然采用低体力倍率并承担工作伤害；不额外再叠加速度惩罚。屏幕显示当前估算时长；若预计途中跨入夜晚，可按已知昼夜日程预估，但不得把估计值写成保证值。

## 06 时间段结算与动作事务

### 动作开始

校验地点、资源、材料、工具和前置条件 → 生成actionId并保存随机结果 → 预留材料或资源 → 保存活动状态。确认即时类操作时先扣物并应用效果。单角色只存在一个主行动，暂停维护子动作不能覆盖主行动数据。

### 每个5分钟段

1. 依据段首时间、身体状态与所在地，计算该段工作倍率、身体变化和健康增减。
2. 推进世界5分钟，应用身体变化并夹紧到0至100，扣除各地点正在燃烧的燃料，处理跨午夜补充与物品到期。
3. 若健康归0，终止动作并执行死亡；否则检查持续条件，必要时暂停或中止。
4. 累积本段工作进度；达到目标时，先校验有效材料与条件，再提交移动、探索、产物或设施结果。
5. 结算动作末尾环境伤害并再次判死；保存状态，展示提醒或返回操作。

例外精度：若火堆恰好在本段末燃尽，而该段开始时燃料覆盖完整5分钟，则该段工作有效，可以完成加工；不足5分钟燃料时先暂停加工，不推进该段，要求投料。食材恰好在完成时刻到期视为已腐败，不能出锅。

### 取消与恢复

取消在时间段边界处理，已消耗时间不返还；探索和移动不提交结果，搜集和加工释放预留，设施不生成半成品。恢复存档时根据activeAction续行，不能再次扣材料、重掷风险、重发里程碑或跳过已过去的时间。

### 存档

每次动作开始、每个5分钟段、主动作完成及取消后保存，即时操作（拾取、投料、装水、排序等）成功后也保存。【实现同步】网页版写入浏览器本地存储的单槽键 survival.save.v1，不经临时文件；包含schemaVersion（当前3）、绝对时间、角色状态、物品批次（含锅内归属）、资源预留、随机状态、设施与锅位、各地清理次数、主动作与单个子动作、卡片排序、最近请求号。离线不推进时间。

游戏死亡后锁定所有行动，显示原因、存活时长、已探索地点及基础检查目标完成情况。【实现同步】原因取最后一次使健康下降的来源，同段多来源按饥饿、缺水、缺睡、过劳、受伤的顺序取第一个；结算同时显示种子以便复现。重新开始完整重置世界和角色；v0.2不提供跨局继承。

## 07 初始条件与七日检查目标

### 开局条件

第1日08:00，角色位于临时营地，状态见第01节。随身有金属锅1和打火器1；营地地面有罐头2、净水2、木材2、纤维2、布料2、石块2。营地火堆未点燃，遮蔽棚和床垫未建造。地图只开放营地至荒地连接。

### 前三天的引导顺序

| **时段** | **引导目标** | **完成标记** |
| --- | --- | --- |
| 第1日 | 探索荒地，找到水源与树林；安排第一次饮食和睡眠。 | field≥50；访问stream或woods；至少睡眠一次。 |
| 第2日 | 完成烧水和块根烹饪，比较露天与遮蔽恢复。 | boil和cook各完成一次；建造遮蔽棚。 |
| 第3日 | 进入村庄或搜集工具，建立一份次日补给。 | 访问village；携带或营地有净水3与熟块根2。 |

引导只显示建议，不因超日未完成失败，不锁住探索顺序。检查标记来自真实行动与当前库存，不能用点击教程按钮替代。【实现同步】标记达成即锁存，之后消耗物资不回退；“净水3”把锅内净水按锅所在（随身或营地）计入。食材补充、保质和火堆燃料必须参与这些步骤。

### 七日验证

到第8日08:00仍存活时显示“七日基础生存检查完成”，附记录：是否建立安全饮水、是否完成食物加工、是否建成遮蔽棚、是否访问全部8地点。只要求存活触发提示，其余是可见进度，玩家可继续完善，不触发胜利重置。【实现同步】检查在第8日08:00所在的5分钟段结束后触发，不打断进行中的行动，行动结束后再弹出结算层。

### 数值可行性的检查方法

用固定配置录制一条保底路线：先发现溪流与树林，利用初始工具处理水和食物，再回营建设。记录每次行动的开始结束时刻、状态、物资与燃料。至少验证“溪流加块根”与“野果加遗迹补给”的不同准备方式均能度过早期，不能只依赖随机伤害未触发。

首日不足以完成所有设施属于正常情况。若测试发现仅靠反复休息、无限制造或重复开箱就能无代价增长物资，应先修复事务与补充规则，再调数值难度。

### 实施顺序

先实现5分钟时钟与无随机状态算例，再接工作倍率、地图和搜集；随后加入休息、睡眠、火堆、加工及腐败，最后接提醒、存档和七日检查。统一配置文件提供初始值和清单，数值修改需同步验收算例。

以上算例为实现验收目标，未代表游戏已开发或通过真实玩家测试。首轮试玩重点记录死亡来源、往返时间、补给次数、露天睡眠代价及过量搬运，评估后再调整默认数值。
