本案基于基础系统v0.2、交互扩展v0.3、卡片与设施v0.4及已有实现同步记录。**不修改现行配置，不自动宣布旧案“战斗暂停”失效。** 全部新增数值为本项目初值，不是参考游戏的原始参数。配套：[参考数据配置](<人物与战斗参考数据 v0.5.json>)。

## 01 设计方向与范围

核心体验是“为搜集做准备—识别敌人—选择武器与目标—承受资源和身体损失—决定继续还是撤退”。击杀是取得资源和通过威胁的一种方式，不保证每场都值得打。

首版沿用一名玩家角色，对抗1—3张敌人卡。招募、伙伴、四人职业队、联机、复杂掩体地图和自由走格仍不接入。先用站位、行动点、武器差异、体力、恐慌和少量状态产生策略，不同时添加力量、敏捷、智力等另一套基础加点。

| 借鉴对象 | 采用的方向 | 本作处理 |
| --- | --- | --- |
| 僵尸毁灭工程 | 生存活动熟练度、工具与武器的实际用途、环境威胁 | 按制造、医疗和武器门类成长，不采用整套原作技能与感染公式 |
| 卡牌生存 | 对象卡片、身体状态、武器/工具与求生共用物资 | 简易斧、石刀既采集也战斗，同一实例共用耐久 |
| 暗黑地牢 | 回合选择、前后排可攻击范围、先手、压力与撤退 | 单人2行动点对多敌，复用健康，另设仅战斗内恐慌 |

参考原作不等于复制原作敌人。下文丧尸变体和野兽为本作自定义卡片；不声称喷吐者、野犬、狼、野猪等全部存在于《僵尸毁灭工程》原版。

## 02 人物信息分为三层

### A. 原有求生状态：保持含义

健康H、饱食N、水分W、体力E、清醒度S、精神M仍是0—100且越高越好。健康同时作为战斗生命，不生成一条打完后自动回满的“战斗HP”。死亡仍为健康≤0且本局结束。

体力直接支付招式成本；饱食和水分影响持久生存；清醒度和精神影响战斗表现。保持旧阈值与战后状态，不能离开战斗就抹掉损失。

### B. 新增技能：长期熟练度

采用0—10级，各技能独立经验。普通新角色初始均1级；旧档接入时也初始化1级，不根据历史操作补经验。没有“总等级提升后全属性上涨”。

| 技能ID | 名称 | 用途与升级收益 |
| --- | --- | --- |
| crafting | 制造 | 手工与建造基础工作量×(1−0.03L)，最多减少30%；不影响火堆自动受热 |
| medicine | 医疗 | 绷带健康恢复5+floor(L/3)，上限8；改善止血处理，不能治疗所有疾病 |
| firearms | 枪械 | 手枪、霰弹枪、步枪的命中与伤害；首版不再拆瞄准/装填经验 |
| blade | 刀斧 | 石刀、厨房刀、简易斧；偏出血和重击 |
| spear | 矛 | 木矛、金属矛；偏触及后排与稳定输出 |
| unarmed | 拳 | 空手攻击、推挡与低资源自救 |
| archery | 弓箭 | 弓、弩；安静远程，消耗箭矢或弩矢 |
| blunt | 钝器（建议增设） | 撬棍等；避免把所有近战物品都塞进刀或拳 |

L为对应技能等级。制造修正发生在基础工作量阶段，再用旧5分钟tick及夜间/负重/低体力倍率推进，不直接改世界时钟。旧已开始制造行动沿用开始时快照；自动烧水、烤制、水煮不吃制造加速。

### C. 战斗派生数据

玩家基础速度4、闪避5、护甲0；武器提供基础伤害、基础命中、暴击率、体力成本与攻击范围。护甲采用固定减伤，首版不新增全身装备槽；后续衣物装备再单独扩展。

恐慌P为0—100、越高越不利，**与精神M不是一条数值**。入战P=floor((100−M)/2)，受惊遭遇再+10。每次受到直接伤害，P增加ceil(实际伤害/3)。P≥60：命中−10、撤退−10；P≥90：瞄准不可用，命中总惩罚变−20，撤退总惩罚变−20。不强制玩家随机跳过回合。

战后精神额外下降floor(P/20)，上限5；P清除。胜利不自动恢复健康或体力，不发可反复刷取的精神奖励。

## 03 经验与成长

从L升到L+1所需经验为50×(L+1)；达到10级停止累计。每次扣当前门槛后继续判断多级提升，不能把累计经验直接当等级。

- 制造：成功完成一次有效配方，获得clamp(ceil(原始配方基础分钟/10),1,12)经验。取消、预览、重复事件与设施被动加工无经验；整批制作按实际提交的配方次数计。
- 医疗：一次真实恢复健康或移除出血的有效治疗+4经验；健康已满且没有出血时不发经验。不能对同一个治疗事件重复领取。
- 战斗：对敌命中并造成直接伤害，每次玩家指令给对应武器技能+2；同次群攻无论命中几个也只+2。每个敌人对同技能的战斗命中经验最多计3次。闪避、空挥、反复防御、装填不发经验。
- 胜利/成功撤退均保留已经得到的操作经验；死亡不跨局继承。技能升级在指令完整提交后生效，预览不能用尚未获得的等级。

不设置“打死才有全部经验”，降低最后一击诱导；也不按原始伤害无上限发经验。制造消耗资源、医疗受真实需求限制，首版不另设训练假人或挂机练功。

同一敌人的经验次数按encounterId+enemyInstanceId+skillId保存，撤退重进不清空，不能靠反复进出重置计数。

所有普通攻击1AP。实际武器重量计入随身，装备栏只是对随身实例的引用，不再复制或额外增加一次重量。玩家选择一把当前武器，入战前可免费调整；战中换到另一把随身武器耗1AP，无额外体力。不能把地面、火堆或远端容器里的工具当作随身武器。

执行一次攻击扣该武器1耐久，无论命中与否；群攻一次只扣1。耐久0禁止该武器攻击，当前指令若由耐久1变0仍可完成；之后可换武器或徒手。采集仍按旧“成功一次扣1”规则，不能战斗磨损后又扣一遍采集损耗。制造/采集正式预留中的武器不能被偷偷调入战斗。

## 05 弹药、装填与噪声

| 武器 | 弹药ID | 装载容量 | 装填 |
| --- | --- | --- | --- |
| 木弓 | arrow 箭矢 | 不设弹仓 | 每射直接消耗随身箭1，不另花装填AP |
| 弩 | bolt 弩矢 | 1 | 1AP，从随身填到上限 |
| 手枪 | ammo_9mm | 8 | 同上 |
| 霰弹枪 | shell_12g | 4 | 同上 |
| 步枪 | ammo_rifle | 5 | 同上 |

弹药必须对应类型，不能用同一“子弹”包容全部枪械。装填只消耗实际填入量，库存不足可部分装填；已满时禁用。弹仓内弹药属于武器实例内容并计重，散弹药减少相同重量，不能重复计重。箭/弩矢50克，9mm与步枪弹各10克，霰弹30克；首版不回收箭，失手也消耗。

空弹仓不自动装填，不能透支弹药。确认射击后先原子扣AP、体力、弹药与耐久，再结算命中；重复请求不能重复扣或多打一次。

噪声只做战斗内的可见“吸引危险”条0—100：每次枪械开火+25，弩+5，木弓和近战+0。首次达到100，若敌方存活<3，则下一轮开始加入普通游荡尸1；若已满3，记录待加入，之后第一个可用轮初加入。每场最多增援1次；开火当下最后一敌已被击杀时直接胜利，不为已结束战斗补增援。逃走不追发增援，不新增全世界声波传播系统。

## 06 招式与通用动作

技能门槛只限制招式，1级即可使用该门类基础攻击。招式可以先全部显示并标注解锁等级，不把基本武器使用锁在高等级。

| 动作 | AP | 条件/效果 |
| --- | --- | --- |
| 基础攻击 | 1 | 表中体力；选合法目标 |
| 刀斧：重劈 | 2 | 刀斧≥3，体力8，命中−10，伤害×1.6；不附免费眩晕 |
| 刀斧：割伤 | 1 | 刀斧≥2，体力4，直接伤害×0.75；命中后施加出血2×3次；对丧尸无效，仅动物/玩家流血 |
| 矛：精准突刺 | 2 | 矛≥3，体力7，命中+10，伤害×1.35；后排仍有0.75修正 |
| 拳/钝器：推挡 | 1 | 对应技能≥1，体力4；零直接伤害，按基础命中判定，命中令目标下次行动失衡 |
| 枪械/弓箭：瞄准 | 1 | 对应技能≥2，体力0；本轮下一次同武器射击命中+20，使用或轮末清除 |
| 霰弹：散射 | 2 | 枪械≥3，体力5，消耗1发；对前排至多2敌各做一次命中，伤害×0.7 |
| 防御 | 1 | 体力0；到下次自己行动开始前，下一次直接伤害×0.5，只挡一次 |
| 调整呼吸 | 2 | 体力+6、恐慌−10；一回合至多一次，敌人仍正常行动 |
| 换武器/装填 | 1 | 体力0；只操作随身，不能顺便白拿物资 |
| 医疗：包扎 | 2 | 消耗随身绷带1，移除出血；健康恢复受医疗等级和原60分钟冷却限制 |
| 勉强拳击 | 1 | 仅体力不足正常攻击时；体力0，伤害×0.5，基础命中−20，拳技能；不磨损原武器 |
| 撤退 | 2 | 一次尝试，规则见第11节 |
| 结束行动 | 剩余AP | 未用AP清零，不积攒到下轮 |

包扎健康冷却沿用角色级60分钟；冷却内允许消耗绷带只止血但不恢复健康，预览必须明确。没有出血且冷却未好则禁用，避免无效消耗。战外包扎也用同一冷却和医疗加成，耗5分钟；战内已花2AP，不再即时跳5分钟，时间统一在轮末结算。

武器招式只在当前装备门类匹配时可用；推挡也必须处于徒手或钝器门类，不能拿着刀免费借用拳的动作。防御与瞄准重复施加不叠层，只刷新同一个状态。有效治疗发放医疗经验，之后按新等级计算下一次治疗，不能用本次刚升级的数值回算已提交疗效。

## 07 回合、站位与先手

敌方最多三个槽：前排F1、前排F2、后排B1；己方仅一名玩家，不伪装成已经有四人队。近战刀/拳/钝器只能打前排；矛可戳后排但减伤；弓/手枪/步枪可打后排；普通霰弹只打前排。

敌人死亡立即移除卡，不留下阻挡尸体位。**轮末**把后排存活敌移至最左空前排；其本轮已行动标记不变，不能因移位多动。若轮中前排全空但后排还在，玩家近战可直接选后排，视为无前排屏障，不吃矛的后排减伤。敌人前排攻击均能打到唯一玩家；后排近战敌若轮中仍有前排屏障，本次用1行动“前压/等待”，不隔人抓咬；具远程/嚎叫能力者可在后排使用。

每轮开始固定行动队列：initiative=有效速度+均匀整数1—4，高者先，平手按稳定战斗实例ID升序。每个角色每轮只进入队列一次；玩家激活时获得2AP，敌人激活时执行1个招式。前后排不是随机先手修正，不另给一整轮免费攻击。

每轮为一个抽象的5分钟求生时间段，包含周旋、观察、攻击与喘息；不是宣称每次挥刀持续5分钟。任何已发生有效战斗指令的轮，即使中途胜利或撤退，也只在退出/轮末推进一次5分钟；只浏览尚未确认指令不推进。首版不用秒级战斗时钟，避免与既有5分钟设施/补充系统再造两套时间。

## 08 命中、暴击、伤害与身体修正

```text
有效速度 = max(1, 基础速度 - [E<20]*1 - [S<=20]*1 - 减速层数*2)
命中率 = clamp(基础命中 + 2*武器技能L + 招式命中修正
               - 目标闪避 - 状态惩罚, 5, 95)
暴击率 = clamp(武器基础暴击 + 0.5*L, 0, 30)
伤害 = max(1, floor(整数随机基础伤害 * (1+0.04*L)
                    * 招式倍率 * 站位倍率 * 暴击倍率) - 目标护甲)
最后若目标防御生效：伤害 = max(1, ceil(伤害*0.5))
```

暴击倍率1.5；先判命中，命中后独立判暴击，再抽整数基础伤害。群攻逐目标按槽位顺序分别抽取，不共享命中，但同一攻击指令只付一次成本。所有概率内部保留小数，不用向下取整的显示值反推。

状态惩罚：E<20命中−10；S≤20命中−10；P≥60/90按第02节−10/−20择一；本次失衡再−10。饱食/水分≤20不再额外叠同类命中惩罚，它们已通过生存消耗施压。

敌人使用各自固定命中、暴击0%、固定面板伤害区间，无技能等级加成；对玩家判命中时只减玩家闪避及其自身失衡。敌人的重击倍率在敌人招式中说明。玩家暴击不额外免费回体力，敌人也不暴击秒杀。

范例：1级简易斧攻击闪避0、护甲0的普通尸，命中77%；基础抽10、未暴击，floor(10×1.04)=10伤害。防御时受到9直接伤害，最终ceil(9×0.5)=5；流血不被护甲或防御减免。

## 09 状态简化

| 状态 | 规则 |
| --- | --- |
| 出血 | 下一次自己的激活开始扣2健康，剩余触发次数−1，共3次；不叠伤害，重复施加只刷新到3次；丧尸免疫 |
| 失衡 | 下次实际攻击命中−10，攻击结算后消失；最多保持至下一轮末；不强制跳整轮 |
| 减速 | 下轮先手速度−2，下轮结束清除；同来源不叠层，仅刷新 |
| 防御 | 下次自己激活开始清除；此前挡下一次直接伤害，挡后移除 |
| 瞄准 | 仅本轮下一次同武器射击+20命中；换武器/轮末清除 |

回合开始处理“自己的出血→判死→清旧防御→恢复本次AP”。受出血死亡则不再行动。玩家战后残留出血转成战外每5分钟扣2健康，剩余次数继承；下一次世界tick才触发，刚结束战斗的轮末不再多扣一次。

医疗既不把僵尸咬伤自动变成必死感染，也不承诺绷带治愈病毒。首版咬击体现为直接伤害、流血与恐慌；复杂感染、抗生素、缝合及部位伤害列后续专题，不在参考稿里藏一个必死概率。

## 11 撤退与战斗终局

撤退占2AP，体力4；若不足4，可用0体力尝试但撤退率再−15。概率=clamp(55+5×(玩家有效速度−敌人最高有效速度)−恐慌惩罚,20,90)。按本轮生效速度计算，UI显示明确百分比。

成功：本轮结束并推进5分钟，退出战斗，回当前地点；不是免费传送回营地。失败：AP用尽，其他尚未行动敌人正常行动。每轮最多尝试1次，不通过关界面重新掷骰。

胜利：全部敌人死亡或逃离，按正常时间结算一次后，地块栏恢复；进入可关闭结果层展示健康/体力/精神变化、耗弹、耐久、经验及地面战利品。撤退不领取场上敌人尸体与丧尸掉落，已消耗资源不返还。

健康≤0立即判死，本轮只记录已发生的时间段，后续敌人与奖励不再提交；不启用《暗黑地牢》式濒死豁免，避免与原健康0死亡冲突。不会因为“最后敌人同一指令也死亡”改判胜利复活。

若直接攻击或轮初出血在轮末世界tick前致死，立即冻结在此前已提交的世界时刻，不为死者再补一段饥渴/设施模拟；日志保留这轮已发生的战斗事件。若轮末tick本身致死，该tick已经发生，不得回滚或再补第二次。

## 12 战斗与原求生时间

战斗使用独立battleId与roundIndex，但共用世界时钟。每个已发生行动的轮只调用一次5分钟世界tick：战斗基础小时率N−1.875、W−4.5、S−5、M−0.5；E的自然率为0，已经按招式支付，不能再套gather额外扣一次。E=0期间仍按原工作类过劳健康−1/小时，战斗计入工作动作；其他归零健康伤害及腹泻照常。

设施燃料、自动烹饪、食物到期、清理回复和午夜补充按同一tick更新。5分钟体力消耗是招式总成本而非角色饥渴双重成本。角色战斗中无法因火堆料理完成自动吃到食物。

普通低值提示在战斗内改为非阻断警告，不弹旧“主行动暂停/补给子行动”面板；玩家通过本轮合法动作处置。世界归零伤害若在轮末致死，优先死亡，不提交战利品。战斗中使用绷带占2AP，不能再发一个旧5分钟即时子行动。食物和饮水首版战斗中禁用，逃离后再补给；不能用免费物品拖拽连续回血。

## 13 遭遇、地图与原行动衔接

为降低首版中途打断和预留恢复成本，**初版只在探索/清理成功完成后检查遭遇，及点击可见敌人卡主动接敌**；暂不在半程移动、睡眠、制造和设施处理中强插战斗。先提交原行动进度/解锁/随机物资、扣次数，再判遭遇；不因战斗失败回退已完成结果或再抽一次物品。

第1日与camp不随机遭遇；第2日起按地点表做一次遭遇判定。固定每5分钟轮末不再叠世界遭遇，撤退与绕行也不再触发递归遭遇。

| 地点 | 完成探索/清理后的遭遇率 | 可能组合（等权选择） |
| --- | --- | --- |
| field | 10% | 游荡尸1；野犬1 |
| stream | 8% | 游荡尸1；野犬1 |
| woods | 15% | 野犬1；游荡尸2；灰狼1（后续阶段） |
| village | 20% | 游荡尸2；游荡尸1+嚎叫尸1 |
| hardware | 20% | 厚衣工尸1；游荡尸1+厚衣工尸1 |
| clinic | 15% | 游荡尸1+爬行尸1；嚎叫尸1 |
| scrapyard | 25% | 厚衣工尸2；防护尸1（后续阶段） |

野猪、鹿与狂奔尸优先作为手工放置/测试敌人卡，暂不塞进随机表，待平衡后扩展。未开放阶段的组合从抽样集合中剔除后等权，不因抽中未实现敌人而出空战斗。

若某地本阶段没有任何已实现组合，则不做该地随机遭遇并在开发配置检查中提示；不创建无敌人的战斗。首批原型正常随机表仅使用游荡尸、爬行尸；野犬先供开发测试，尸体处理和肉类加工接入后才开放正常野犬遭遇。

随机遭遇先显示“发现敌踪”卡及敌方组成：玩家可选择接敌或绕行。绕行固定10分钟，按travel消耗、无新随机掉落/遭遇，清除该次敌踪；不改变位置，不直接逃回上一个节点。允许绕行是首版保护，待战斗验证后再讨论不可规避的伏击。

逃走后的同一敌踪保留存活敌的血量，已死敌不复生、已有状态只清战斗临时态；再次主动接敌用同一encounterId，不能重复领取此前死敌掉落。战斗结束时未领取的尸体奖励只在最终胜利时一次生成；绕行清掉敌踪意味着放弃其中战利品。每地最多一个未处理敌踪；有敌踪时再次探索/清理先要求接敌或绕行，不追加叠敌。

## 14 掉落、动物与食物闭环

丧尸每个死亡实例一次抽签：未获50%、布料1份30%、废金属1份20%；原资源池不扣，不掉无限成品枪和净水。首次成功整场胜利才将累计死敌掉落提交到当前地面；撤退重进不能重复发。

动物死亡生成其动物尸体卡1，留当前地面；野犬尸体1.5kg、狼3kg、野猪6kg、鹿4kg，12小时腐败。新增“处理尸体”30基础分钟，craft消耗、需随身有效石刀/厨房刀/简易斧，成功磨损该工具1；制造加速不作用于此，医疗不代替屠宰技能。

处理野犬/狼/野猪/鹿分别产出生肉2/3/4/3份及兽皮1；取消按旧加工规则返还原尸体至地面，原腐败时间不刷新，完成时已腐败则不产物。尸体源与产物不能同时存在。

新增生肉300克、12小时保质、不可直接食用；兽皮500克、无保质、首版仅储备不设高级皮革链。生肉可沿用v0.4设施规则：直接火堆30受热分钟→烤肉，锅内每份预留/消耗净水500毫升、30受热分钟→水煮肉。烤肉N+35/W−3/M+2，水煮肉N+32/W+5/M+3，均300克、24小时保质、食用5分钟。原锅食材白名单必须新增生肉及两种成品，仍最多2份，不能因新增肉类绕过容量。

## 15 武器取得与首版原型范围

不要只写出枪械面板而让正常流程找不到枪。参考取得方案：

- 沿用石刀与简易斧配方、原耐久和采集用途。
- 木矛：木材2、石块1、纤维2，45基础分钟→木矛1；木弓：木材2、纤维4、布料1，90分钟→木弓1；箭矢：木材1、石块1、纤维1，30分钟→箭4。都由制造修正基础工作量。
- 五金店探索50%新增独立“武器柜”一次性搜集30分钟，产撬棍1、厨房刀1；不替换原锅具箱，不补发历史已搜柜子。
- 村庄探索75%新增独立“上锁储物柜”一次性搜集30分钟，产空手枪1、9mm弹12；首版暂不做开锁技能，名称可改“旧储物柜”避免误导。
- 金属矛、弩、霰弹枪与步枪先提供开发测试箱，后续专题再做正常取得途径；未进入首版的武器不假装已能由现有配方制作。

三人团队建议先做：单人/1—2敌、石刀/斧/木矛/木弓/手枪、游荡尸/爬行尸/野犬、攻击/防御/包扎/装填/撤退、出血与恐慌、战斗地块覆盖层。第二批加3敌站位、钝器、精英/嚎叫、其他动物和尸体烹饪；第三批再加其余枪械、护甲装备、感染与队友。

所有本案完整规则为参考目标，未做的阶段在配置关闭；首版没有动物尸体处理时，野犬只用于战斗测试、不作为正常掉落与求生供给入口。

## 16 UI：只覆盖最上方地块栏

进入战斗时，以战斗覆盖层替换中央最上方地块卡片区域；不盖住顶部全局导航、左侧求生HUD、下方地面/随身栏、右侧信息栏。战斗结束恢复原地块滚动和选中对象。

```text
顶部：游戏名 / 地点 / 导航（战斗中地图制作休息入口锁定）
左HUD   ┌ 战斗第3轮 / 行动顺序头像 / 噪声50/100 ────────────┐   右信息栏
健康等  │ 玩家图卡+AP2/2     F1游荡尸   F2爬行尸   B1嚎叫尸 │   动作/目标
        │ 武器/弹药/耐久      HP/护甲/状态/公开意图          │   命中/伤害
        │ 攻击  招式  防御  包扎  装填  撤退  结束行动       │   体力/耗弹
        └───────────────────────────────────────────────┘   世界消耗
        当前地面：保留可见，战斗中锁定拾取/投放              战利品位置
        随身物品：保留可见，仅合法战斗物品可选               不重复确认
```

敌人卡保持统一插画、标题、数量/实例与状态框；不用纯文字行替代敌人。当前行动者高亮，已行动者角标区别；可选目标亮框、不可选目标显示“后排/射程不足”，敌人意图用图标+文字。只有一名玩家也显示武器技能、体力和恐慌。

上方区域高度不足时，顺序条与动作条固定，卡片区内部滚动，不能把关键战斗按钮挤进地面栏。基准1600×900、最小1280×720，字号沿用UI v0.4；本案先交布局规则，不将文本框图当最终美术稿。

点击敌卡只选目标，不攻击；点动作显示右栏预览，再点其“执行”确认本条指令。该规则与探索/清理一次点击开始不同，避免玩家误选敌人就消耗稀缺子弹。切换武器、装填等也显示确切成本。执行期间锁定输入并即时提交requestId，不允许动画期间叠点。

下方物品仍可查看，但禁止拾取、放下、排序改归属、投料、装水、制作和战外使用按钮。合法包扎、装填、换武器从战斗指令读取随身物，不调用旧即时行动。Esc只关目标详情或打开战斗菜单，不能关掉覆盖层免费脱战。

## 17 数据、保存与边界

SkillState保存各技能level/xp；角色武器栏保存itemInstanceId引用；枪械实例保存loadedAmmoId/count；EnemyDefinition和EnemyInstance分开，实例保存HP、slot、status、意图与是否已发掉落。

BattleState最少包含battleId、encounterId、locationId、roundIndex、queue及其游标、双方AP、pendingTick、选中目标、恐慌、噪声/增援标记、所有状态持续期、PRNG与最近请求号。战斗内预览不推进PRNG；指令确认事务统一保存扣费、骰子与结果。玩家不能靠读取改变已经执行指令的命中；不保证取消未确认预览锁定未来骰子。

EncounterState另存敌人剩余HP、死亡记录、尚未提交的掉落计划、各敌各技能经验计数。掉落在敌人首次死亡时锁定，最终胜利时一次落地；再次接敌不得重抽此前死敌掉落。

每条指令提交、敌方行动结束、轮末世界tick、战斗结束均保存。读取中途战斗直接恢复覆盖层和当前队列位置，敌人不会再行动一次；pendingTick保证胜利/撤退只推进一个轮时间段。角色死亡不再提交后续攻击/掉落。

采用新且未占用的存档schema；不能仅凭本案v0.5名称认定程序schema也为5。旧档技能初始化、cooked_root等存量保留，旧进行中行动不强插战斗；战斗开关默认关闭，评审后再启用。现阶段不改旧文档“战斗暂停”的有效性。

## 19 一场完整战斗示例

用于说明流程，命中、伤害与先手均指定为例子，不代表普通战斗保证如此。

玩家H90/E60/M60、刀斧1级、简易斧耐久17，前排有游荡尸18HP和爬行尸14HP。入战恐慌20。第1轮先手抽值为玩家3、爬行尸4、游荡尸2，速度加骰子后分别7、5、4。

1. 玩家先用两次普通斧击攻击爬行尸，均命中、不暴击，各10伤害，爬行尸死亡；消耗2AP、10体力、2耐久。
2. 队列跳过已死亡爬行尸。游荡尸命中造成6伤害，玩家H84、恐慌22。
3. 轮末推进5世界分钟，照常计算饥渴、清醒和设施；不再额外扣gather体力。玩家E50。
4. 第2轮假设玩家仍先手，两次10伤害斧击击杀游荡尸；E40、斧耐久13，刀斧累计获得8经验。
5. 最后敌死亡，结算本轮唯一一次5分钟tick，共10世界分钟；判定仍存活后将两尸已锁定掉落一次放地面。恐慌22带来战后额外精神−1；健康84、体力40保留，不自动补满。

玩家若第1轮改为攻击1次+防御，可以减少一次敌方直接伤害，但更晚解决爬行尸，其减速可能影响下一轮先手；这就是“尽快减少敌方行动数”和“保守承伤”的取舍。
