## 02 数值尺度与显示

健康H上限20、初始20；体力E上限20、初始18。饱食N80、水分W80、清醒S90、精神M60的初值与0—100范围保留。新增免疫I初始70、范围0—100，病毒程度V初始0、范围0—100。

健康20不是另开“战斗生命”；受伤、饥渴、疾病和战斗都影响同一个H。健康≤0生命终结；V≥100尸变结束本局，即使健康还高也不能继续。

内部保存至少1e−6精度，不按UI显示两位小数回算，不在每5分钟先舍去小数。小于0.01但仍正的成本/生命显示“<0.01”，不显示为0。阈值比较使用统一数值策略，浮点实现允许≤1e−8的比较容差；不能因累计误差使理论100病毒永不尸变。验证脚本感染部分采用有理数计算精确核对边界。

旧H/E全部按0.2缩放，包括当前值、上限、警戒线、恢复、损伤、招式体力和历史伤害提示。例：健康高危25→5，低体力20→4，绷带基础恢复5→1，饥渴归零损血也缩放。N/W/S/M、物品重量、时间与食物的饱食补水效果不缩放。

## 03 无等级封顶的熟练度

制造、医疗、枪械、刀斧、矛、拳、弓箭、钝器共8项，初始1级，各自经验。移除10级上限，不再出现“满级停止经验”。升级门槛继续为50×(当前L+1)，逐级扣经验；等级和经验应使用能覆盖长档期的整数/数值类型，溢出报错而非静默回零。

“不封顶”指等级和能力收益不被人为截断。概率仍不能超过100%，损耗不能为负，生命恢复不能超过当前上限；这些是结果范围，不是10级/95%的成长硬上限。

| 收益 | 公式 | 说明 |
| --- | --- | --- |
| 对应武器伤害倍率 | 1+0.035L | 持续增长，无1.4或2.0倍率硬截断 |
| 对应武器命中能力A | 武器基础A+3L | 能力值持续增长，之后与目标闪避共同换算概率 |
| 对应武器体力成本 | 基础成本/(1+0.025L) | 持续减少且正值，不减为负，不硬钳至某一固定成本 |
| 制造工作量 | 原始工作分钟/(1+0.025L) | 不再“最多减少30%”；设施被动受热和处理尸体不吃该加速 |
| 绷带健康恢复 | 1×(1+0.02×医疗L) | 无技能硬上限，实际只补缺少的健康 |
| 绷带病毒抑制量 | 2×(1+0.01×医疗L) | 仍不能把已感染程度降至1以下或清感染状态 |

制造仍按5分钟tick。高等级单件即使基础工作量小于5分钟，也不能让世界倒流；同一已预留批次可在一段内制作多件、结转该批剩余工作量，使高熟练度继续提高批量产量。不得跨到无关配方白送进度、超出材料或重复产物；普通单件最低一段是时钟精度约束。

经验继续按有效制造、有效医疗、造成直接伤害的攻击发放，预览、空治疗、装填、防御不刷经验；群攻按一次指令计，不按每目标倍增。同一世界敌人/技能最多计3次命中经验，计数随worldEnemyId保存，巡游、撤退、换encounterId都不重置；这是反刷规则，不限制技能总等级。

## 04 命中、暴击与小数伤害

命中能力A与闪避能力D均为正值：

```text
A = (武器基础A+3L) × 招式命中系数 × 身体状态系数
实际命中概率 = A/(A+D)
暴击能力C = 武器基础C+0.3L
命中后暴击概率 = C/(C+100)
直接伤害 = max(0, 随机基础伤害×技能倍率×招式倍率×站位倍率×暴击倍率−护甲)
防御生效时，直接伤害再×0.5
```

随机基础伤害在武器区间内连续均匀取值；暴击倍率1.5。敌人用固定攻击能力，无技能倍率、无暴击。取消原5%—95%命中夹紧、30%暴击上限和最低1伤，不对最终伤害取整。护甲高于伤害可完全挡住该次直接伤害；此时不触发“造成伤害”经验或咬伤暴露。

玩家闪避能力36。普通游荡尸攻击能力20，对玩家命中20/(20+36)=35.71%。1级简易斧命中能力27，对游荡尸闪避25，命中51.92%。玩家每轮2AP，敌人一次动作，且玩家H20而普通尸H3.6，提供前期优势；低命中不等于让前期玩家与怪物完全对等。

身体修正乘命中能力，不直接扣百分比：E<4时×0.85、S≤20时×0.85、P≥60时×0.85、P≥90改×0.70（后两者择一）、失衡×0.90。技能越高仍持续改善，不被固定95%封顶。恐慌初值(100−M)/2，直接受伤后P增加实际伤害×1.5；战后精神−min(5,P/20)，不因缩小伤害导致恐慌完全不涨。

本次命中的低体力修正以支付本次招式成本后的E为准，预览也按这一值计算；轮初先手仍按轮初E，不能在轮中重排整个队列。

实际能力值趋近无穷时概率趋近100%但不超过；这与“允许100%后继续变成150%命中”不同。若未来需要溢出命中转暴击，应单独立项，不在本版暗中转换。

最大耐久在实例生成时按0.1精度均匀抽一次，保存seed结果与实例ID。新制品current=max；拾荒物品可另有0.6—1.0成色，current=max×成色。不能每次读档、转移、装备、拾取或展开卡片重抽。将来附加系统可修改区间、乘数或额外上限，不设全装备统一的最大耐久天花板。

武器每次已执行攻击磨损1，命中与否都扣，群攻不按目标多扣。动作开始前必须有足够耐久支付磨损；例如0.8耐久不能执行成本1的攻击，但可转移或修理。锅损坏后保留内容，不销毁水和食物；没有足够耐久的目标加工显示维护不足，不预扣原料。

为避免锅和打火器从无限使用改为有限耐久后永久卡死，增加基础工具维护：选定随身/当前地面工具，废金属1+零件1，30基础工作分钟，恢复其自身最大耐久20%，不超过自身max、不重抽max。锅须先取下并清空；无资源时可使用备用实例。制造熟练影响维护工作量，不凭高技能免费修复。满耐久禁用，缺料不扣物。

动作沿用2AP框架：普通攻击1AP；重劈2AP、基础体力1.6、伤害×1.6、命中能力×0.9；割伤1AP、体力0.8、直接伤害×0.75、出血0.4×3；精准突刺2AP、体力1.4、伤害×1.35、命中能力×1.1；推挡1AP、体力0.8、不直接伤害、施失衡；霰弹散射2AP、体力1、1发、前排至多2目标各×0.7伤害。门槛仍为v0.5对应2/3级，成本用对应熟练度折减。

防御1AP体力0，只挡下一次直接伤害的一半；调整呼吸2AP体力+1.6、P−10；换武器/装填1AP体力0。勉强拳击1AP体力0，拳伤害×0.5、命中能力×0.65。没有足够体力时仍可防御、恢复或撤退，不形成无法输入的死锁。

**彻底移除瞄准动作和瞄准增益。** 弩弹仓1、手枪8、霰弹4、步枪5，保留1AP装填；木弓不设弹仓，射击直接消耗随身箭。其余弹药、重量和武器取得路线沿用v0.5。不要保留瞄准按钮空位或用“稳住枪”改名重新添加同一动作。

## 07 回合与战斗UI衔接

保持一名玩家、敌方F1/F2/B1、至多3敌；玩家2AP，敌方每激活1动作。每轮先手为max(0.1,速度−低体力1−低清醒1−减速2)+1—4随机整数，平手按稳定实例ID。每轮每人只激活一次，移位不额外行动。

刀/拳/钝器打前排；矛可打后排但伤害×0.75；弓、弩、手枪、步枪全排，普通霰弹前排。前排全空时剩余后排可被近战攻击，轮末再压前。攻击预览、队列游标、死亡/撤退和一次轮末tick的事务沿用v0.5；改用小数值和本案概率。

撤退2AP，基础体力0.8；不足体力可强行撤退，成功率再×0.75。概率sigmoid((己方有效速度−敌方最高有效速度)/3+0.7)，P≥60再×0.9、P≥90改×0.8，结果自然处于0—1，移除旧20%—90%夹紧。失败耗行动，成功回当前地块，不传回营地。

战斗仍只覆盖最上方地块栏。左HUD新增免疫和病毒状态入口，右栏同时给出命中能力值与实际命中率，不把“命中能力27”写成27%。敌卡与武器卡显示小数伤害、随机最大耐久和当前成色；移除瞄准按钮，保留合法装填按钮。

战斗每个有效轮只推进一次5分钟世界tick，角色E只按动作支付，不再套一次采集体力。战斗基础N−1.875/W−4.5/S−5/M−0.5每小时，免疫和病毒也按世界分钟更新。绷带、抗生素、特效药战内均2AP、体力0，实际药物效果在确认时应用，不另跳一个5分钟。食物/饮水仍需脱战后处理。

尸变或健康归0立即锁局；当前轮直接伤害已经致死时不补未来tick。轮末病毒进展致尸变时，当前tick已发生，不回滚也不补第二段。病毒/免疫警告不能打开旧子行动绕过AP。

## 08 免疫力I如何变化

每5分钟读取段首状态，按每小时速率×5/60更新I并限制0—100。以下修正相加：

| 条件 | 免疫每小时变化 |
| --- | ---: |
| N≥50、W≥50、S≥50、H≥健康上限50%、M≥40同时满足 | +0.5 |
| 遮蔽睡眠/露天睡眠 | +2 / +1 |
| 遮蔽休息/露天休息 | +1 / +0.5 |
| 其他动作、等待、浏览本身 | 0；浏览不推进任何恢复 |
| N<20 / W<20 / S<20 | −2 / −3 / −2，可叠加 |
| H<5 / M<20 | −2 / −1 |
| 腹泻 / 已感染病毒 | −1 / −0.5 |

睡眠不是无条件免疫药：缺水、缺营养等惩罚照常计算。感染但营养良好的清醒角色，健康奖励+0.5与感染惩罚−0.5相抵；遮蔽睡眠在此基础上+2/h。食物仍按其N/W/M效果间接支撑免疫，不再让每吃一口普通食物直接加I。

I是生存管理结果，不是打怪升级属性；不会用制造/医疗等级自动把I永久推满。离线不恢复。

## 09 病毒暴露、进展与尸变

只有**丧尸咬击命中且造成正直接伤害**才判病毒暴露；抓击、动物撕咬、护甲完全挡住的攻击不判僵尸病毒。动物仍可造成出血，不混同为僵尸感染。

```text
一次有效咬击的感染暴露概率 = 0.05 + 0.55×(1−I/100)
I=0：60%；I=40：38%；I=70：21.5%；I=85：13.25%；I=100：5%
```

初次暴露成功：infected=true、V=20、连续高免疫计时=0。已感染后再次成功暴露：V+10、计时重置；判定失败不额外加病毒。一次咬击不做两次暴露判定，结果随攻击事务保存，不因读档重抽。

已感染时V按段首I进展：

| 段首免疫 | V每小时变化 |
| --- | ---: |
| 0≤I<40 | +4 |
| 40≤I<70 | +2 |
| 70≤I<85 | +0.5 |
| 85≤I≤100 | −1.5，但未满足治愈前最低1 |

V≥100即尸变，本局结束。无感染时V必须为0，不计算负病毒或自然扣减。20/50/80提供阶段警告、当前变化速率与理论剩余时间；理论时间假设I与用药条件不变，不能写成必定死亡倒计时。

## 10 只有两种彻底治愈方式

### 高免疫持续自然治愈

必须同时满足：I≥85连续720游戏分钟，且V≤10。满足后将infected清除、V归0、计时清0。

任何一段I跌到85以下，或发生新的成功咬伤暴露，连续计时归0。计时只在该段段首与段末均≥85时增加5分钟，避免刚跨线就白拿完整一段。达到12小时但V还高则继续维持I，直到V≤10才治愈，不在12小时无条件清病毒。

例：I85、V20，营养与状态维持良好，12小时后自然V已到2，满足条件治愈；I85、V80，12小时后仅降至62，仍感染。高免疫可能需要更长照护；抑制剂能降低V、帮助进入可治愈区间，但不替代连续时间。

### 病毒特效药

使用antiviral_cure1份立即清infected、V和高免疫计时；不额外回健康、回体力或永久加免疫。战外5分钟wait、战内2AP。游戏已尸变/死亡后不可补救。

免疫与V在同一tick更新后，先判健康死亡/尸变，再判自然治愈。病毒达到100不能被同段计时刚满强行拉回。医疗技能、睡眠、绷带、抗生素或其他食品不能额外提供第三个“清感染状态”入口。

## 11 普通治疗只抑制，不能清除

| 物品 | 病毒/身体效果 | 限制 |
| --- | --- | --- |
| 草药绷带 | 止血；医疗公式回血；已感染时V减少2×(1+0.01医疗L) | 回血60分钟冷却；病毒减量另有6小时冷却；V最低1，不清infected |
| 抗生素 | V立即−8，之后6小时正向进展×0.5 | 给药间隔6小时；不叠乘，负向自然恢复不被减半；V最低1，不清infected |
| 病毒特效药 | 清病毒状态，V归0 | 极稀有，只有本条药物入口能直接治愈 |

绷带处于回血冷却但病毒效果就绪，可只抑制/止血；两种效果都无实际收益且没有出血时禁用，明确原因。病毒减量实际生效或健康/出血实际改善才给医疗经验，同次使用只发一次。

回血冷却与病毒冷却分别仅在对应效果实际生效时启动；未感染时包扎不消耗病毒减量冷却，只止血不延长原回血冷却。抗生素的6小时作用按段首是否在有效期判断，最后一个完整5分钟段仍可生效，不提前少算一段。

药物把V从2减到1时，角色仍感染；不能把“数值接近0”当治愈。若玩家另外已经满足高免疫720分钟，药物减量后在下一次世界tick可能触发**自然治愈**，日志必须记为高免疫治愈，而不是宣称绷带或抗生素直接治好。

特效药取得建议：诊所探索100%新增一次性医药补给箱，固定抗生素2+实验室试剂1，另独立1%概率附带特效药1；村庄探索100%新增一次性废弃冷藏箱，20%抗病毒前体1、80%草药绷带2。旧箱内容不覆盖、不读档重抽、不为已访问旧档补发。

特效药配方：医疗≥15、制造≥12，抗病毒前体1+实验室试剂1+抗生素2+草药4+净水2，营地制作、原始120分钟，需明确指定取下并清空的锅作为不消耗催化工具。净水作为明确原料消耗，不自动装锅、补水或倒出原锅内容。稀缺前体与高技能门槛让制作困难，不保证每局都能找到前体；自然免疫是稳定可规划的主要治愈途径。

## 13 已执行的数值验证与结论

详表见验证记录。做了8组、每组10,000次简化战斗，包含随机先手、命中、暴击、基础敌甲、恐慌与体力；另做正常/低精神日程、感染精确边界和人口上限检查。

1级简易斧对单游荡尸：样本平均约2.20轮、损健康0.41、消耗体力2.51，正常休息约25分钟能补回；95分位为4轮。徒手约5.10轮、耗体力2.84、至少一次病毒暴露约6.25%；斧相同模型暴露约2.13%。因此降低命中仍有早期玩家优势，武器能减少接触时间与咬伤机会。

正常24小时预算：移动3h+探索2h+搜集4h+制造3h+休息2h+等待/饮食2h+遮蔽睡眠8h。穿插休息时E最低7.4，睡后20，未触及低体力4。全天工作总耗22，穿插休息回12，睡眠补足并有溢出；不是建议白天连续12小时工作后才休息。

这个日程自然耗水87.75，若吃两份烤根额外−4，则共91.75；旧“三份净水90”建议不能长期覆盖。此类工作日至少准备四份净水，按缺水量分次喝，避免溢出；采用水煮还要另算加工水。初始水分80能暂时补缺口，不代表每天收支已经平衡。

反例：低精神、10h重活、只休1h、露天睡8h的日程出现E归零。该日程**不满足安全消耗预算**，应增加休息、改善精神/营地或减少工作。不可把睡后最终回了一部分E当作白天没有过劳。

这些结果不是实际工程测试：模拟没有完整实现敌人特殊AI、出血和病毒后续进展，也没验证物资取得或真实手感。尤其3敌群、病中补给与长档敌群分布仍需原型实测。80,000样本里的高胜率只说明基础战斗模型下早期角色有优势，不证明所有战斗都容易。

## 15 游荡迁移、低遭遇与噪声

每180游戏分钟对未交战敌做一次20%巡游判断，至多走一条世界物理相邻边；目标不为camp、不超过目标上限。原地点扣1与新地点加1原子提交，全局数量不变。物理边不依赖玩家是否已发现路线；未知地块名称仍不向玩家泄露。交战敌锁住不巡游，死亡敌不复活；离线不刷新不迁移。

角色当前地点已有的可见敌人卡可主动接近。雄鹿初始中立，不参加随机攻击池，主动攻击才转敌对。新出生避开当前地块，巡游可进入当前地块并提示“新的敌踪出现”，但不立刻强插战斗。

探索/清理成功完成后才检查随机接敌：

```text
探索：P=2%×当前未交战敌对存活数/该地上限
清理：P=1%×当前未交战敌对存活数/该地上限
无敌对敌人：0%；camp：0%；第1日：不随机接敌
```

触发时从**同地已有敌人**组成至多3敌，按最早发现的敌对实例及其余稳定顺序选择，不从刷新器另造怪。先提交原探索/清理产物，再显示敌踪选择；可接敌或绕行10分钟。绕行/脱战后60分钟内不再随机接敌，主动接敌仍可；绕行不杀死/清空世界敌人，只暂时避开本次威胁。

枪声条沿用枪+25、弩+5，达到100最多请求1次增援，但只能调用同地现有、未交战丧尸，保留其原类型与worldEnemyId。没有可用实例则没有新增怪；不为了凑增援超出上限或生成一只新游荡尸。场上已有3敌时等空位，战斗已结束就取消请求。

撤退后的存活敌保留HP和经验计数回世界池，不能换个encounterId刷满血或刷经验。狼/鹿自行逃离时尝试迁到合法相邻地；没有空位则留原地隐藏60分钟，不删除后再刷一只，不给尸体奖励。死亡/掉落计划与持久ID绑定，最终胜利一次结算，重进不重复发。

## 16 存档、事务和接入冲突

新增保存：8项无等级上限技能、实际随机装备耐久、免疫/病毒/连续高免疫时间、药物截止与冷却、世界敌人实例及其HP/经验/归属、刷新和巡游检查游标、已消费的PRNG与requestId。预览不推进任何随机，读档不重掷装备、暴露、刷新或已经提交的战斗指令。

若采用此案，需要一次性迁移旧H/E×0.2，不能每次读取再乘。N/W/S/M不动；旧技能等级/经验保留、去上限。旧装备随机出新的max并保持旧current/max成色；旧锅/打火器原本无耐久则初始化区间满耐久一次。既有实例ID、锅内物品、弹仓归属、布局索引不能复制。

若旧战斗尚在进行，先按旧快照结束或显式结算退出再启用新规则，不在攻击中途缩放一方数值。存档schema由程序选未占用版本，不能由v0.6文件名推断；先备份，失败保留原档。

每世界tick建议依次：读取段首快照 → 更新身体/燃料/设施/药物时间/免疫/病毒 → 终局判定 → 自然治愈 → 清理及资源恢复 → 敌人刷新/巡游 → 原主行动与结果提交 → 警告与保存。料理完成与死亡的优先关系继续遵守既有“死亡先于本段未提交产物”；不要因为加疾病系统重复调用一次世界tick。

与现有规则的主要冲突包括：固定耐久变随机且锅/打火器开始损耗；健康与体力尺度变化；技能不再封顶；制作批次余量规则变化；包扎多一个病毒冷却；地图敌人从临时遭遇变持久池。这些应成组接入，不是只替换武器表。旧v0.5瞄准、整数伤害、10级/95%上限与高遭遇表明确废止于本参考版本。
