# 重墨 V2 · 给开发的动效与版式说明

先看 [离线样机](打开动效样机.html)。可选择 23 个样例，拖动时间轴、重播、跳到结果或启用减少动态效果。这里的毫秒数是表现建议，和游戏世界分钟分别计时。

## 本轮版式

| 位置 | 设计 |
| --- | --- |
| 全局 | 主面板用约 8px 厚的黑铁外沿，卡片约 6px，操作按钮约 4px。斜切角、内侧铜线和局部铆钉在独立边框层。卡名、数值和点击热区各自独立。 |
| 战斗 | 1600×900 基准下，同队中心间距 169px，最近敌我站位间距 360px。人形目标高 244px，过宽轮廓按槽宽等比缩放；足底共用 y=466。名字和站位牌在各自头顶，底部 38px 数值条只放 HP、恐惧等数值与图标。战场人物、HUD、选中标记和相机分开。 |
| 对白 | 一句一个框，按发言身份靠左或靠右，顺序从上到下。气泡尾指向同侧肖像，正文 20px、行高 34px。新句进入 190ms，旧句保持位置；用户向上滚动时保留阅读位置。历史记录使用同样的身份与对齐规则。 |
| 行动浮窗 | 进度、剩余阶段、暂停原因与退出均集中在画面正中。右栏继续显示对象详情。耗时行动按引擎阶段推进，暂停停在最后确认进度，即时动作使用结果反馈。 |
| 势力鸟瞰 | 只在可进入鸟瞰的势力地区提供入口。营区、教会、科学院分别配置建筑轮廓热区，绑定地点 ID。普通区域地图和地牢继续用路线节点。轮廓采用与场景图相同的裁切坐标系。默认淡描边，悬停或键盘聚焦增强，点击只选中并锁定，下一路段独立确认。 |

## 战斗特写的 1200ms 时序

| 时间 | 表现 | 接口数据 |
| --- | --- | --- |
| 0–150ms | 保持全局站位。确认指令、短亮技能和实际目标。 | 指令 ID、行动者 ID、实际目标列表、当前阶段 |
| 150–390ms | 剪入双人构图，画幅遮挡无关单位。近战前压，远程保持距离，治疗靠近受益者。 | 行动类型、攻击者及目标素材 ID、起止锚点 |
| 390ms | 接触帧消费实际结果。命中推退或闪光、未命中侧移、格挡显示盾面、治疗暖绿、远程用弹迹，多目标同镜分别显示。 | 命中判定、实际变化、倒地、状态增减、来源序号 |
| 565–880ms | 数字和状态停留供阅读。倒地保留槽位。 | 显示快照、实际剩余 HP 等 |
| 880–1200ms | 镜头回原位，清理瞬态光效，恢复下一步可用输入。 | 下一行动者、对白或暂停等引擎状态 |

确认后用唯一事件 ID 推进引擎事务，拿到结果快照后入播放队列。接触帧更新显示，重复点、跳过动画、切页、读档都复用已确认的快照。被拒的请求在触发处说明原因。快进时直接显示结果与日志；减少动态效果时使用静态结果反馈，保留数值和文字。

## 其他操作的过渡与结果

| 场景 | 建议时长与方式 | 结果落点 |
| --- | --- | --- |
| 打开和关闭菜单、确认框、说明 | 入场 180–220ms，位移 8–12px 加淡入；退场 120–160ms，遮罩分轨 | 开后焦点进入，关后归还触发按钮 |
| 侧栏、抽屉、二级页 | 160–220ms 从同侧短滑入，底层桌面与四轨固定 | 在新内容标题聚焦 |
| 悬停、焦点、选中、不可用 | 100–180ms 边线变亮、底色变化；保留形状、文字和焦点环 | 临时悬停和已选状态各自独立 |
| 建筑热区 | 默认淡描边，悬停 160ms，名牌浮出；点击 190ms 单次回落到常驻选中态 | 右栏更新已选建筑，点击与 Enter 等价 |
| 移动、探索、采集、制作、烹饪、晾制、休息 | 中央浮窗入场 180ms；每个确认阶段的进度插值 100–160ms | 到达才切换场景；产物从地面或工位反馈 |
| 拾取、放下、拖拽、交接、装备替换 | 180–250ms 从来源到目标，目标亮一次；无效拖拽按原轨返回 | 数量、归属、重量和耐久依实际快照 |
| 食饮、医疗、状态增减 | 160–300ms 目标描边或短标，数值变到实际值 | 目标本人 HUD 或队友卡和头像 |
| 任务、奖励、存档、失败 | 160–200ms 在发生位置淡入；成功提示短停后退场，关键错误和重试持续可读 | 任务册、战利品、地面、底栏或操作入口 |
| 暂停、退出、跳过 | 暂停保留已确认刻度；退出淡出浮窗和不再适用的高亮 | 保留已结算阶段，输入权限依引擎恢复 |

## 接线和验收

1. 表现队列按事件 ID 去重。视图卸载只取消相机、粒子和定时器。重载后显示最终快照，避免重放旧伤害。
2. 用前快照、实际结果与后快照驱动数值、进度和动画。镜头和装饰层不接收点击。关弹层、读档、切后台和跳过时，检查输入锁能恢复。
3. 分别用键盘、鼠标和减少动态效果模式检查命中、闪避、格挡、治疗、多目标、倒地、暂停、退出、无效拖放、重复点击和无效请求。
4. 建筑热区按稳定地点 ID 绑定。覆盖三城、非势力地块、地牢、缩放和键盘选中。实际移动仍在路线确认后进行。
5. 在 1280×720、1600×900、1920×1080 检查文字、浮窗和效果安全边。核对模型时间、库存、日志和显示快照。

建议先接公共开合、焦点与阶段反馈，再接单目标战斗特写，之后扩展多目标、治疗、三城建筑轮廓及其他操作结果。
