# 适者生存 · 重墨 V2 粗框与动效修订

全套 67 页统一加粗框。战斗立绘放大、姓名与站位上移、脚下保留数值条。对白改为交错气泡，行动回到中央浮窗，三城鸟瞰改用建筑轮廓热区。

- [打开动效样机](打开动效样机.html)
- [给开发的动效说明](给开发的动效说明.md)


游戏基线为主线 02ea6a2。美术基线为保留分支的 fd7518c 及策划包的 21 张原始参考。本包是独立离线设计稿。示意存档、数值、文案、地图节点位置和可用状态用于展示版式，正式交互规则由现行游戏和策划案提供。

## 查看

1. 解压后，用 Chrome 或 Edge 打开 [打开全界面.html](打开全界面.html)。
2. 在左侧搜页面标题或编号，或用上方下拉菜单切换。链接末尾的 #P05a 等编号可直接定位到对应画面。
3. 选择「合成」「仅美术」「仅 UI」，也可以逐层开关。切换「清晰阅读」可以对照系统黑体。交付的合成 PNG 与分层文件采用默认寒蝉点阵体。
4. 查看右侧页面下方的现行组件、素材 ID 与原始参考。底部可展开全部 21 张参考和各自的页面去向。

## 效果图与图层

| 文件夹 | 内容与用法 |
| --- | --- |
| 效果图 | 67 张 1600×900 合成 PNG，按页面 ID 命名 |
| 分层文件 | 67 份 OpenRaster .ora，可用 Krita 或 GIMP 打开。每份 7 个命名图层，采用同一画布和锚点。单层透明 PNG 也在各 .ora 的 data 目录内 |
| SVG源稿 | 67 张结构源稿。每个图层是单独命名的 SVG 组，坐标与效果图一致。图像和字体以相对路径引用素材目录，移动时一起复制 |
| 素材 | V2 原始参考、稳定 ID 图集、原始字体授权和复用的场景图 |
| 资料 | 页面源数据、生成脚本、全部组件与页面交叉索引、预览校验记录 |

7 层自下而上依次为场景与光影、底板与分区、主体美术与图标、边框与装饰、操作控件、选中与状态反馈、文字与数值。导出时弹层区域会遮住其后方对应的结构和文字。全页 SVG 的文案仍以可编辑文字保存，OpenRaster 的文字层是栅格导出。

## 给开发的对照点

- 主桌按四条等高区排列，地面和随身各使用独立物资卡。随身金属锅用主图规格，水量与食材摘要独立排在下方。火堆的两个加工位、锅子行和八个晾制位分别有页面样件。
- 整备展示七个现行槽位。防具比较与交接预演分开。整备的锅作为根卡，锅内饮水放在同行食饮页与锅内页。战斗物资查看保留只读版式。
- 战斗使用固定八槽和接地线。敌我人形共用高度基准，犬类与低伏敌人降低目标高，空位保留原位置。横向轮廓过宽时优先保留完整主体。卡牌标记、先手队列与技能插图都与立绘分层。
- 对白将肖像、底框、正文与继续按钮分开，普通对白正文为 20px、行高 34px。代班使用岗位对应的肖像，历史样板保留当时的发言身份。随机招募画为职业示意，正式外观由角色资料提供。
- 地图区的底景、节点、道路、风险与文字各自分层。三城鸟瞰、材料来源、远征饮水预算、地牢实例、封存和重置分别有页面。
- 保留的 21 张原始参考分为物品、底图、布局、人物、鸟瞰、装备和怪物七类。带字或合成的原参考用于构图和材质对照；页面中的对象取用后来核定的透明图集。

完整索引见 [覆盖与素材映射](资料/覆盖与素材映射.json)。组件索引以主线 74 个 Razor 文件为范围，容器、快捷键、子卡等复用组件归入可见的宿主场景。外部反馈入口单列为 PXo。主题覆盖按页面与代表状态计算，同类物品和状态共用模板，不逐条展开为数值组合截图。

[逐页坐标与组件槽](资料/逐页坐标与组件槽.json) 给出面板、操作控件、卡片、肖像和素材槽的左上坐标及宽高。单位为 1600×900 设计像素，弹层前景标为 overlay。

## 重建

使用 Node 18+ 运行「资料/生成界面.cjs」。需要重新导出时，用装有 Playwright 的 Node 环境运行「资料/导出图层.cjs」，参数指定临时层目录。运行「资料/打包分层.py」并传同一目录，需 Python 和 Pillow。参考包里的组件快照和素材均独立于游戏构建。
