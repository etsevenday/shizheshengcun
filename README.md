# 适者生存

末日里的单人卡牌生存原型：探索地点、清理地块、搜集物资、烧水做饭、搭棚过夜、与丧尸和野兽回合制战斗，撑过七天。卡片可以拖动：整理、拾取放下、木材投火堆、水倒进锅、锅和生块根放进火堆——火堆随世界时间自动烧水、烤制、水煮。

**在线试玩：** https://etsevenday.github.io/shizheshengcun/

- 用电脑浏览器打开，建议窗口不小于 1280×720。
- 首次载入需要下载约 10MB 运行时，之后会缓存。
- 存档保存在本浏览器里，换浏览器或清除网站数据会丢失。
- 快捷键：M 地图，C 手工制作，R 休息，L 行动日志，F 反馈，Esc 关闭当前面板。
- 选中物品后，食用/饮用/使用与转移都在该卡片下方；打火器拖到火堆直接点火，或点火堆卡“点燃”选一把打火器。
- 第 2 日起探索或清理后可能发现敌踪，可选接敌或绕行；地块上的敌人也可以主动接近。战斗中点指令只预览，点右栏“执行”才提交；Esc 打开战斗菜单（没有脱战）。
- 地址加 `?dev=1` 时菜单里有开发入口（开发测试箱、放敌人、立即敌踪、感染、药品与维护材料），仅供测试。
- 遇到问题按 F 留言：会自动附上当前画面、系统环境和游戏状态，截图可以直接 Ctrl+V 粘贴。

## 工程结构

```
data/config.v0.6.json      全部数值配置（v0.4 配置，再加人物与战斗 v0.6/v0.5 的替换与新增；存档 schema 5）
src/Core/                  纯 C# 内核，不依赖 UnityEngine；同时是一个 Unity 本地包
web/Survival.Core/         .NET 类库，编译 src/Core 的源码
web/Survival.Core.Tests/   NUnit：M、G、S 验收用例，v0.3 的 D、C、E 用例，v0.4 的 P401–P421，v0.7 的 U708–U728（玩法层部分），v0.6 的 R601–R624 与 v0.5 的 B501–B528，旧存档迁移（0.2、schema 3、schema 4）与七日通关脚本（含带战斗路线）
web/Survival.Web/          Blazor WebAssembly 网页壳（拖拽 wwwroot/js/drag.js、全局滚轮 wheel.js、通用留言组件 feedback-widget.js）
tools/                     留言板建表脚本与收件工具 feedback.py
```

将来接 Unity UGUI：在 Unity 工程的 `Packages/manifest.json` 里加一行本地包引用即可复用同一份内核。

```json
"com.survival.core": "file:../../src/Core"
```

## 本地运行

需要 .NET 8 SDK。

```bash
dotnet test web/Survival.sln
```

```bash
dotnet run --project web/Survival.Web --launch-profile http
```

然后打开 http://localhost:5177 。推送到 main 后，GitHub Actions 会跑测试并自动发布到 Pages。
