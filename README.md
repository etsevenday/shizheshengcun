# 适者生存

末日里的单人卡牌生存原型：探索地点、清理地块、搜集物资、烧水做饭、搭棚过夜、与丧尸和野兽回合制战斗，撑过七天。卡片可以拖动：整理、拾取放下、木材投火堆、水倒进锅、锅和生块根放进火堆——火堆随世界时间自动烧水、烤制、水煮。

**在线试玩：** https://etsevenday.github.io/shizheshengcun/

- 用电脑浏览器打开，建议窗口不小于 1280×720。
- 首次载入需要下载约 10MB 运行时，之后会缓存。
- 存档保存在本浏览器里，换浏览器或清除网站数据会丢失。
- 快捷键：M 地图，C 手工制作，R 休息，L 行动日志，F 反馈，Esc 关闭当前面板。
- 中间四行一样高：地图与场景、设施与资源、当前地面、随身物品；选卡、开面板都不改变行高。随身最多 5 张物品卡（同批堆叠算 1 张，工具/武器各 1 张，锅连同内容 1 张）。
- 选中物品后，食用/饮用/使用与转移都在卡片旁弹出的小操作窗里；打火器拖到火堆直接点火，或点火堆卡“点燃”选一把打火器。
- 要确认的行动就在对象旁边：点相邻地图卡或“前往”在卡旁确认移动，敌踪卡点“接近”在卡旁“接近并开战”，制作在所选配方卡下方“开始”，休息在所选时长下方“开始”；右栏只看详细预测。行动开始后屏幕中央显示进度、剩余时间与“退出”。
- 新局在临时营地醒来，脑内的“饱饱”会提示先找吃喝；第一次到达农野荒地会遇到一只游荡尸（首战）。打赢后地面多一份“未鉴定的活性物质”，选中它在卡下点“吞噬融合”。
- 首战胜利后、第 2 日起探索或清理后可能发现敌踪，可选接敌或绕行；地块上的敌人也可以主动接近。战斗占上两行：上行队伍（我方左、敌方右），下行操作台；先选技能，把鼠标移到亮起的敌人上看右栏预测，点击它就执行；防御、用药等不用选敌人的指令在操作台“确认”；右键/Esc 取消瞄准，Esc 打开战斗菜单（没有脱战）。
- 新鲜食材在火堆上实际受热后受这次烹饪保护，做熟不因原保质时间到了而失败；取出就结束保护。复煮/烹饪成品从完成起计保质。
- 人物对话会盖住地图与设施两行，读完才能继续操作；顶栏“对话记录”可重看，“系统说明”按主题查看各系统规则，“生存目标”“生存提示”看本局进度与建议。
- 卡片与锅里物品旁的三角箭头点一下直接转移（不弹操作窗）；要改数量或目的地点卡片/图标本身。行动暂停时暂停层可以直接选打火器点火。
- 地址加 `?dev=1` 时菜单里有开发入口（开发测试箱、放敌人、立即敌踪、感染、药品与维护材料、活性物质、三种新配方材料），仅供测试。
- 遇到问题按 F 留言：会自动附上当前画面、系统环境和游戏状态，截图可以直接 Ctrl+V 粘贴。

## 工程结构

```
data/config.v0.6.json      全部数值配置（v0.4 配置，加人物与战斗 v0.6/v0.5 的替换与新增，再加系统策划总册 v1.0 答复与 Q7 调整的参数；存档 schema 8）
src/Core/                  纯 C# 内核，不依赖 UnityEngine；同时是一个 Unity 本地包
web/Survival.Core/         .NET 类库，编译 src/Core 的源码
web/Survival.Core.Tests/   NUnit：M、G、S 验收用例，v0.3 的 D、C、E 用例，v0.4 的 P401–P421，v0.7 的 U708–U728（玩法层部分），v0.6 的 R601–R624 与 v0.5 的 B501–B528，系统策划总册 v1.0 的 V10*（配置、烹饪、战斗、世界、剧情、迁移、Q7、重量与方位、对话、等待烹饪、就近执行、战斗本地执行），系统策划总册 v1.0 修订的 V11*（模型、烹饪受热保护、随身五卡、超额整理），旧存档迁移（0.2、schema 3、4、5、6、7）与七日通关脚本（完整新局含首战，另有带战斗路线）
web/Survival.Web/          Blazor WebAssembly 网页壳（拖拽 wwwroot/js/drag.js、全局滚轮 wheel.js、通用留言组件 feedback-widget.js）
tools/                     留言板建表脚本与收件工具 feedback.py；界面实机测量 verify-ui-v11.cjs（零依赖，三档分辨率四行等高与重叠）；无头试玩驱动 playtest/cdp.mjs
```

将来接 Unity UGUI：在 Unity 工程的 `Packages/manifest.json` 里加一行本地包引用即可复用同一份内核。

```json
"com.survival.core": "file:../../src/Core"
```

## 本地运行

需要 .NET 8 SDK。

```bash
dotnet test web/Survival.sln
```

```bash
dotnet run --project web/Survival.Web --launch-profile http
```

然后打开 http://localhost:5177 。推送到 main 后，GitHub Actions 会跑测试并自动发布到 Pages。
